# A 组 · 比较与真假

### A1 · 六种比较运算符 【新】

```python
print(5 > 3)
print(5 < 3)
print(5 >= 5)
print(5 <= 3)
print(5 == 5)
print(5 != 5)
```

**实际输出**

```
True
False
True
False
True
False
```

> **`>=` 和 `<=` 都包含"等于"**，所以 `5 >= 5` 是 `True`。
> **`!=` 是"不等于"**，`5 != 5` 是 `False`。

---

### A2 · `None` 和布尔值 【新】

```python
a = True
b = False
c = None

print(a, b, c)
print(type(c))
print(c == None)
print(type(a))
```

**实际输出**

```
True False None
<class 'NoneType'>
True
<class 'bool'>
```

> **`None` 的类型是 `NoneType`**，不是 `bool`，也不是 `str`。
>
> **它是"没有值"的意思**，和 `0`、`""` 都不一样：
> - `0` → 值是零
> - `""` → 值是空字符串
> - **`None` → 根本没有值**
>
> **进阶（本课不深入）**：官方建议写 `c is None` 而不是 `c == None`。
> 现在你只要知道 **`None` 这个名字和含义**就行。

### A3 · 什么算真什么算假 【新】

```python
print(bool(0))
print(bool(1))
print(bool(""))
print(bool("abc"))
print(bool([]))
print(bool([1, 2]))
```

**实际输出**

```
False
True
False
True
False
True
```

**记这一张表：**

| 算「假」 | 算「真」 |
|---|---|
| `False` | `True` |
| **`None`** | 任何非空的东西 |
| `0` / `0.0` | 非零数字 |
| `""` | 非空字符串 |
| `[]` | 非空列表 |

> **实用价值**：以后你可以写 `if 列表:` 来判断"列表里有没有东西"，
> **不用写 `if len(列表) > 0:`**。这是 Python 的写法。

# B 组 · `if` 基本结构

### B1 · 单分支 【新】

```python
age = 20

if age >= 18:
    print("成年了")

print("结束")
```

**实际输出**

```
成年了
结束
```

> **`print("结束")` 没有缩进**，所以它**不属于 `if`**，无论条件成立与否都会执行。
>
> **如果你把它缩进了**，`age = 15` 时就不会输出 `结束`——**这就是缩进决定归属。**

---

### B2 · `if` / `else` 【新】

```python
age = 15

if age >= 18:
    print("成年了")
else:
    print("未成年")
```

**实际输出**

```
未成年
```

> 把 `age` 改成 20，输出就变成 `成年了`。
> **两条分支都要跑一遍**——这叫"测试两种分支"。

---

### B3 · `if` / `elif` / `else` 【新】

```python
score = 85

if score >= 90:
    print("优秀")
elif score >= 80:
    print("良好")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

**实际输出**

```
良好
```

**四个测试用例：**

| `score` | 输出 |
|---|---|
| 95 | `优秀` |
| 85 | `良好` |
| 60 | `及格` |
| 59 | `不及格` |

> **为什么必须"从高到低"排？**
>
> `elif` 是**从上往下依次判断，第一个成立就执行，后面全跳过**。
> 所以如果 `score >= 60` 排在最前面，**85 分会被它先抓住**，输出"及格"。
>
> **E2 那道改错题就是这个坑。**

---

### B4 · `=` 还是 `==` 【新】

```python
x = 5
print(x == 5)

# if x = 5:                      # 故意写错，报错如下
#   File "...", line 5
#     if x = 5:
#        ^^^^^
# SyntaxError: invalid syntax. Maybe you meant '==' or ':=' instead of '='?
```

**实际输出**

```
True
```

> **报错关键字**：`SyntaxError`（语法错误）。
> **Python 直接拦住了，还提示"你是不是想写 `==`"**——这是好事，不会静默出错。

### C4 · 组合与优先级 【新】

```python
print((5 > 3) and (2 > 4))
print((5 > 3) or (2 > 4))
print(not (5 > 3))
print(True or False and False)
```

**实际输出**

```
False
True
False
True
```

**逐行拆解：**

| 行 | 计算过程 | 结果 |
|---|---|---|
| `(5 > 3) and (2 > 4)` | `True and False` | `False` |
| `(5 > 3) or (2 > 4)` | `True or False` | `True` |
| `not (5 > 3)` | `not True` | `False` |
| `True or False and False` | `True or (False and False)` = `True or False` | `True` |

**多加的那一行：**

```python
print((True or False) and False)
```

**实际输出**

```
False
```

> **对比一下**：
> - `True or False and False` → **`True`**（`and` 先算）
> - `(True or False) and False` → **`False`**（括号让 `or` 先算）
>
> **优先级：`not` > `and` > `or`。记不住就加括号。**

# D 组 · 嵌套与综合

### D1 · 嵌套 【新】

```python
age = 20
has_ticket = True

if age >= 18:
    if has_ticket:
        print("可以入场")
    else:
        print("需要买票")
else:
    print("未成年，不能入场")
```

**实际输出**

```
可以入场
```

**三条路径都测一遍：**

| `age` | `has_ticket` | 输出 |
|---|---|---|
| 20 | True | `可以入场` |
| 20 | False | `需要买票` |
| 15 | True | `未成年，不能入场` |

> **缩进层级**：
> ```
> if age >= 18:          ← 第 1 层
>     if has_ticket:     ← 第 2 层（缩进 4）
>         print(...)     ← 第 3 层（缩进 8）
>     else:              ← 这个 else 配的是 has_ticket
> else:                  ← 这个 else 配的是 age >= 18
> ```

### D2 · 闰年判断 【新】

> ### ⚠️ 更正：这里原本标的是"二级经典题"——**那个说法是错的**
>
> 你问"这题在二级里算什么位置"之后，我去查了真题。结论：
>
> **闰年逻辑几乎不出现在二级操作题里。** 它是**教材/高中信息技术**里的经典练习题，不是二级真题的形态。
>
> **二级操作题的真实形态见 `学习规则.md` 5.3 节**——核心是
> **turtle / jieba / 文件读写 / 字典词频统计**，而且**以"填空补全"为主，不是从零写**。
>
> **那为什么还留着这题？**
> 1. 它练的是 **`%` + `and`/`or` + `if`** ——这三样是**所有**操作题的基础
> 2. `1900` 那个用例专治"整百年"的坑
> 3. 它是**好的逻辑练习**，只是**别把它当成"真题模拟"**


```python
year = int(input("请输入年份："))

if (year % 4 == 0 and year % 100 != 0) or (year % 400 == 0):
    print(f"{year} 是闰年")
else:
    print(f"{year} 不是闰年")
```

**四个测试用例（实际输出）**

| 输入 | 输出 |
|---|---|
| `2024` | `2024 是闰年` |
| `2000` | `2000 是闰年` |
| `1900` | `1900 不是闰年` |
| `2023` | `2023 不是闰年` |

**为什么这四个用例特别重要：**

| 年份 | 考点 |
|---|---|
| 2024 | 普通闰年（`%4==0` 且 `%100!=0`） |
| **2000** | **整百年但能被 400 整除** → 是闰年 |
| **1900** | **整百年但不能被 400 整除** → 不是闰年（**最容易判错**） |
| 2023 | 普通平年 |

> **括号是关键**：`(A and B) or C`
> 如果不加括号写成 `A and B or C`，因为 **`and` 优先级比 `or` 高**，
> 结果**恰好一样**——但这是运气，**写括号才是对的**（可读性也更好）。

### D3 · 回文判断 【新 + 复习】

```python
word = input("请输入一个词：")

if word == word[::-1]:
    print(f"{word} 是回文")
else:
    print(f"{word} 不是回文")
```

**三个测试用例（实际输出）**

| 输入 | 输出 |
|---|---|
| `level` | `level 是回文` |
| `python` | `python 不是回文` |
| `上海自来水来自海上` | `上海自来水来自海上 是回文` |

> **这题把三课串起来了：**
>
> | 用到的 | 来自 |
> |---|---|
> | `input()` | 第二课 |
> | **切片反转 `[::-1]`** | **第三课 + 复习一** |
> | f-string | 第二课 |
> | **`if` / `else`** | **本课** |
>
> **`word[::-1]` 就是"把字符串倒过来"**——复习一 甲5 你已经用过。
> 这里只是把它和 `if` 组合起来。

# E 组 · 两道特殊题

## E1 · 读官方文档自学 【新】★ 规则七

### 六个式子的实际输出

```python
print(5 and 3)          # 3
print(0 or "abc")       # abc
print("" and 5)         # （空字符串，什么都不显示）
print("abc" and 5)      # 5
print(0 and 5)          # 0
print("" or 0)          # 0
```

**注意第 3 行**：`"" and 5` 的结果是**空字符串**，所以 `print` 出来是**一行空白**。
看起来"什么都没输出"，其实是输出了一个空字符串。用 `repr()` 能看到：

```python
print(repr("" and 5))    # ''
```

### 四个问题的答案

**Q1：`and` / `or` 返回的一定是 `True` 或 `False` 吗？**

> **不是。** 它们返回的是**参与运算的某一个操作数本身**。

**Q2：`5 and 3` 的结果是什么？为什么？**

> **`3`**。
> `5` 是"真"，所以 `and` 继续往右看，**把右边那个直接返回**——也就是 `3`。
> **注意返回的是 `3`（整数），不是 `True`。**

**Q3：`0 or "abc"` 的结果是什么？为什么？**

> **`"abc"`**。
> `0` 是"假"，所以 `or` 继续往右看，**把右边那个直接返回**——也就是 `"abc"`。

**Q4：一句话总结 `and` / `or` 到底怎么决定返回值。**

> **`and`：先看左边。左边为假 → 返回左边；左边为真 → 返回右边。**
> **`or`：先看左边。左边为真 → 返回左边；左边为假 → 返回右边。**

**整理成表：**

| 写法 | 左边 | 返回 |
|---|---|---|
| `A and B` | 假 | **A** |
| `A and B` | 真 | **B** |
| `A or B` | 真 | **A** |
| `A or B` | 假 | **B** |

**对着验证：**

| 式子 | 左边真假 | 返回 |
|---|---|---|
| `5 and 3` | 5 真 | → 右边 `3` ✅ |
| `0 or "abc"` | 0 假 | → 右边 `"abc"` ✅ |
| `"" and 5` | "" 假 | → 左边 `""` ✅ |
| `"abc" and 5` | 真 | → 右边 `5` ✅ |
| `0 and 5` | 0 假 | → 左边 `0` ✅ |
| `"" or 0` | "" 假 | → 右边 `0` ✅ |

### 为什么这个知识有用

**1. 解释了 `if` 为什么能工作**

```python
if age > 18 and age < 30:
```

`and` 返回的可能是某个操作数，但 **`if` 只看它"真不真"**，所以照样正确。

**2. 一个常见写法（二级会考）**

```python
name = input("请输入名字：") or "匿名"
```

**如果用户直接回车（输入空字符串 `""`，是"假"），`or` 就会返回右边的 `"匿名"`。**
**这是个"默认值"的惯用写法。**

**3. 短路求值**

`A and B` 里，**如果 A 是假，B 根本不会被计算**。这叫"短路"。
以后（学函数时）会看到它的实际用途——**用来避免不必要的计算和报错**。

> **官方文档对应的说法**（你在 [6.11 布尔运算](https://docs.python.org/zh-cn/3/reference/expressions.html#boolean-operations) 里应该读到了）：
> `x and y` 先对 `x` 求值，**为假则返回 `x` 的值**，否则对 `y` 求值并返回结果；
> `x or y` 先对 `x` 求值，**为真则返回 `x` 的值**，否则对 `y` 求值并返回结果。

## E2 · 改错题 【新】★ 规则八

### 问题在哪

**`elif` 的顺序反了。**

```python
if score >= 60:        # ← 85 满足这个，直接执行，后面全部跳过
    print("及格")
elif score >= 80:      # ← 永远轮不到
elif score >= 90:      # ← 永远轮不到
```

**`elif` 是"从上往下，第一个成立就执行，后面全跳过"。**
`score = 85` 时，`85 >= 60` 成立，所以输出 `及格`，**后面两个 `elif` 根本没机会判断**。

### 改对

**从高到低排：**

```python
score = 85

if score >= 90:
    print("优秀")
elif score >= 80:
    print("良好")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

**四个测试用例（实际输出）**

| `score` | 输出 |
|---|---|
| `95` | `优秀` |
| `85` | `良好` |
| `60` | `及格` |
| `59` | `不及格` |

### 关于 `59` —— 题目问你"想想应该是什么"

**`59` 不满足任何一条 `>=` 判断**，所以：

- **如果你的代码有 `else:`** → 输出 `不及格` ✅ **（推荐这样写）**
- **如果没有 `else:`** → **什么都不输出**，程序安静地结束

> **这就是为什么推荐加 `else`。**
> 没有 `else`，程序遇到"所有条件都不满足"时会**静默通过**——看起来没出错，其实漏了情况。
> **不报错的漏洞最难发现**——这正是这道改错题想让你体会的。

### 这题的真正教训

> **`elif` 链的顺序 = 你的判断逻辑。**
> 顺序错了，程序**照样能跑**，只是结果悄悄错了。
>
> **写 `elif` 链时问自己一句：这些条件互相包含吗？**
> 如果 `A` 包含 `B`，那 **`A` 必须写在后面**（先判断更严格的）。
