# 第 1 节 · 比较与真假

## 1.1 六种比较运算符

**比较的结果是 `True` 或 `False`：**

```python
print(5 > 3)      # True
print(5 < 3)      # False
print(5 >= 5)     # True
print(5 <= 3)     # False
print(5 == 5)     # True
print(5 != 5)     # False
```

| 运算符 | 意思 |
|---|---|
| `>` | 大于 |
| `<` | 小于 |
| `>=` | 大于等于 |
| `<=` | 小于等于 |
| `==` | **等于**（两个等号！） |
| `!=` | **不等于** |

> ⚠️ **`==` 是两个等号。** 一个 `=` 是赋值，两个 `==` 才是比较。第 2.4 节专门讲这个坑。

## 1.2 `True` / `False` / `None`

**前两个你见过（第二课 B2）。`None` 是本课新增的。**

```python
a = True
b = False
c = None

print(a, b, c)
print(type(c))
```

实际输出：

```
True False None
<class 'NoneType'>
```

| 值 | 意思 | 类型 |
|---|---|---|
| `True` | 真 | `bool` |
| `False` | 假 | `bool` |
| **`None`** | **"什么都没有"** | **`NoneType`** |

**`None` 是 Python 里表示"空"的专用值**，和 `0`、`""` 都不一样：

- `0` 是"值是零"
- `""` 是"值是空字符串"
- **`None` 是"根本没有值"**

> **注意**：官方文档建议判断 `None` 用 `is None`，而不是 `== None`。本课不深入 `is`，你**先记住 `None` 这个名字和它的含义**。

## 1.3 什么算"真"、什么算"假"

**Python 里几乎所有东西都能当条件用。** 用 `bool()` 一看就清楚：

```python
print(bool(0))
print(bool(1))
print(bool(""))
print(bool("abc"))
print(bool([]))
print(bool([1, 2]))
```

实际输出：

```
False
True
False
True
False
True
```

**规律——这些算"假"：**

| 假值 | 说明 |
|---|---|
| `False` | 本身 |
| **`None`** | 空 |
| **`0`** / `0.0` | 数字零 |
| **`""`** | 空字符串 |
| **`[]`** | 空列表 |

**除了这些，其他都算"真"。**

> **为什么这个重要**：你以后会写 `if 列表:` 来判断"列表里有没有东西"——
> **不用写 `if len(列表) > 0:`**。这是 Python 的写法。

# 第 2 节 · `if` 基本结构

> **`if` 就是"如果……就……"。** 这是程序学会"做选择"的第一步。

## 2.1 单分支 `if`

```python
age = 20
if age >= 18:
    print("成年了")
print("结束")
```

实际输出：

```
成年了
结束
```

**三个必须记住的点**（第一课讲缩进时提过，现在正式用）：

1. `if` 那行的末尾，**必须有英文冒号 `:`**
2. 冒号下面的一行，**必须缩进**（4 个空格）
3. **只有缩进的那一行属于 `if`** —— `print("结束")` 没缩进，所以**无论如何都会执行**

## 2.2 `if` / `else`

**加一个"否则"：**

```python
age = 15
if age >= 18:
    print("成年了")
else:
    print("未成年")
```

实际输出：

```
未成年
```

**`if` 和 `else` 是二选一，永远只执行其中一个。**

## 2.3 `if` / `elif` / `else`

**多个条件时，用 `elif`（else if 的缩写）：**

```python
score = 85
if score >= 90:
    print("优秀")
elif score >= 80:
    print("良好")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

实际输出：

```
良好
```

**关键：`elif` 是从上往下依次判断，第一个成立的就执行，后面的全部跳过。**

> ⚠️ **所以顺序很重要。** 如果把 `score >= 60` 写在最前面，85 分会被判成"及格"。
> **这一点 E2 那道改错题专门考。**

## 2.4 `=` 和 `==` 的区别

```python
x = 5          # 一个等号：赋值，把 5 存进 x
print(x == 5)  # 两个等号：比较，结果是 True
```

实际输出：

```
True
```

**如果写错了会怎样？** 实测：

```python
x = 5
if x = 5:
    print("a")
```

```
SyntaxError: invalid syntax. Maybe you meant '==' or ':=' instead of '='?
```

**Python 直接拦住了**，还提示你"是不是想写 `==`"。

> **这是好事**——写错了立刻报错，不会静默出错。

# 第 3 节 · 逻辑运算

> **`and` / `or` / `not` 用来把多个条件连起来。**
> **这一节是二级选择题的高频考点。**

## 3.1 `and` —— 两个都成立才真

```python
age = 25
print(age > 18 and age < 30)
```

实际输出：

```
True
```

**`and` 两边都为 `True`，结果才是 `True`；只要有一个 `False`，结果就是 `False`。**

| 左 | 右 | `and` 结果 |
|---|---|---|
| True | True | **True** |
| True | False | False |
| False | True | False |
| False | False | False |

## 3.2 `or` —— 有一个成立就真

```python
day = "周六"
print(day == "周六" or day == "周日")
```

实际输出：

```
True
```

**`or` 两边只要有一个 `True`，结果就是 `True`。**

| 左 | 右 | `or` 结果 |
|---|---|---|
| True | True | True |
| True | False | **True** |
| False | True | **True** |
| False | False | False |

## 3.3 `not` —— 反过来

```python
is_rain = False
print(not is_rain)
```

实际输出：

```
True
```

**`not` 把真变假、假变真。**

## 3.4 优先级：`and` 比 `or` 高

```python
print(True or False and False)
```

实际输出：

```
True
```

**为什么？** 因为 **`and` 先算**：

```
True or (False and False)
= True or False
= True
```

**如果想让 `or` 先算，就加括号：**

```python
print((True or False) and False)    # False
```

> **`not` 最高，`and` 次之，`or` 最低。**
> **记不住就加括号**——括号永远最优先，而且更易读。

# 第 4 节 · 嵌套与综合

## 4.1 嵌套 `if`

**`if` 里面还能再放 `if`**——靠**缩进**表达层级：

```python
age = 20
has_ticket = True

if age >= 18:
    if has_ticket:
        print("可以入场")
    else:
        print("需要买票")
else:
    print("未成年，不能入场")
```

实际输出：

```
可以入场
```

**缩进的层级关系：**

```
if age >= 18:          ← 第 1 层
    if has_ticket:     ← 第 2 层（缩进 4）
        print(...)     ← 第 3 层（缩进 8）
```

> **两个 `else` 分属不同的 `if`**——靠缩进对齐来判断。
> **缩进对错了，逻辑就完全变了。** 这是 Python 最容易出错的地方之一。

# 附录

## A. 本课常见报错速查

| 报错 | 原因 | 怎么改 |
|---|---|---|
| `SyntaxError: invalid syntax. Maybe you meant '==' or ':=' instead of '='?` | `if` 里用了 `=` | 比较要用 `==` |
| `SyntaxError: expected ':'` | `if` 那行**漏了冒号** | 在条件后面加 `:` |
| `IndentationError: expected an indented block after 'if' statement` | 冒号后面**没缩进** | 下一行缩进 4 空格 |
| `NameError: name 'xxx' is not defined` | 变量名拼错 / 没定义 | 检查拼写 |

## B. 本课语法速查

```python
# 比较（结果是 True / False）
5 > 3      5 < 3      5 >= 5      5 <= 3      5 == 5      5 != 5

# 布尔值与空值
True    False    None

# 什么算假
bool(0) → False    bool("") → False    bool([]) → False
# False / None / 0 / "" / [] 都算假，其余算真

# if 单分支
if 条件:
    语句            # 缩进 4 空格

# if / else
if 条件:
    语句
else:
    语句

# if / elif / else   —— 从上往下，第一个成立的就执行
if 条件1:
    语句
elif 条件2:
    语句
else:
    语句

# 逻辑运算
A and B     # 两个都真才真
A or B      # 有一个真就真
not A       # 反过来

# 优先级：not > and > or   （记不住就加括号）
```
