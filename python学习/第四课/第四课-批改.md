## 1. `and` / `or` 的返回规则 ★★（本次最重要）

**你的原话**：说反了（见上）。

**正确规则——记这两句就够：**

> **`and`：看左边。左边假 → 返回左边；左边真 → 返回右边。**
> **`or`：看左边。左边真 → 返回左边；左边假 → 返回右边。**

**一句话记法**：**`and` 要"一路真"，`or` 要"一路假"才继续往右走。**

**自己校验的口诀**：
- `5 and 3` → 5 真 → **往右走** → `3`
- `0 or "abc"` → 0 假 → **往右走** → `"abc"`
- `"" and 5` → 空假 → **停下** → `""`
- `"abc" and 5` → 真 → 往右 → `5`

**实在记不住就写这一句**：**"往右走的条件：`and` 看到真，`or` 看到假。"**

## 2. `else` 后面**不能**带条件

**你的原话**（`b2.py` 的报错日志）：

```
SyntaxError: expected ':'
```

**正确知识点**：

```python
if age >= 18:
    ...
else:               # ← else 后面直接冒号，不带条件
    ...
```

- **`else` = "其余所有情况"**，它**不接受条件**
- **如果还要判断别的条件，用 `elif 条件:`**

**你的理解是对的**（"else 是除此以外的所有情况。elif 可以用作别的情况"），**这条是你的留痕，不是缺口——但值得留在这里。**

## 3. `if x == True:` 写成 `if x:`

**位置**：`d1.py` 的 `if haveTicket == True:`

**正确写法**：


**顺便**：`bool` 变量命名通常不加 `is` 前缀？——**不，`is_xxx` 恰恰是好名字，继续用。**
