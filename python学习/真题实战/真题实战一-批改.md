# 三、选择题（20 / 30）

**你对了 10 题，错了 5 题。**

## ❌ 错题 1：第 1 题 · 合法变量名

你答 **B**（`my-var`），正确是 **C**（`_name`）。

**实测：**
```
SyntaxError: cannot assign to expression here.
```

**变量名不能含 `-`** —— `my-var` 会被 Python 看成 `my` **减** `var`，那是算式，不是名字。

**完整规则：** 只能用**字母、数字、下划线**，且**不能以数字开头**，**不能用关键字**（`class`）。

## ❌ 错题 2：第 2 题 · `//` 和 `/`

你答 **B**（`3.5 1`），正确是 **A**（`3 1`）。

**实测：**
```
7 // 2, 7 % 2 = 3 1
```

**`//` 是整除，不返回小数。** 返回 `3.5` 的是 `/`。

> ⚠️ **这一条要留意**——`/` 和 `//` 是**第二课的核心**，而且当时你 A2 题做过一遍。
> 这**不是"没学过"，是隔久了模糊了**。**属于该复习的信号。**

## ❌ 错题 3：第 3 题 · 幂运算

你答 **A**（`64`），正确是 **B**（`512`）。

**实测：**
```
2 ** 3 ** 2 = 512
```

**幂运算是「从右往左」算的**：

```
2 ** 3 ** 2  =  2 ** (3 ** 2)  =  2 ** 9  =  512     ✅
不是 (2 ** 3) ** 2 = 8 ** 2 = 64                      ❌
```

> **这是二级选择题的经典陷阱**——**记住"幂运算右结合"**就行。
> （`+` `-` `*` `/` 是左结合，**只有 `**` 是右结合**。）

## ❌ 错题 4：第 5 题 · 真值判断 ★ 这题最值得说

你答 **C**（`False` 和 `False`），正确是 **A**（`False` 和 **`True`**）。

**实测：**
```

bool("0") = True      ← 你答成了 False
```

**`""` 是空字符串（假）；但 `"0"` 是「含一个字符 0 的字符串」（真）。**

### ⚠️ 而你自己在第四课 a3 里写过这样一句话

**用你自己的规律推一遍：**

| 值 | 装了东西吗？ | 按你的规律 |
|---|---|---|

**你自己的规律能推出正确答案——但你没用上。**

> **这是这次最值得记住的一条**：

## ❌ 错题 5：第 8 题 · 运算符优先级
