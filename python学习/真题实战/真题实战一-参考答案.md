# 一、单项选择题（每题 2 分，共 30 分）

| 题 | 答案 | 解析 |
|---|---|---|
| 1 | **C** | 变量名不能以数字开头（A 错）、不能含 `-`（B 错）、不能用关键字（`class` 是关键字，D 错）。**`_name` 合法**。 |
| 2 | **A** | `//` 整除 → `3`；`%` 取余 → `1`。**注意不是 `3.5`**——`/` 才返回小数。 |
| 3 | **B** | **幂运算从右往左算**：`2 ** (3 ** 2)` = `2 ** 9` = **512**。不是 `(2**3)**2 = 64`。 |
| 4 | **B** | `[1:4]` 取下标 1、2、3 → `y`、`t`、`h` → **`yth`**。含头不含尾。 |
| 5 | **A** | `""` 是空字符串 → **假**；`"0"` 是**含一个字符的字符串** → **真**。 |
| 6 | **B** | `None` 的类型是 **`NoneType`**，既不是 `bool` 也不是 `str`。 |
| 7 | **C** | `5 and 0` → 5 是**真** → 往右走 → 返回右边的 `0`。**不是 `False`。** |
| 8 | **B** | `*` 优先级高于 `+`：`"a" + ("b" * 2)` = `"a" + "bb"` = **`abb`**。 |
| 9 | **A** | `-3` 是第 3 个（即 3），`-1` 是最后一个（5）。含头不含尾 → 取 3、4 → **`[3, 4]`**。 |
| 10 | **B** | 中文字符也算 **1 个字符**，一共 **9 个字**。（不是按字节算 18。） |
| 11 | **C** | **`sorted(a)` 函数**：不改原列表，返回新列表。**`a.sort()` 方法**：原地改。 |
| 12 | **B** | `b = a` 是**引用**，同一个列表。`b.append(3)` 后 `a` 也变成 `[1,2,3]` → `len` = **3**。 |
| 13 | **C** | **必须接住返回值。** B 选项 `int("24")` 算完就丢了，`x` 根本没被赋值。 |
| 14 | **A** | `3 > 5` 是 `False`，`not False` = **`True`**。 |
| 15 | **C** | **`else` 后面不能跟条件。** 要判断条件得用 `elif`。（`else x > 0:` 会报 `SyntaxError`。） |

# 二、基本操作题（共 40 分）

## 第 1 题（15 分）· 成绩等级

```python
score = int(input("请输入成绩："))

if score >= 90:              # ← (1)
    print("优秀")
elif score >= 80:            # ← (2)
    print("良好")
elif score >= 60:
    print("及格")
else:                        # ← (3)
    print("不及格")
```

**四个测试用例（实际输出）**

| 输入 | 输出 |
|---|---|
| 95 | `优秀` |
| 85 | `良好` |
| 60 | `及格` |
| 59 | `不及格` |

**评分**：(1) 5 分，(2) 5 分，(3) 5 分。

> **(1) 必须是 `score >= 90`** —— 而且**必须放在最前面**。
> **(2) 是 `elif`**，不是 `if` —— 用 `if` 的话 85 会被前一个条件之外的情况重复判断。
> **(3) 是 `else`**，**不带条件**。

## 第 2 题（15 分）· 偶数和

```python
nums = [3, 8, 12, 5, 20, 7]

total = 0                        # ← (1)
for n in nums:
    if n % 2 == 0:               # ← (2)
        total = total + n        # ← (3)

print(total)
```

**实际输出**

```
40
```

**验证**：8 + 12 + 20 = **40** ✅

**评分**：(1) 4 分，(2) 6 分，(3) 5 分。

> **(1) 是 `0`** —— 累加器的"桶"必须从 0 开始。
> **(2) 是 `n % 2 == 0`** —— **"整除"要用取余判断，不是除法**。
> （这就是 `语法速查.md` 第〇节「词面陷阱表」第一条。）
> **(3) 是 `total + n`** —— **右边必须出现 `total` 才是累加**。
> 写成 `n` 就成了替换，最后只会得到最后一个偶数。

## 第 3 题（10 分）· 字符串切片

```python
s = "Python"

print(s[:3])        # ← (1)  输出 Pyt
print(s[::-1])      # ← (2)  输出 nohtyP
```

**实际输出**

```
Pyt
nohtyP
```

**评分**：每题 5 分。

> **(1) `s[:3]`** —— 从头取到下标 3 之前（下标 0、1、2）。
> 也可以写 `s[0:3]`，同样正确。
> **(2) `s[::-1]`** —— 步长 -1，反转。

# 三、综合编程题（20 分）

## 参考代码

```python
a = int(input("请输入第1个成绩："))
b = int(input("请输入第2个成绩："))
c = int(input("请输入第3个成绩："))

scores = [a, b, c]

print(f"共 {len(scores)} 门")
print(f"总分 {sum(scores)}")
print(f"平均 {sum(scores) / len(scores):.2f}")
print(f"最高 {max(scores)}，最低 {min(scores)}")
print(f"是否全部及格：{scores[0] >= 60 and scores[1] >= 60 and scores[2] >= 60}")
```

## 运行结果

**输入 `85`、`92`、`58`：**

```
请输入第1个成绩：85
请输入第2个成绩：92
请输入第3个成绩：58
共 3 门
总分 235
平均 78.33
最高 92，最低 58
是否全部及格：False
```

**输入 `70`、`80`、`90`：**

```
共 3 门
总分 240
平均 80.00
最高 90，最低 70
是否全部及格：True
```

## 评分细则（20 分）

| 项 | 分 | 说明 |
|---|---|---|
| 读入 3 个整数并存进列表 | 4 | `int(input(...))` × 3，`scores = [a, b, c]` |
| 共几门 | 3 | `len(scores)` |
| 总分 | 3 | `sum(scores)` |
| 平均（2 位小数） | 4 | `sum/len` + `:.2f` |
| 最高、最低 | 3 | `max()` / `min()` |
| **是否全部及格** | 3 | **`and` 连三个比较** |

## 几个关键点

**1. 第 5 行必须用 `and`：**

```python
scores[0] >= 60 and scores[1] >= 60 and scores[2] >= 60
```

**三个都成立才 `True`。** 只要有一个不及格，`and` 就返回假。

> **为什么不写成 `min(scores) >= 60`？**
> **那样也对**，而且更简洁（"最低分都及格了，那就是全及格"）。
> **两种都能拿满分**——但 `and` 那版更"直译"，考官更容易看懂你的思路。

**2. 也可以把三个比较存起来再用 `and`：**

```python
ok1 = scores[0] >= 60
ok2 = scores[1] >= 60
ok3 = scores[2] >= 60
print(f"是否全部及格：{ok1 and ok2 and ok3}")
```

**3. 平均分不能手写：**

```python
f"平均 {sum(scores) / len(scores):.2f}"     # ✅ 算出来的
f"平均 78.33"                                # ❌ 手写数字不给分
```
