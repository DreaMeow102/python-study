# 二、基本操作题（共 3 题，共 40 分）

> **这一部分是二级真题的典型形式**：给你一段代码，**在横线处填入正确内容**。
>
> **不要改其他代码。** 把完整的代码（填好的）写进 `code\操作题1.py` 等文件里。

## 第 1 题（15 分）· 成绩等级

**要求**：补全横线，使程序能正确判断成绩等级。

```python
score = int(input("请输入成绩："))

if ________(1)________:
    print("优秀")
________(2)________ score >= 80:
    print("良好")
elif score >= 60:
    print("及格")
________(3)________:
    print("不及格")
```

**要求**：`95` → `优秀`；`85` → `良好`；`60` → `及格`；`59` → `不及格`。

---

## 第 2 题（15 分）· 偶数和

**要求**：补全横线，使程序输出列表中**所有偶数**的和。

```python
nums = [3, 8, 12, 5, 20, 7]

total = ________(1)________
for n in nums:
    if ________(2)________:
        total = ________(3)________

print(total)
```

**正确输出应该是 `40`**（8 + 12 + 20 = 40）。

# 三、综合编程题（共 1 题，20 分）

> **这一部分和真题一样，是从零写代码**（不是填空）。

**要求**：新建 `code\综合题.py`，实现下面的功能。

**输入**：读入 **3 个整数**（成绩），存入一个列表。

**输出**（五行）：

```
共 3 门
总分 235
平均 78.33
最高 92，最低 58
是否全部及格：False
```

**具体要求**：

| 行 | 内容 |
|---|---|
| 1 | 共几门（用 `len()`） |
| 2 | 总分（用 `sum()`） |
| 3 | 平均分，**保留 2 位小数** |
| 4 | 最高分和最低分 |
| 5 | **是否全部及格（每门都 ≥ 60）**，输出 `True` 或 `False` |

**测试用例**：输入 `85`、`92`、`58` → 输出应该是上面那样（`False`）。
再测一组 `70`、`80`、`90` → 最后一行的结果应该变。

> **提示**：第 5 行要用 `and` 把三个比较连起来。
> **这门课还没学循环**，所以三个分数**只能一个个比较**——这正好用上 `and`。
