### 这一轮定下的关键判断（别忘）

1. **出题的锚点是"知识点 + 例题"，不是学生。** 学生只在**批改**里出现。
   （`易错点台账` 降级为"批改时归因用"，**不拿来设计题面、也不拿来预判他**。他说：「我是动态的，不完全是死的」。）
2. **留痕 = 保留他自己的错，不是制造错误。**
   （第六课 A1 曾要求"先故意写错、抄报错原文"，他当场指出：「留痕是我留自己错误的痕迹，不是假定我错误」。）
3. **规定 ≠ 账本。** 事件、原话、事故经过 → 归 `旧文档\` 或本文件；规定里只留判据。
4. **注释变少是好事**（他错得少了）。他**唯一**的真实失败模式是"**懒得跑**"（旧台账三次都对得上）。
5. **他会直接在代码注释里提问** → 批改第一步是**读他的代码**（**不是** grep 问号；他纠正过：照抄的报错原文也带 `?`，假阳性）。
6. **不假定他会错，也不假定他会抄。** 题面里每句话要能改写成"这题要求你做到 X"。
7. **真题：先上网找真题原文；找得到就原样用，不管超纲**（不裁、不换、不因"还没学过"而删）。
   找不到才自拟仿真卷，并在试卷头写明"它不是真题原文"。
8. **复习：检查出题覆盖的知识点，是否和路线要求的课程内容重合。**
9. **三级分离，边界不许互相污染**：路线（顺序 + 块）/ 参考格式（形状）/ 知识点拟定（来源 + 怎么教清楚）。

### `复核.ps1` 的约定（重要）

每题一个文件：**`第X课\参考\a1.py`**

```python
# @输入          ← 可选，喂给 stdin 的行
# 407
# @预期          ← 必须，**我认为这题的正确答案**（独立于代码写下）
# 各位数字之和：11
# @结束          ← 必须
n = int(input())
```

- **参考解里不写 `input()` 的提示符**（写裸的）——重定向后提示符会和输出挤在一起，没法逐行比
- **只有绿的题才写进答案**；红的**不写**（写了 = 把"没查清的"当"实测过的"发出去）
- `-写答案` 会**拒写**比旧答案题数更少的内容（防截断）
- 一个参考解都没有时 → `结果：空` + `exit 1`，**不报绿**
- ⚠️ **它必须存成 UTF-8 with BOM**（PS 5.1）

## 2026-09-22 · 铁律的出口：就地发明 → 双方商定 → 抽象成一条 → 焊进链

我上一轮担心过：「如果中途我又开始就地发明（自己加字段、自己定题型），那就是链条有洞，而这次没有旧文档可以兜。」

**他给的解法（原话）：**

> 「**这没关系。如果平繁，可以双方商定后抽象成一个条目（避免此类问题），然后焊进文档链里即可。**
> 这不可能都不出错，但这是避免膨胀、避免昏头等的最好办法。」
> 「（**也是我实现各种项目，和 ai 合作的方法论之一**）」

> 「至于跑不出正文？没关系。以前六课都没这么稳定的文档，只依靠上下文，不照样有了？
> **第六课因为文档复杂化反而崩了。** 我认为，现在理论上是最优解。」

### 所以要这么操作

**"就地发明" = 信号，不是漏洞。** 它说明链条缺一条 → **双方商定** → 加**一条** → 焊进去。
**冻结不是死锁，是设了一道闸。**

### ⚠️ 它为什么这次不会重蹈覆辙（三个性质，缺一不可）

我盯着这条，是因为「**每出一次错就抽象一条**」**正是旧 `学习规定` 长到 828 行的路径**——
每条判据后面都挂着一个【事件】。它这次能不能不烂，取决于：

1. 加进去的是**一条判据**，**不是一段【事件】**
2. 必须**双方商定**——**我不能单方面加**
3. 来历写进本文件（`AI备忘.md`），**不写进判据**

> **失效条件**：我哪天又开始单方面加，或者把事件塞进判据里——**那就是 828 行回来的时候。**

### 记牢的两个数据点

- **第六课崩掉，是因为文档复杂化，不是因为文档不够。**
  那个 A1 烂题的根源是 `模板.md` 里**一行短指示**（"如果有坑，加一句提示：它会报错——这行注释保留，并写上报错原文"）。
  **短句 + 零上下文的读者 = 被用反。** 而当时三个检查全绿——**文档越复杂，越没人看得出它自己病了。**
- **前五课没有这套文档，靠上下文也做出来了。**
