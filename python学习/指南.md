# 指南

> **第一个读这个。**
> 它只装两样东西：**阅读链** + **一条铁律**。

---

## 一、阅读链

### 平时课

```
指南.md（本文件）
  ↓
AI备忘.md                      ← 先看最后一条：上一次干到哪、定了什么
  ↓
学习路线.md                     ← 这是第几项、要覆盖哪一块
  ↓
知识点拟定.md                   ← 这一课的知识点从哪来、怎么才能教清楚
  ↓
参考格式\课程参考格式.md         ← 正文长什么样
  ↓
出题.md                        ← 题怎么想出来
  ↓
生成（写正文）
  ↓
复核.ps1                       ← 跑题 ↔ 我写下的答案；**绿的才写进答案**
```

### 复习课

```
指南.md → AI备忘.md → 学习路线.md → 知识点拟定.md
        → 参考格式\复习参考格式.md → 出题.md → 生成 → 复核.ps1
```

### 真题卷

```
指南.md → AI备忘.md → 学习路线.md → 知识点拟定.md
        → 参考格式\真题参考格式.md → 出题.md → 生成 → 复核.ps1
```

> **每份文档的开头都写着"读它之前先读什么"**；对不上就以那行为准。
