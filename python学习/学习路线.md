# 学习路线

> **目的：极其熟练地掌握 Python —— 能调控 AI、面对考试、独立开发项目。**
>
> **这份文档是半动态的，只有一件事会让它变：某一项冻结之后，把它的勾打上。**
> 其余任何时候都不动——**路线一旦定下就不再改。**

---

## 路线（按时间顺序）

- [x] **第一课** ｜ `print` / 注释 / 缩进 / 引号 / 变量 / 运行方式 —— 让程序跑起来、能打印
- [x] **第二课** ｜ `input` / `int` `float` `str` 转换 / 算术 / 复数 / f-string（含 `.2f`）—— 读入数据并算出来
- [x] **第三课** ｜ 列表 / 索引（正负）/ 切片（步长、反转）/ 增删改查 / 排序 / `b = a` 引用与复制 —— 把一堆数据装起来、取一段
- [x] **复习一** ｜ 覆盖 第一 ~ 三课 —— 把前三课再捞一遍
- [x] **第四课** ｜ 比较运算符 / `True` `False` `None` / 真值判断 / `if` `elif` `else` / `and` `or` `not` / 优先级 —— 让程序做判断
- [x] **真题实战一** ｜ 覆盖 第一 ~ 四课 —— 限时做一套
- [x] **第五课** ｜ `for` / `range`（三种形态）/ 遍历 / 累加器 / 计数器 / 打擂法 / `while` / 死循环 / `break` `continue` —— 让程序重复做
- [ ] **第六课** ｜ 字符串不可变 / 返回新串 / `find` `index` `count` `startswith` `endswith` / `replace` `upper` `lower` `strip` / 链式调用 / `split` `join` / `isdigit` `isalpha` `isspace` `isalnum` / `format()` / `ord` `chr` / `bin` `oct` `hex` / 转义字符 / 原始字符串 / 三引号 / 字符串乘法 —— 切分和处理文本
- [ ] **复习二** ｜ 覆盖 第一 ~ 六课 —— 把六课再捞一遍
- [ ] **真题实战二** ｜ 覆盖 第一 ~ 六课 —— 限时做一套
- [ ] **第七课** ｜ 字典（建取改删、遍历、`get`）/ 集合（去重、交并差）/ 元组（不可变、解包）—— 按名字存数据、去重
- [ ] **真题实战三** ｜ 整套限时卷（120 分钟）—— 第一次做完整卷
- [ ] **第八课** ｜ `def` / 参数（位置、默认、关键字）/ 返回值 / `return` 与 `print` 的区别 / 作用域 / 递归 —— 把代码拆开复用
- [ ] **第九课** ｜ `open` / `with` / 读（`read` `readline` `readlines` 逐行）/ 写（`w` `a`）/ 编码 / CSV —— 读写外部文件
- [ ] **复习三** ｜ 覆盖 第一 ~ 九课 —— 再捞一遍
- [ ] **真题实战四** ｜ 覆盖 第一 ~ 九课 —— 限时做一套
- [ ] **第十课** ｜ `try` `except` / 常见异常类型 / `else` `finally` / 主动抛错 —— 让程序不崩
- [ ] **第十一课** ｜ 列表推导 / 条件推导 / 字典推导 / 集合推导 / 嵌套 —— 一行写出"循环 + 筛选"
- [ ] **真题实战五** ｜ 覆盖 第一 ~ 十一课 —— 限时做一套
- [ ] **第十二课** ｜ `import` 的几种写法 / `random` / `time` / `math` / `turtle` —— 用标准库
- [ ] **复习四** ｜ 覆盖 第一 ~ 十二课 —— 再捞一遍
- [ ] **第十三课** ｜ `pip install` / `jieba` / `PyInstaller` 打包 —— 装并用第三方库
- [ ] **真题实战六** ｜ 覆盖 第一 ~ 十三课 —— 限时做一套
- [ ] **第十四课** ｜ 模块 / `if __name__ == "__main__"` / 包 / 类与对象（`class`、`__init__`、方法、继承）—— 拆成多个文件、写成对象
- [ ] **第十五课** ｜ NumPy：数组 / 向量化运算 / 切片与索引 —— 用数组代替循环
