## 2. 运行 Python 的两种方式

### 方式 A：交互模式（临时试一句）

在终端里直接输入：

```powershell
python
```

你会看到出现 `>>>`，这叫 **REPL**，可以一行一行地试：

```python
>>> 1 + 2
3
>>> print("你好")
你好
```

想退出，输入：

```python
>>> exit()
```

或者按 `Ctrl + Z` 然后回车。

**REPL 用来试小东西，但它不会保存。** 关掉就没了。

### 方式 B：运行文件（★ 主要用这个）

1. 在 `code` 文件夹里新建一个文件，叫 `hello.py`
   （如果 Windows 不显示扩展名，在资源管理器「查看」里勾上「文件扩展名」，**这一步很重要**，不然会变成 `hello.py.txt`）
2. 用 VS Code 打开它，写上：

```python
print("Hello, Python")
```

3. 保存（`Ctrl + S`）
4. 回终端，确认你在 `code` 文件夹里，输入：

```powershell
python hello.py
```

**你应该看到：**

```
Hello, Python
```

🎉 恭喜，你跑通了第一个 Python 程序。

> **约定**：以后说"运行 `xxx.py`"，就是指在终端里 `python xxx.py`。**不要用鼠标双击 .py 文件**，那样窗口会一闪而过，看不到结果。

## 3. print —— 让程序说话

`print` 是"打印"，但它不是真的打印到纸上，而是**把内容显示到屏幕上**。

### 引号

文字（专业叫**字符串**）必须用引号包起来：

```python
print("你好")
print('你好')
```

**单引号和双引号都行，效果一样。** 但必须**成对**。

```python
print("他说：'早上好'")     # 外面双引号，里面单引号，可以
print('他说："早上好"')     # 外面单引号，里面双引号，可以
```

### ⚠️ 中文引号是致命的坑

```python
print(“你好”)      # ❌ 错误！这是中文全角引号
print("你好")      # ✅ 正确
```

**写代码时输入法一定要切到英文半角。** 这是中文用户最常见的报错来源。

### 一次输出多个内容

```python
print("我叫", "小明")
```

输出：

```
我叫 小明
```

**注意中间有个空格** —— 用逗号隔开时，Python 会自动加一个空格。这是 Python 和 C# 很不一样的地方。

### 输出一个空行

```python
print()
```

## 4. 变量 —— 给数据起个名字

```python
name = "小明"
age = 18
```

**逐字读作**：把 `"小明"` 这个值，存进名为 `name` 的盒子。

和 C# 的区别：

```csharp
// C# 要写类型
string name = "小明";
int age = 18;
```

```python
# Python 不用写类型，Python 自己会认
name = "小明"
age = 18
```

**规则**：

- 变量名只能用**字母、数字、下划线**，不能有空格
- 不能以数字开头（`1name` ❌，`name1` ✅）
- **区分大小写**：`Name` 和 `name` 是两个不同的变量
- 命名习惯：用小写字母 + 下划线，如 `my_age`、`user_name`

### 把变量输出出来

```python
name = "小明"
age = 18

print(name)              # 输出：小明
print(name, age)         # 输出：小明 18
print("我叫", name)      # 输出：我叫 小明
print("姓名：", name, "年龄：", age)   # 输出：姓名： 小明 年龄： 18
```

**重点**：`print(name)` 输出的是变量的**值**；`print("name")` 输出的是**这四个字母**。引号决定了这一点，非常容易搞混。

## 5. 注释 —— 写给人看的话

`#` 号后面的内容，Python **完全无视**。

```python
# 这一行是注释，不会被执行

name = "小明"     # 也可以写在代码后面

# print("这行被注释掉了，不会输出")
```

**用途**：

- 记录这行代码是干什么的
- 临时屏蔽某行代码（调试时很有用）

**快捷键**：VS Code 里选中几行，按 `Ctrl + /`，可以批量加/去注释。

## 6. 缩进 —— Python 的命根子

这一节最重要，请慢慢看。

在 C# 里，缩进只是为了好看，代码块靠 `{}` 划分：

```csharp
if (age > 18) {
    Console.WriteLine("成年了");
}
```

在 Python 里，**没有 `{}`，代码块完全靠缩进划分**：

```python
age = 20

if age > 18:
    print("成年了")
```

**三个必须记住的点：**

1. `if` 那一行的末尾，**必须有英文冒号 `:`** （不是中文冒号 `：`）
2. 冒号下面的一行，**必须缩进**（比上一行往右缩）
3. 缩进用 **4 个空格**（按一次 Tab 键，VS Code 默认会插入 4 个空格）

**同一个代码块里，缩进必须完全一致。** 有的行缩进 4 个空格、有的缩进 3 个，Python 会直接报错。

```python
if age > 18:
    print("第一行")
    print("第二行")     # ✅ 缩进一致，属于同一个 if

print("这行不缩进")      # 不属于 if，无论如何都会执行
```

**现在只需要理解"缩进决定归属"这件事**，`if` 的用法下一课细讲。

## 7. 常见报错对照表（收藏这一节）

报错**不是失败，是 Python 在告诉你哪里错了**。看懂报错是最重要的技能。

| 报错信息 | 原因 | 怎么改 |
|---|---|---|
| `SyntaxError: invalid syntax` | 语法错误，常见于少括号、少冒号 | 看报错指的行，检查符号 |
| `SyntaxError: unterminated string literal` | 引号没闭合 | 补上右边的引号 |
| `SyntaxError: invalid character '“'` | **用了中文引号/中文标点** | 换成英文半角 |
| `IndentationError: expected an indented block` | 冒号后面没缩进 | 下一行缩进 4 空格 |
| `IndentationError: unexpected indent` | 不该缩进的地方缩进了 | 把这行的缩进去掉 |
| `NameError: name 'xxx' is not defined` | 用了没定义过的变量，或变量名拼错 | 检查拼写 |

**读报错的顺序**（非常重要）：

1. 看**最后一行** —— 那是错误的类型和原因
2. 往上看 `File "xxx.py", line 3` —— 那是出错的行号
3. 去 VS Code 里跳到那一行检查

**注意**：Python 遇到第一个语法错误就会停下来，所以**修好一个错误后可能又冒出下一个，这是正常的**，一个一个修。
