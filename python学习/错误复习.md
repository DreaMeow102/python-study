# 错误复习

> **只有错。** 编号 ｜ 知识点 ｜ 错在哪。别的什么都没有。
> 要细节（代码原文、当时怎么想的、怎么解决的）→ `旧文档\易错点台账.md`
>
> 操作权归 AI；**只记录，不许复杂化**。按课的时间顺序排。

| # | 知识点 | 错在哪 |
|---|---|---|
| **1** | 第一课 · `print` 逗号 | 用逗号分隔 → 自动加空格，输出多出空格 |
| **2** | 第一课 · 中文引号/标点 | 代码里用了中文引号 → `SyntaxError` |
| **3** | 第一课 · 内置函数名 | 拿 `int` / `sum` 当变量名 → 之后调用就炸 |
| **4** | 第二课 · `//` 向下取整 | 以为 `//` 是"砍掉小数"，其实负数向下（`-7 // 2` = `-4`） |
| **5** | 第二课 · 转换要**接住** | 写了 `float(a)` 却没赋值 → 结果被丢掉，`a` 没变 |
| **6** | 第二课 · 转换别滥加 | 不确定就包一层 `int()` / `float()` → 多余 |
| **7** | 第三课 · 切片含头不含尾 | `nums[1:4]` 以为含下标 4 |
| **8** | 第三课 · 步长 | 记成"隔 N 个"，其实是隔 **N−1** 个 |
| **9** | 第三课 · `insert` 的位置 | 想插到**开头**，写了 `insert(3, x)` → 加到了末尾 |
| **10** | 第三课 · `b = a` 不是复制 | 改 `b` 把 `a` 也改了 |
| **11** | 第三课 · 方法名没背牢 | 想不起 `append`；不确定 `sort` 的方向 |
| **12** | 第四课 · `and` / `or` 返回规则 | **说反了** |
| **13** | 第四课 · `if x == True` | 冗余写法，直接 `if x:` 就够 |
| **14** | 第四课 · `=` 和 `==` | `if a = 5:` —— **犯过两次** |
| **15** | 第四课 · 引号看漏 | `bool("")` 与 `bool("0")`：只看到 `0`、没看到引号，答成两个 `False` |
| **16** | 第五课 · 累加要写回 | 写了 `a + 1` 没写回 → 算完就丢 |
| **17** | 第五课 · `range()` 只吃整数 | `range("hello")` |
| **18** | 第五课 · 边界和起点配套 | `a = 0` 配 `while a <= 5` → 多跑一次 |
| **19** | 交付 · 自检要逐行比 | 漏了一行输出没对照 |
| **20** | 交付 · 跑一遍是提交前的动作 | 有报错行没注释掉 → 整个文件跑不起来 |
