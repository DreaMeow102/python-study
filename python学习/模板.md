# 模板（出题 / 写答案 / 批改 的格式）

> **为什么要有这份文档**：学生会**跟不同的教师 AI 合作**。格式不写死，就**一代一个样**。
>
> **这不是预测，已经发生了：**
>
> | 漂移项 | 规范写的 | 实际 |
> |---|---|---|
> | 批改文件名 | `第X课-作业批改.md` | 前三课对；**第四、五课叫 `-批改.md`** ❌ |
> | 验证标签 | 规则一：参考答案必须有**【自检】** | 第二~五课答案 **0 个【自检】**，改叫"实测/实际输出"；第六课又回到 25 个【自检】 ❌ |
>
> **规范写在文档里照样会漂。所以这里给的是"照着抄就对的骨架"。**
>
> **用法**：出题前读 §二，写答案前读 §三，批改前读 §四。

---

# 一、命名

**以 `约定.md` 附 A 为准。** 速查：

| 类型 | 命名 |
|---|---|
| 课次文件夹 | `第一课`、`第二课`…… |
| 复习文件夹 | `复习一`、`复习二`…… |
| 正文 | `第X课-正文.md` / `复习X-正文.md` |
| 批改 | `第X课-作业批改.md` |
| 答案 | `第X课-参考答案.md` / `复习X-参考答案.md` |
| 学生代码 | `第X课\code\` 下面 |

**题目编号**：`A1` `A2` … `B1` …（组大写字母 + 序号）；特殊题用 `I1` `I2` `I3`。
**学生文件名**：和题号一致的小写，`a1.py` `b2.py` `i1.py`。

---

# 二、正文模板（`第X课-正文.md`）

```markdown
# 第X课：<一句话主题>

> **题量**：N 题（A x + B x + … + 特殊题 3）
> **预计时间**：N~N 小时（含做题）
> **覆盖**：二级大纲 **<哪几个板块>**
>
> <如果是收尾课，加一句：这是第 N 段的最后一格。>

## 怎么用这一课

结构照旧：**理论（短）→ 例题 → ★ 对应习题**。
**每题标了类别**：【新】必须跑通 /【复习】跑一遍确认。

| 题 | 是什么 | 规则 |
|---|---|---|
| **I1** | **读官方文档自学**（教师不讲） | 规则七 |
| **I2** | **改错题**（给能跑但结果不对的代码） | 规则八 |
| **I3** | **读代码**（说出它在做什么、为什么） | 读代码（约定 §四） |

**代码写在 `<课次>\code\`，文件名用 `a1.py` / `b1.py` / … / `i3.py`。**

### 正文的几条硬要求

| # | 要求 | 为什么 |
|---|---|---|
| 1 | **每个知识点后面必须跟着习题** | "第一课做得很好，每个例子都有习题"——这个模式是对的 |
| 2 | **理论要短，讲完立刻动手** | "代码的学习必须靠敲" |
| 3 | **只用本课及之前课学过的语法** | 规则二（不超纲，优先级最高） |
| 4 | **给真实输出，不给"应该会输出"** | 规则一 |
| 5 | **每题标【新】或【复习】** | 验收方式不同（约定 §四） |
| 6 | **难题给提示，提示放可折叠区** | 先让学生自己想 |
| 7 | **题目要串联前面学过的东西** | 综合题不是超纲，是复习 |

# 六、每次出题/批改前的自查（贴墙上）

```
出题前：
□ 查过 进度.md §2 已考知识点清单了吗？（规则三）
□ 这题用的语法都在"已覆盖"范围内吗？（规则二）
□ 这个知识点有 ID 吗？没有 → 先加进 进度.md §2
□ 本课有 I1（读文档）/ I2（改错）/ I3（读代码）吗？（第四课起）

批改后：
□ 走完 约定.md 附 D 的 11 项收尾清单了吗？
□ 每个失分点标【性质】了吗？
□ 要归因"概念没掌握"的地方，问过学生了吗？
□ 新踩的坑进 语法速查 §三 了吗（带【归属】ID）？
```
