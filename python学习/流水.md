## 专题：`bool("0")` 的归因更正（#48 的由来）

> **这是本次重构最重要的一条副产品：教师把一个错误归错了因，学生纠正了它。**

**教师的原始批改**（`真题实战一-批改.md` §三 / §八）：
> "你答 C（`False 和 False`），正确是 A…… **真值判断没内化**。
> 而你自己在第四课 a3 里写过这样一句话…… **你自己的规律能推出正确答案——但你没用上。**"
> → 归因为**提取失败 / 概念问题**。

**学生的更正（原话）**：
> "至于那个 bool 的错误……因为我是**下意识看到的 0 没注意引号**，粗心导致的，
> 我能承认这次错误，**但我认为我的知识总结没啥问题**。"
>
> "**恰恰是因为知识总结没啥问题**，0 本身输出就是 false，但字符串输出是 true——
> **这也是人才会犯的错误，AI 很注意双引号在不在。**"

**为什么学生的解释成立**（教师复核后的证据）：

| 证据 | 说明 |
|---|---|
| 同一张卷子第 7 题 `5 and 0` → **答对** | 说明"`0` 是假"他没问题 |
| 他答的 `False 和 False` | **正好是把他在 a3 写的规律用在 `bool(0)` 上的结果**——答案和他的规则自洽，只是输入看错了 |
| 若是概念没掌握 | 更可能答成 `True 和 False`（把"非空字符串都是真"搞反）——他没搞反 |

**结论**：**教师的归因是错的，已改。** 补救不是"复习真值判断"，是**"读题时把引号念出来"**。

**学生的这句话值得单独存档**：
> **"恰恰因为知识总结没问题，才会犯这个错。"**
>
> ——**规则越准确、越通用，套错输入的时候答案就越一致地错。**
> 而 AI 不会犯这种错（它不会漏看一个引号），**所以这类错误只能靠人自己的检查动作兜住。**

**这是学生第 5 次纠正教师**（前四次：`//` 的定义、步长措辞歧义、出题重复、真题超纲）。

> "这就像是你会中文和会英文的区别，**计算机语言在我眼里是不同的东西**，我认为我就该重新学。"

**结论**：**会 `$"{x:F2}"` 不等于会 f-string。** 知识要在**新语言里重新长一遍**，删掉中间步骤 = 抽掉地基。

   知道对应关系能帮记住格式符，**但不等于可以少练一遍**

# 六、几件值得单独存档的经过

## 6.1 规则三的由来：第二课的病（出题人自己的责任）

**第二课的毛病是机械对应**：讲一个点 → 配一道题 → 下一个点 → 再配一道题。
结果是 20 道互不相干的小题，还互相重复（B2 / B3 / B5）。

**后果链**：重复的题 → 无聊 → 敷衍（硬编码一个答案交差）→ **被误判成"态度问题"**。

**结论（学生的话推出来的）**：
> **"简单不是不能有，主要是重复性。"**
> **"过度的重复有时候会令人疲惫。"**

**所以**：~~宁多勿难~~ → **宁准勿多。每点一题。**
**一道重复题的伤害不是浪费时间——是它会诱发敷衍，把"没练"伪装成"练了"。**
**责任在设计，不在做题的人。**

## 6.2 规则七的判分标准为什么改松（第五课 F1，2.0 → 3.5）

**教师初判**：F1 得 2.0/5。理由：没写代码、Q3 答错、Q5 没答、没贴文档原文。

**学生提出"判分太严格"——教师重读后，学生是对的。**

**学生原话**：
> "**还是保留**（我没说这种题型不行，而是**判分或者判错太过严格**，仅此而已，这种题型保留是没问题的。）"
>
> "这毕竟是**概念理解题**……大部分实际情况，`range` 和 `while` 的使用，很少会直接套在列表里或者直接打印。"

**教师当时把"输出的类似数组的简写"当成了含糊其辞**，其实它答对了：
`print(range(5))` 输出 `range(0, 5)`，**而 `range(0, 5)` 就是 `[0,1,2,3,4]` 的紧凑写法**。
**教师只认字面量，所以判错了。**

**改后的标准**：

| | 旧标准 | **新标准** |
|---|---|---|
| 看什么 | 交付齐不齐 | **理解对不对** |
| 强制写代码 | ✅ | ❌ 不强制 |
| 强制贴文档原文 | ✅ | ❌ 不强制 |
| 没答全 | 不给分 | **按理解程度部分给分** |

> **保留的软提醒（不扣分）**：Q3 那次是**想错了**，说明脑子里的模型有错——**这个靠刷题兜住。**

**并存档**：初判 2.0 的意见保留，**为了留痕**——以后回头看，能看见标准是怎么变的、为什么变。

## 6.3 学生发现出题人错误的四次（这是真正长出来的能力）

| # | 时间 | 学生发现了什么 |
|---|---|---|
| 1 | 第二课 | 教师正文里 `//` 的定义**写错了**（学生提问触发） |
| 2 | 第三课 c3 | 教师正文对**步长**的措辞**有歧义**（"每 2 个取 1 个"） |
| 3 | 第二课之后 | **出题重复**（B2/B3/B5 是同一个知识点的重复） |
| 4 | 真题实战一 | **卷子超纲**——操作题第 2 题用了第五课的 `for`，而卷子声明只覆盖第 1~4 课 |
| **5** | **真题实战一之后** | **批改的归因错了**（`bool("0")` 判成"概念没内化"，实为看漏引号） |

> **第四次的细节**：学生在卷子上直接写——
> `(此题超纲，建议按照0分算，1到4课没有讲循环)`
>
> **他没做那道题，但写下了理由**——这正是规则五（跳题给理由）要求的。
> **而卷子按他的要求原样保留、不改**（他说"超纲就超纲，这确实没法，但卷子设计没啥问题，保留就好"）。
>
> **这已经是第五次了。而这个能力——"验证出题人，而不是相信出题人"——才是真正在长出来的东西。**

## 6.4 规则十二（提交即冻结）的由来

**学生原话**：
> "不用了。作业留痕。我既然说了提交，那就说明我准备以后面对这个刺眼错误的决定，
> 以后我能看见这个错误——**只要我说了提交打分，就说明我这边做好了「冻结」的决定**，
> **你也没见过学生能后面改卷子分数的吧？**"

**教师的判断**：**这个类比是准的。事后改卷子 = 事后改分，是荒唐的。**

**配套调整**：既然提交后不能改，"检查"（`跑一遍`）就必须发生在**提交之前**。
第四课 `b4.py` 扣的 3 分，就是**按提交时的状态**算的——**这才是公平的位置。**
