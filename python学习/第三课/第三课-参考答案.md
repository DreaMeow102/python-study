## B 组 · 索引

### B1 · 正索引 【新】

```python
fruits = ["苹果", "香蕉", "橘子", "葡萄", "西瓜"]
print(fruits[0])
print(fruits[2])
```

**实际输出**

```
苹果
橘子
```

> 第 1 个 → `[0]`；第 3 个 → `[2]`。**索引比"第几个"少 1。**

---

### B2 · 负索引 【新】

```python
fruits = ["苹果", "香蕉", "橘子", "葡萄", "西瓜"]
print(fruits[-1])
print(fruits[-2])
print(fruits[-5])
```

**实际输出**

```
西瓜
葡萄
苹果
```

> 5 个元素，负索引范围是 `-1`（最后一个）到 `-5`（第一个）。
> **`-1` 永远是最后一个**，不用先算 `len()`。

---

### B3 · 故意越界 【新】

```python
fruits = ["苹果", "香蕉", "橘子"]
print(fruits[3])
print(fruits[-4])
```

**实际输出**

```
IndexError: list index out of range
IndexError: list index out of range
```

> 3 个元素：正索引只能用 `0~2`，负索引只能用 `-1~-3`。
> **`3` 和 `-4` 都刚好超出一步**，报的是同一个错。
>
> 第二行其实在第一个错误处就停了——Python **遇到第一个错就中断**。
> 想看第二个错，得先把第一行注释掉。这也是为什么 B3 题面说"再试一次"。

## C 组 · 切片

> **C 组是本课重点。** 下面每题都写清"为什么是这个结果"。

### C1 · 基本切片 【新】

```python
nums = [10, 20, 30, 40, 50]
print(nums[1:4])
```

**实际输出**

```
[20, 30, 40]
```

> **含头不含尾**：取下标 `1, 2, 3`，**不取下标 4**。
> 元素个数 = `4 - 1 = 3` 个 ✅

---

### C2 · 三种省略写法 【新】

```python
nums = [10, 20, 30, 40, 50]
print(nums[:3])
print(nums[2:])
print(nums[:])
```

**实际输出**

```
[10, 20, 30]
[30, 40, 50]
[10, 20, 30, 40, 50]
```

| 写法 | 意思 |
|---|---|
| `nums[:3]` | 从**头**取到下标 3 之前 |
| `nums[2:]` | 从下标 2 取到**尾** |
| `nums[:]` | 整个列表的**副本** |

---

### C3 · 步长 【新】

```python
nums = [10, 20, 30, 40, 50]
print(nums[::2])
print(nums[1::2])
```

**实际输出**

```
[10, 30, 50]
[20, 40]
```

> - `nums[::2]` → 下标 `0, 2, 4` → `10, 30, 50`
> - `nums[1::2]` → 下标 `1, 3` → `20, 40`
>
> **两个冒号**：第一个冒号前后是 start/stop（这里都省略），第二个冒号后面才是步长。

---

### C4 · 反转 【新】

```python
nums = [10, 20, 30, 40, 50]
print(nums[::-1])
```

**实际输出**

```
[50, 40, 30, 20, 10]
```

> **`[::-1]` 是 Python 反转列表的标准写法。** 步长为负就是倒着走。

---

### C5 · 切片不影响原列表 【新】

```python
nums = [10, 20, 30, 40, 50]
part = nums[1:3]
part[0] = 999

print("part =", part)
print("nums =", nums)
```

**实际输出**

```
part = [999, 30]
nums = [10, 20, 30, 40, 50]
```

> **`nums` 一点没变。**
> 因为切片**复制出了一份新列表**——`part` 和 `nums` 是两个独立的东西。
>
> 这一条理解透了，第 6 节的陷阱就自然懂了。

## D 组 · 修改与增删

### D1 · 改元素 【新】

```python
fruits = ["苹果", "香蕉", "橘子"]
fruits[1] = "葡萄"
print(fruits)
```

**实际输出**

```
['苹果', '葡萄', '橘子']
```

> "第 2 个" → 索引 `1`。

---

### D2 · 加东西 【新】

```python
fruits = ["苹果", "香蕉"]
fruits.append("橘子")
print(fruits)

fruits.insert(0, "西瓜")
print(fruits)
```

**实际输出**

```
['苹果', '香蕉', '橘子']
['西瓜', '苹果', '香蕉', '橘子']
```

> - `append` 加**末尾**
> - `insert(下标, 值)` 插到**指定位置**，后面的自动后移
>
> **注意这是"方法"**：列表写在**点前面**（`fruits.append(...)`），
> 不是写在括号里（`append(fruits, ...)` ❌）。

---

### D3 · 删东西 【新】

```python
fruits = ["苹果", "香蕉", "橘子", "葡萄"]

fruits.remove("香蕉")
print(fruits)

last = fruits.pop()
print("pop 出来的是:", last)
print(fruits)

del fruits[0]
print(fruits)
```

**实际输出**

```
['苹果', '橘子', '葡萄']
pop 出来的是: 葡萄
['苹果', '橘子']
['橘子']
```

> **重点在 `pop()`**：它一边删，一边**把删掉的东西交给你**。
> 所以 `last` 里就是 `葡萄`。`remove` 和 `del` 都不返回东西。

---

### E2 · 两种排序 【新】

```python
nums = [3, 1, 4, 1, 5]

print("sorted 返回新列表:", sorted(nums))
print("原来的 nums 没变:", nums)

nums.sort()
print("sort 原地排完:", nums)
```

**实际输出**

```
sorted 返回新列表: [1, 1, 3, 4, 5]
原来的 nums 没变: [3, 1, 4, 1, 5]
sort 原地排完: [1, 1, 3, 4, 5]
```

> **第 2 行是这题的关键**：证明 `sorted()` **没有动原列表**。
>
> | | 类型 | 改原列表吗 | 返回什么 |
> |---|---|---|---|
> | `sorted(nums)` | 函数 | ❌ 不改 | 新列表 |
> | `nums.sort()` | 方法 | ✅ 改 | 不返回 |
>
> **这和你已经见过的两组东西是同一个区别**：
> - `nums[1:3]`（产生新的） vs `fruits[1] = "葡萄"`（改原来的）
> - `sorted(nums)`（产生新的） vs `nums.sort()`（改原来的）

## F 组 · 陷阱

### F1 · 亲手制造这个 bug 【新】

```python
a = [1, 2, 3]
b = a
b.append(4)

print("a =", a)
print("b =", b)
```

**实际输出**

```
a = [1, 2, 3, 4]
b = [1, 2, 3, 4]
```

> **只对 `b` 做了 `append`，`a` 也跟着变了。**
>
> 因为 `b = a` **没有复制任何东西**——它只是给同一个列表又起了个名字：
>
> ```
>     a ──┐
>         ├──→  [1, 2, 3]
>     b ──┘
> ```
>
> **这题的目的不是"做对"，是"亲眼看到 `a` 被改了"。** 见过一次，以后就不会被它坑。

---

### F2 · 改成真复制 【新】

**改动只有一行**：`b = a` → `b = a[:]`

```python
a = [1, 2, 3]
b = a[:]
b.append(4)

print("a =", a)
print("b =", b)
```

**实际输出**

```
a = [1, 2, 3]
b = [1, 2, 3, 4]
```

> **`a[:]` 是切片，切片会做一份新的。**
>
> | 写法 | 效果 |
> |---|---|
> | `b = a` | 同一个列表，**两个名字** |
> | `b = a[:]` | **两个独立的列表** |
>
> 这和 C5 是同一个道理的两面：
> - C5：切片**产生新的** → 改新的不影响旧的
> - F1：直接赋值**没产生新的** → 改一个另一个也变

## 第 7 节 · 关卡

### 关卡 1 · 购物结算

```python
prices = [19.9, 5.5, 32.0, 8.8]

print(f"共 {len(prices)} 件商品")
print(f"总价 {sum(prices):.2f} 元")
print(f"最贵 {max(prices):.2f} 元")
print(f"最便宜 {min(prices):.2f} 元")
print(f"平均 {sum(prices) / len(prices):.2f} 元")
```

**实际输出**

```
共 4 件商品
总价 66.20 元
最贵 32.00 元
最便宜 5.50 元
平均 16.55 元
```

> **注意 `f"{sum(prices):.2f}"` 这个写法**：
> `{}` 里可以放**整个函数调用**，后面的 `:` 再对它做格式化。
> 平均价那行更复杂一点：`f"{sum(prices) / len(prices):.2f}"`——先算除法，再格式化。

### 关卡 2 · 成绩分析

```python
scores = [88, 92, 75, 96, 81, 100, 67]

desc = sorted(scores)[::-1]

print(f"从高到低：{desc}")
print(f"前三名：{desc[:3]}")
print(f"去掉最高最低后：{desc[1:-1]}")
print(f"共 {len(scores)} 人，平均 {sum(scores) / len(scores):.2f} 分")
```

**实际输出**

```
从高到低：[100, 96, 92, 88, 81, 75, 67]
前三名：[100, 96, 92]
去掉最高最低后：[96, 92, 88, 81, 75]
共 7 人，平均 85.57 分
```

**逐步拆解：**

| 步骤 | 结果 |
|---|---|
| `sorted(scores)` | `[67, 75, 81, 88, 92, 96, 100]` 升序 |
| `[::-1]` 反转 | `[100, 96, 92, 88, 81, 75, 67]` 从高到低 |
| `desc[:3]` | 前三个 → `[100, 96, 92]` |
| `desc[1:-1]` | 跳过第 1 个、不取最后 1 个 → `[96, 92, 88, 81, 75]` |

> **`desc[1:-1]` 为什么能去掉头尾？**
> - `start=1` → 从下标 1 开始（跳过下标 0，就是最高的 100）
> - `stop=-1` → 取到**最后一个之前**为止（不取最后一个，就是最低的 67）
>
> **正索引和负索引可以混着用**，这是切片灵活的地方。
