## 三、针对你的问题

### 1. d4：`float(a)` 的返回值被丢掉了 ★ 本课最重要

你的代码：

```python
a = input("请输入第一个价格")
float(a)          # ← 这一行什么也没做
b = input("请输入第二个价格")
float(b)          # ← 同样
```

**`float(a)` 不会改变 `a`。** 它只是**算出一个新的值然后交给你**——而你**没接住**。

所以后面 `c.append(a)` 的时候，`a` **还是字符串**。你最后是靠 `float(c[0])` 在 f-string 里现场补救的，所以**结果是对的**——但根因没解决。

**正确写法：**

```python
a = float(input("请输入第一个价格"))     # 直接接住
```

**为什么这一处特别值得说——因为它和你 E2 做对的东西是同一个道理：**

| 写法 | 改原来的吗 | 你需要做什么 |
|---|---|---|
| `float(a)` | ❌ **不改** `a` | **必须接住**：`a = float(a)` |
| `sorted(nums)` | ❌ **不改** `nums` | 接住返回值 |
| `nums.sort()` | ✅ **改** `nums` | 不用接 |

**你在 E2 里正确区分了 `sorted` 和 `sort`，但 `float(a)` 这里又踩了同一个坑。**

这不是"没学会"，是**同一个知识点还没跨单元迁移**——而这一步恰恰是最难的。所以给你一条能一口气吃下的规律：

### ★ 一条值得记住的规律：函数 vs 方法

| | 例子 | 行为 |
|---|---|---|
| **函数** | `float(x)` `int(x)` `str(x)` `sorted(x)` `len(x)` `sum(x)` `max(x)` | **不改参数**，返回新东西，**你必须接住** |
| **方法** | `x.append()` `x.insert()` `x.remove()` `x.sort()` | **改 x 自己**，通常**不返回东西** |
| 方法中的例外 | `x.pop()` | 既**改** x，**又返回**被删的那个 |

**记住这张表，d4 这种错就不会再犯。**

### 2. d2：`insert` 的位置用错了

你的代码：

```python
shuiGuo = ["Apple","Banana"]
shuiGuo.append("Orange")
print (shuiGuo)                    # ['Apple', 'Banana', 'Orange']

shuiGuo.insert(3,"Watermalon")     # ← 题目要求"在开头加"
print (shuiGuo)                    # ['Apple', 'Banana', 'Orange', 'Watermalon']
```

**题目要求"用 `insert` 在开头加"**，应该是：

```python
shuiGuo.insert(0, "Watermalon")    # → ['Watermalon', 'Apple', 'Banana', 'Orange']
```

**`insert(下标, 值)` 的准确含义**：把值插到**那个下标的位置上**，原来在那个位置的元素及后面的**全部往后挪一位**。

所以在一个 3 个元素的列表上：

| 写法 | 效果 |
|---|---|
| `insert(0, x)` | 插到**最前面** |
| `insert(3, x)` | 3 个元素的列表，下标 3 = **末尾**（等于 `append`） |
| `insert(len(a), x)` | 也是**末尾** |

你自己也写了"容易用错 insert 的用法。以后会注意"——**判断是对的**。

我原文写的是：

> `nums[::2]` = 从头到尾，**每 2 个取 1 个** → 下标 `0, 2, 4`

问题在于：**"每 2 个取 1 个"这句话，能读成两种意思：**

- "步长 2"（每 2 个位置取 1 个）
- "跳过 2 个"（那其实是步长 3）

而你题目里看到的"**每隔一个取一个**"才是**没有歧义**的说法。

**实测验证（我跑过）：**

```
a[::2] = [0, 2, 4, 6, 8]   取的下标 0,2,4,6,8  → 中间隔了 1 个
a[::3] = [0, 3, 6, 9]      取的下标 0,3,6,9    → 中间隔了 2 个
```

**规律：步长 N = 每隔 (N-1) 个取一个。**

**已修教材**：正文 3.3 那两行改正，并新增了一张"步长 ↔ 隔几个"的换算表，还写明了"为什么'每 2 个取 1 个'这种说法要避免"。
