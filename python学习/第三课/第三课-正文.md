# 第 1 节 · 什么是列表

## 1.1 创建列表

用**方括号 `[]`**，元素之间用**逗号**隔开：

```python
fruits = ["苹果", "香蕉", "橘子"]
print(fruits)
```

实际输出：

```
['苹果', '香蕉', '橘子']
```

**注意**：`print` 一个列表时，Python 会**带上方括号和引号**原样显示。这和 `print("苹果")` 直接输出 `苹果` 不一样——**前者显示的是"列表本身的样子"**。

空列表：

```python
empty = []
print(empty)      # []
```

## 1.2 列表里能装什么

**什么都能装，而且可以混着装**：

```python
info = ["YN4", 24, 1.75, True]
print(info)
```

实际输出：

```
['YN4', 24, 1.75, True]
```

字符串、整数、浮点、布尔值，全放一个列表里完全没问题。

> **这就是第二课"动态类型"的延伸**：Python 不检查列表里装的是不是同一种东西。

## 1.3 `len()` —— 数一数有几个

`len()` 是**内置函数**，返回列表里有几个元素：

```python
fruits = ["苹果", "香蕉", "橘子"]
print(len(fruits))
```

实际输出：

```
3
```

> `len` 是 **len**gth（长度）的缩写。
> 它和第二课的 `int()` / `float()` / `str()` 是同一类东西——Python 自带的函数。

# 第 2 节 · 索引：取其中一个

## 2.1 索引从 0 开始

**用 `[]` 加数字，取列表里的第几个元素：**

```python
fruits = ["苹果", "香蕉", "橘子"]
print(fruits[0])
print(fruits[1])
print(fruits[2])
```

实际输出：

```
苹果
香蕉
橘子
```

**位置和索引的对应关系：**

```
索引:     0        1        2
        ┌────────┬────────┬────────┐
        │  苹果  │  香蕉  │  橘子  │
        └────────┴────────┴────────┘
```

**第一个元素的索引是 `0`，不是 `1`。** 这一点 C# 也一样，应该不陌生。

## 2.2 负索引 —— 从右往左数 ★

```python
fruits = ["苹果", "香蕉", "橘子"]
print(fruits[-1])
print(fruits[-2])
print(fruits[-3])
```

实际输出：

```
橘子
香蕉
苹果
```

**一张图看懂正负索引：**

```
索引:    -3       -2       -1
        ┌────────┬────────┬────────┐
        │  苹果  │  香蕉  │  橘子  │
        └────────┴────────┴────────┘
          0        1        2
```

**规律：**

- `-1` **永远是最后一个**
- `-2` 是倒数第二个，以此类推
- **同一个列表，正索引和负索引指向的是同一批元素**

**为什么这个很有用？** 因为**取最后一个元素不用先算长度**：

```python
fruits[len(fruits) - 1]    # 麻烦
fruits[-1]                 # 干净
```

## 2.3 越界会报错

```python
fruits = ["苹果", "香蕉", "橘子"]
print(fruits[3])
```

实际输出：

```
IndexError: list index out of range
```

**`range` 是"范围"**，整句意思是"**列表的下标超出范围了**"。

三个元素，合法的正索引只有 `0 1 2`，合法的负索引只有 `-1 -2 -3`。

**所以 `fruits[3]` 和 `fruits[-4]` 都会报同一个错。**

# 第 3 节 · 切片 ★ 本课核心

> **切片 = 一次取出一段。** 这是 Python 最有代表性的能力之一，一定要练熟。

## 3.1 基本写法 `[start:stop]`

```python
nums = [10, 20, 30, 40, 50]
print(nums[1:4])
```

实际输出：

```
[20, 30, 40]
```

**规则：含头不含尾。**

- `start=1` → 从下标 **1** 开始取（也就是 20）
- `stop=4` → 取到下标 **4** 之前为止（下标 4 是 50，**不取它**）
- 所以取的是下标 `1, 2, 3` → `[20, 30, 40]`

**图示：**

```
        ┌────┬────┬────┬────┬────┐
        │ 10 │ 20 │ 30 │ 40 │ 50 │
        └────┴────┴────┴────┴────┘
索引:     0    1    2    3    4
                └───────┘
              nums[1:4]
              取到 4 之前
```

### 为什么要"含头不含尾"？

因为这样**元素个数 = `stop - start`**：

```
nums[1:4]  →  4 - 1 = 3 个元素   ✅  [20, 30, 40]
nums[0:3]  →  3 - 0 = 3 个元素   ✅  [10, 20, 30]
```

**这个设计让"取几个"一眼就能算出来。** 记住这条，就不会记错。

> **最容易错的地方**：以为 `nums[1:4]` 会取到 `50`。
> **不会。** `stop` 那个下标**永远不取**。

## 3.2 省略写法

`start` 和 `stop` 都可以省略：

```python
nums = [10, 20, 30, 40, 50]
print(nums[:3])
print(nums[2:])
print(nums[:])
```

实际输出：

```
[10, 20, 30]
[30, 40, 50]
[10, 20, 30, 40, 50]
```

| 写法 | 意思 | 结果 |
|---|---|---|
| `nums[:3]` | 从头取到下标 3 之前 | `[10, 20, 30]` |
| `nums[2:]` | 从下标 2 一直取到尾 | `[30, 40, 50]` |
| `nums[:]` | 从头到尾（整个列表） | `[10, 20, 30, 40, 50]` |

> **注意**：`nums[:3]` **省略的是数字，不是冒号**。
> `nums[3]` 是"取一个元素"，`nums[:3]` 是"取一段"——**冒号是切片的标志。**

## 3.3 步长 `[start:stop:step]`

**切片的第三个数字是"步长"**——每隔几个取一个：

```python
nums = [10, 20, 30, 40, 50]
print(nums[::2])
print(nums[1::2])
```

实际输出：

```
[10, 30, 50]
[20, 40]
```

- `nums[::2]` = 从头到尾，**隔 1 个取 1 个** → 下标 `0, 2, 4` → `[10, 30, 50]`
- `nums[1::2]` = 从下标 1 开始，**隔 1 个取 1 个** → 下标 `1, 3` → `[20, 40]`

**注意 `::` 是两个冒号**——第一个冒号前后省略了 start 和 stop，第二个冒号后面才是步长。

### ⚠️ "步长"和"隔几个"的换算（最容易混的地方）

> 这里原文我写的是 **"每 2 个取 1 个"——措辞有歧义，已修正。**
> （你在 `c3.py` 的注释里指出了这一点，是对的。）

| 写法 | 步长 | 取到的下标 | 正确说法 |
|---|---|---|---|
| `a[::2]` | 2 | `0, 2, 4, 6` | **隔 1 个**取 1 个 |
| `a[::3]` | 3 | `0, 3, 6, 9` | **隔 2 个**取 1 个 |

**规律：步长 N = 每隔 (N-1) 个取一个。**

**为什么"每 2 个取 1 个"这种说法要避免**：它既能读成"步长 2"，也能读成"跳过 2 个"（步长 3）。
**只要说法有歧义，就回到下标去看——下标不会骗人。**

## 3.4 反转 `[::-1]`

**步长写成 `-1`，就是倒着取：**

```python
nums = [10, 20, 30, 40, 50]
print(nums[::-1])
```

实际输出：

```
[50, 40, 30, 20, 10]
```

**`nums[::-1]` 是 Python 里反转列表最常用的写法，记住它。** 以后你会天天用。

## 3.5 切片返回的是「新列表」★

```python
nums = [10, 20, 30, 40, 50]
part = nums[1:3]
part[0] = 999

print("part =", part)
print("nums =", nums)
```

实际输出：

```
part = [999, 30]
nums = [10, 20, 30, 40, 50]
```

**改了 `part`，`nums` 一点没变。**

因为**切片会复制出一份新的列表**。`part` 和 `nums` 是**两个独立的东西**。

> 这一条很重要，和第 6 节的陷阱是同一个道理的两面。**先记住现象，第 6 节讲原理。**

# 第 4 节 · 修改列表

## 4.1 改单个元素

**列表是可以改的**——用索引直接赋值：

```python
fruits = ["苹果", "香蕉", "橘子"]
fruits[1] = "葡萄"
print(fruits)
```

实际输出：

```
['苹果', '葡萄', '橘子']
```

> **对比一下字符串**——字符串**不能**这么改（实测）：
>
> ```python
> s = "abc"
> s[0] = "x"
> ```
>
> ```
> TypeError: 'str' object does not support item assignment
> ```
>
> 意思是"**字符串不支持按下标赋值**"。
>
> **列表能改元素，字符串不能。** 这是个重要区别，后面讲字符串方法时会再遇到。

## 4.2 增：`append()` 和 `insert()`

**这里出现一个新语法：方法。**

```python
fruits = ["苹果", "香蕉"]
fruits.append("橘子")
print(fruits)

fruits.insert(0, "西瓜")
print(fruits)
```

实际输出：

```
['苹果', '香蕉', '橘子']
['西瓜', '苹果', '香蕉', '橘子']
```

| 写法 | 作用 |
|---|---|
| `fruits.append(值)` | 加到**末尾** |
| `fruits.insert(下标, 值)` | 插到**指定下标**，后面的元素自动往后挪 |

### 函数 vs 方法（新概念）

| | 写法 | 列表在哪儿 |
|---|---|---|
| **函数** | `len(fruits)` | 列表写在**括号里** |
| **方法** | `fruits.append("橘子")` | 列表写在**点前面** |

**方法 = "这个列表自己的功能"。** `append` 是"列表才会做的事"，所以要写在列表后面，用**点**连起来。

以后你会见到很多方法：`fruits.remove(...)`、`fruits.pop()`、`nums.sort()`。

## 4.3 删：`remove` / `pop` / `del`

```python
fruits = ["苹果", "香蕉", "橘子", "葡萄"]

fruits.remove("香蕉")
print(fruits)

last = fruits.pop()
print("pop 出来的是:", last)
print(fruits)

del fruits[0]
print(fruits)
```

实际输出：

```
['苹果', '橘子', '葡萄']
pop 出来的是: 葡萄
['苹果', '橘子']
['橘子']
```

**三种删除方式的区别：**

| 写法 | 按什么删 | 返回东西吗 |
|---|---|---|
| `fruits.remove(值)` | 按**值**删 | 不返回 |
| `fruits.pop()` | 删**最后一个**，可指定下标 | **返回被删掉的那个元素** |
| `del fruits[下标]` | 按**下标**删 | 不返回 |

> **`pop()` 的特殊之处**：它一边删，一边**把删掉的东西交给你**。
> 所以 `last = fruits.pop()` 之后，`last` 就是被删掉的那个 `葡萄`。
> 这就是它和 `remove` / `del` 最大的区别。

## 5.1 `sum` / `max` / `min`

```python

print("总分 =", sum(scores))
print("最高 =", max(scores))
print("最低 =", min(scores))
```

实际输出：

```

最高 = 96
最低 = 75
```

三个都是**内置函数**，直接吃列表。和 `len()` 是同一类东西。

**注意**：这三个**只能用在全是数字的列表上**。如果列表里有字符串，会报错。

## 5.2 `sort` 和 `sorted` —— 函数 vs 方法

```python
nums = [3, 1, 4, 1, 5]

print("sorted 返回新列表:", sorted(nums))
print("原来的 nums 没变:", nums)

nums.sort()
print("sort 原地排完:", nums)
```

实际输出：

```
sorted 返回新列表: [1, 1, 3, 4, 5]
原来的 nums 没变: [3, 1, 4, 1, 5]
sort 原地排完: [1, 1, 3, 4, 5]
```

**这两个功能一样，但行为不同：**

| | 类型 | 会不会改原列表 | 返回什么 |
|---|---|---|---|
| `sorted(列表)` | **函数** | **不改** | 一个新的排好序的列表 |
| `列表.sort()` | **方法** | **改**原列表 | 不返回东西 |

> **这和切片的关系**：
> - `sorted(nums)` 像 `nums[1:3]` —— **产生新的，不动原来的**
> - `nums.sort()` 像 `fruits[1] = "葡萄"` —— **直接改原来的**
>
> **"动自己"还是"产生新的"，是 Python 里一个反复出现的区别。** 记住这个感觉。

## 5.3 `in` —— 判断在不在里面

```python
fruits = ["苹果", "香蕉", "橘子"]
print("香蕉" in fruits)
print("西瓜" in fruits)
```

实际输出：

```
True
False
```

`in` 判断"**在不在里面**"，返回 `True` 或 `False`。

> `True` / `False` 你在第二课的 B2 见过（`"24" == 24` 就是 `False`）。

# 第 6 节 · 一个几乎人人会踩的陷阱

## 6.1 `b = a` 不是复制

```python
a = [1, 2, 3]
b = a
b.append(4)

print("a =", a)
print("b =", b)
```

实际输出：

```
a = [1, 2, 3, 4]
b = [1, 2, 3, 4]
```

**`a` 也变了！** 我们只对 `b` 做了 `append`，为什么 `a` 跟着变？

**因为 `b = a` 没有复制任何东西。** 它只是给**同一个列表**又起了一个名字。

```
        a ──┐
            ├──→  [1, 2, 3]
        b ──┘
        两个名字，一个列表
```

所以对 `b` 做的任何修改，`a` 那里都会看到——**因为它们本来就是同一个东西。**

## 6.2 `b = a[:]` 才是复制

```python
a = [1, 2, 3]
b = a[:]
b.append(4)

print("a =", a)
print("b =", b)
```

实际输出：

```
a = [1, 2, 3]
b = [1, 2, 3, 4]
```

**这次 `a` 没变。** 因为 `a[:]` 是**切片**，切片会**做一份新的**（第 3.5 节讲过）。

```
        a ──→  [1, 2, 3]
        b ──→  [1, 2, 3]     两个独立的列表
```

### 对比记忆

| 写法 | 效果 | 会不会互相影响 |
|---|---|---|
| `b = a` | **同一个列表，两个名字** | ✅ 会 |
| `b = a[:]` | **两个独立的列表** | ❌ 不会 |

> **这就是第 3.5 节那个现象的另一面。**
> 第 3.5 节：`part = nums[1:3]` → 改 `part` 不影响 `nums`（因为切片复制了）
> 这一节：`b = a` → 改 `b` **会**影响 `a`（因为没复制）

## A. 本课常见报错速查

| 报错 | 原因 | 怎么改 |
|---|---|---|
| `IndexError: list index out of range` | 索引超出范围 | 检查索引；3 个元素只能用 `0~2` 或 `-1~-3` |
| `TypeError: 'str' object does not support item assignment` | 想改字符串的某个字符 | 字符串不能改，只能整个重新赋值 |
| `TypeError: 'list' object is not callable` | 把列表名当函数调用了 | 检查是不是漏了点：应该写 `fruits.append(x)`，不是 `fruits(x)` |
| `AttributeError: 'list' object has no attribute 'appnd'` | 方法名拼错 | 检查 `append` / `remove` / `sort` 的拼写 |
| `TypeError: unsupported operand type(s) for +: 'int' and 'str'` | `sum()` 里混了字符串 | `sum` 只能算纯数字列表 |
| `TypeError: '>' not supported between instances of 'str' and 'int'` | `max()` / `min()` 里混了字符串 | 同上，纯数字才能比大小 |
