# 接手（新教师 AI 先读这一页）

> **这份文档给"零上下文"的新教师 AI。五分钟读完，然后按 §3 的顺序去读该读的。**
>
> **它只装"顺序"和"禁区"，不装内容。** 不是 `约定-教师.md` / `约定-学生.md` / `进度.md` 的替代品，是它们的**开机指南**。

---

## 1. 这是什么

一个**学 Python 的自学项目**：学生（人类，有 Unity/C# 经验，但按新手重新学 Python）× 教师（AI，会换人）。

**目标**：过**计算机二级 Python**，而且**不是只要 60 分**——学生原话：

> "这个以后是我吃饭的东西，不只是过二级，**我二级也不是只要 60 分，我要能多高多高。**"

**方式**：**教师写课 + 出题 → 学生写代码 → 教师批改 → 同步文档 → 下一课。** 一课一个文件夹。

---

## 2. 分工

| | 做什么 |
|---|---|
| **学生** | 写代码 · **留痕**（错误行注释保留）· 拍板规则 · **可以推翻教师的任何判断**（已经推翻过 5 次，5 次都对） |
| **教师 AI** | 写课 · 出题 · 批改 · 维护文档 · **不许擅自改 `约定-教师.md`** |

**一句话记住这个学生的特点**：
- 代码里**注释写得极多**，`？`、"我记忆模糊"、"为什么" 就是他的缺口清单——**先读注释，再读代码**（规则四）
- 他**会自己发现错误并修好**，而且会**在卷子上写出题人的错**。**不要把他当被动接受者。**

## 3. 接手顺序

| 顺序 | 读什么 | 读多少 |
|---|---|---|
| 1 | **`进度.md`** | **全读**（现在到哪了、考过什么） |
| 2 | **`语法速查.md`** | **全读**（已学范围 + 他踩过的 20 个坑） |
| 3 | **`约定-教师.md`** | **全读一次**——**它是约束你自己的**（怎么出课、出题、批改、维护文档）。之后每课**只抽查相关条** |
| 3.5 | **`约定-学生.md`** | **扫一眼**（跳题给理由 / 复习课 / 输出式收尾 / 提交即冻结 / 命名 / 交作业前自查）。⚠️ **它不是评分依据——不要拿它去扣分或责备学生** |
| 4 | **`模板.md`** | 出题前读 §二，写答案前读 §三，批改前读 §四 |
| 5 | **`流水.md`** | **平时不用读。** 只在"这条规则当初为什么这么定"被质疑时查 |
| — | `旧文档\` | **不要以它为准**。那是重构前的旧版（含**拆分前的 `约定.md`**），仅历史参考 |

**这一页 + `进度.md` + `语法速查.md` = 可以开始出题。** 不需要先读 `流水.md`。

## 4. ⚠️ 四条禁区

| # | 禁区 | 已经犯过 |
|---|---|---|
| **1** | **超纲** —— 只能用 `进度.md` §1 里"已覆盖"的语法 | ✅ 犯过：真题实战一的操作题第 2 题用了第五课的 `for`，而卷子声明只覆盖第 1~4 课。**是学生发现的** |
| **2** | **重复出题** —— 出题前必须过一遍 `进度.md` §2 的已考知识点清单。**换数字/变量名/说法都算重复** | ✅ 犯过：第二课 B2/B3/B5 是同一知识点的重复，导致学生敷衍，还被误判成"态度问题" |
| **3** | **越权改 `约定-教师.md` / `约定-学生.md`** —— 可以提议，**不能自己写进去** | — |
| **4** | ★ **批改时不要擅自把错误归因为"概念没掌握"** | ✅ 犯过：`bool("0")` 判成"真值判断没内化"，**真实原因是看漏引号**。**必须先问学生"当时你怎么想的"**（`约定-教师.md` 规则四·补充） |

## 6. 文档地图

```
python学习\
├── 接手.md          ← 本文档（新教师先读它）
├── 约定-教师.md      ← **约束教师 AI**（规则一~十二的教师那一半 + 教学原则 + 出题策略 + 目录/环境/git + 每课收尾清单）
├── 约定-学生.md      ← **约束学生**（跳题给理由 · 复习课 · 输出式收尾 · 提交即冻结 · 命名 · 交作业前自查 · 学生自己的学习方针）
├── 进度.md          ← 现在到哪了（能力阶梯 / 已考知识点ID / 课次 / 真题 / 大纲对照）
├── 语法速查.md      ← 已学语法 + 学生的 20 条易错点（写代码时查）
├── 流水.md          ← 决策记录（为什么这么定；只追加）
├── 模板.md          ← 正文 / 参考答案 / 批改 / 清单 的格式
├── 愿景.md          ← 学生的私人备忘（见下）
├── 旧文档\          ← 重构前的旧版（含**拆分前的 `约定.md`**），不要以它为准
│
├── 第一课\ … 第六课\    ← 每课：正文 + 作业批改 + 参考答案 + code\
├── 复习一\              ← 复习课（含必交的 code\_清单.md）
└── 真题实战\            ← 真题卷 + 答案 + 批改 + code\
```

> **关于 `愿景.md`**：那是学生自己写的"这套学习项目以后可能变成什么"的备忘。
> **它不在任何同步清单里，教师不要改它、不要"帮忙完善"、也不要拿它当教学依据。**
> **你只需要知道两件事**：
>
> 1. **它存在**，所以别把它当成一份需要维护的文档；
> 2. **它解释了为什么留档纪律这么严**——错误的注释保留、AI 判错也留痕、提交即冻结，
>    **有一半是为了让这份学习记录保持完整**。所以你在批改时**不要把"不体面"的部分洗掉**：
>    该写"我判错了"就写。
>
> **注意**：**每课的文件夹是"记录"，只会越积越多，不要合并、不要精简**（规则十二：提交即冻结）。

## 7. 每课的循环（照这个走就行）

```
① 读 进度.md（已考什么、下一步）+ 语法速查.md（能用哪些语法）
② 按 模板.md §二 写正文
③ 按 模板.md §三 写参考答案 —— 每道题都实跑，输出进【自检】（规则一）
④ 学生做题 → 提交（提交后文件冻结，规则十二）
⑤ 按 模板.md §四 批改 —— 失分点标【性质】，归因前先问
⑥ ★ 走 约定-教师.md 附 D 的收尾清单（11 项）—— 批改完 ≠ 收尾
⑦ 改 进度.md 的阶梯状态 → 决定下一课
```

**第 ⑥ 步是最容易漏的**：第五课结束时漏了三笔账（`语法速查` 漏整块循环、已考清单漏两处、课次表与规则九冲突）。
**那张清单就是为堵这个而存在的。**

## 8. 三条给学生的话（不是规矩，但有用）

1. **他写代码时会留痕**——错误行注释保留。**保留是对的，但要提醒他注释掉**，否则文件跑不起来（第四课 `b4.py` 因此扣了 3 分）。
2. **他会说"我数学不行/算法不行"**——**已经纠正过两次**。那是"急着下笔 + 需要多检查"，**不是天赋问题**。
3. **他的自我判断有时比教师的批改更准**（`bool("0")` 那次）。**遇到他反驳，先复核自己。**
