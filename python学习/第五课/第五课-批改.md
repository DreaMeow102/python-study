```python

a = 0
```

**"上述实现方式带了个6"——你自己找到了。**

**这正是我们讨论"`<=` 还是 `<`"的结论，你把它落到了代码里，而且保留了旧版本作对比。**

## ⚠️ 但顶部那句注释还在

```python

```

| 写法 | 是什么 |

**这是 Python 里最容易手滑的一处——方括号和圆括号只差一个字符，但是两种东西。**

> **元组是第六课的内容**（第 6 级：按名字存数据），现在不用学。
