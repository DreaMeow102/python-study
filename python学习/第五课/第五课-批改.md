# 二、★ 先说最重要的：d1 你自己修好了

**我上一轮读到的 d1 是这样的：**

```python
a = 0

```

**现在你交上来的是：**

```python
# a = 0
# while a <= 5:
#     a = a + 1
#     print (a)
a = 0
while a < 5: # 这一步相当于是自己想的、更符合自己习惯些的实现方式。
             # 上述实现方式带了个6，并且将a挪到了外面。不符合自己习惯。
    a = a + 1
    print (a)
```

**"上述实现方式带了个6"——你自己找到了。**

**这正是我们讨论"`<=` 还是 `<`"的结论，你把它落到了代码里，而且保留了旧版本作对比。**

## ⚠️ 但顶部那句注释还在

```python
# 原题目的演示代码应该是出错了。a = a + 1出现在了打印后，应该是打印完成前先进行循环终止。
```

**我的演示代码没有出错**（实测输出 `1 2 3 4 5`）。

**两个版本的差别不是"谁对谁错"，是"起点和边界配套"：**

| 顺序 | 起点 | 边界 | 结果 |
|---|---|---|---|
| 先打印，后加 | `1` | `<= 5` | 1 2 3 4 5 ✅ |
| 先加，后打印 | `0` | **`< 5`** | 1 2 3 4 5 ✅ |
| 先加，后打印 | `0` | `<= 5` | **1 2 3 4 5 6** ❌ ← 你抓到的 |

**你已经抓到了第三个，但还没回头确认"第一个本来就是对的"。**

**扣 0.5 分就是因为这句注释**——代码满分。

```python

    print (b)
```

**实测：**

```

b 的类型 = <class 'list'>       ← 题目要的
```

**输出完全一样**（元组也能遍历、也能切片），**但类型不同。**

| 写法 | 是什么 |
|---|---|

| `("苹果","香蕉","橘子")` | **元组**（`tuple`） |

**这是 Python 里最容易手滑的一处——方括号和圆括号只差一个字符，但是两种东西。**

> **元组是第六课的内容**（第 6 级：按名字存数据），现在不用学。
> **但这题你写的是圆括号**——要么是手滑，要么是不知道两者不同。

> 你写："我认为在返回时最大的区别，**可能也只是文本**"

**`range` 和列表的区别不是文本，是：**

| | `range(5)` | `[0,1,2,3,4]` |
|---|---|---|
| 存了什么 | **只存 3 个数**（start、stop、step） | **存了 5 个数** |
| 占内存 | 微小 | 随长度增长 |
| 什么时候算出数 | **迭代到那一步才算** | 一开始就全在 |

**`range(100000000)` 几乎不占内存；`list(range(100000000))` 会把内存吃爆。**
**这是"文本区别"吗？不是——这是本质区别。**

**而文档里那句话写得很清楚：**

> "该对象只有在被迭代时才一个一个地返回所期望的列表项，
> **并没有真正生成过一个含有全部项的列表，从而节省了空间。**"
