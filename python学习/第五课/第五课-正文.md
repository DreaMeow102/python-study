# 第 1 节 · `for` 与 `range`

## 1.1 `range(n)` —— 重复 n 次

```python
for i in range(5):
    print(i)
```

实际输出：

```
0
1
2
3
4
```

**读法**：`for i in range(5):` = "让 `i` 依次等于 0、1、2、3、4，每次执行下面的缩进代码"。

**三个必须记住的点：**

1. `for` 那行末尾**必须有冒号 `:`**
2. 下面**必须缩进**（4 空格）——**缩进的部分才是"要重复做的事"**
3. **`range(5)` 给出 0~4，不包括 5** ——这是**含头不含尾**，和切片一模一样

> **和切片的联系**：`nums[1:4]` 取下标 1、2、3（不含 4）。
> **`range(1, 4)` 也给出 1、2、3（不含 4）。** 同一个规则。

## 1.2 `range(a, b)` —— 指定起点

```python
for i in range(1, 6):
    print(i)
```

实际输出：

```
1
2
3
4
5
```

**从 1 到 5。**`range(a, b)` = 从 `a` 到 `b-1`。

## 1.3 `range(a, b, step)` —— 步长

```python
for i in range(1, 10, 2):
    print(i)
```

实际输出：

```
1
3
5
7
9
```

**和切片的第三个参数是同一个东西**（第三课 3.3）：

| 写法 | 含义 |
|---|---|
| `range(1, 10)` | 1,2,3,…,9 |
| `range(1, 10, 2)` | 1,3,5,7,9（**步长 2**） |

> **第三课那张"步长 ↔ 隔几个"的表，在这里照样管用**：
> **步长 N = 每隔 (N-1) 个取一个。**

## 1.4 遍历列表

**`for` 不只是配 `range`，它可以直接遍历列表：**

```python
fruits = ["苹果", "香蕉", "橘子"]
for f in fruits:
    print(f)
```

实际输出：

```
苹果
香蕉
橘子
```

**`for f in fruits:` 的意思是"让 `f` 依次等于列表里的每个元素"。**

**字符串也能遍历**：

```python
for ch in "abc":
    print(ch)
```

→ `a`、`b`、`c`

> **这是 Python 的 `for` 和 C 的 `for` 最大的区别**：
> C 的 `for` 是"计数循环"，Python 的 `for` 是"**遍历**"——
> **它直接给你元素，不用管下标。**

# 第 2 节 · 两种经典模式

> **几乎所有循环都在做两件事之一：累加、或计数。** 这两个模式必须刻进肌肉记忆。

## 2.1 累加器：先开一个"桶"，再往里加

```python
nums = [10, 20, 30, 40]
total = 0                 # ← 先准备一个"桶"，从 0 开始
for n in nums:
    total = total + n     # ← 每轮往桶里加一个
print(total)
```

实际输出：

```
100
```

**结构**：

```
total = 0                 ① 循环之前：桶清零
for n in nums:
    total = total + n     ② 循环之内：往桶里加
print(total)              ③ 循环之后：看桶里有多少
```

> **这三步是死格式。** 换个说法（"求总和""求平均的前一步"）也是它。

## 2.2 计数器：数一数有几个

```python
nums = [3, 8, 12, 5, 20, 7]
count = 0
for n in nums:
    if n > 10:
        count = count + 1
print(count)
```

实际输出：

```
2
```

**和累加器一模一样，只是"加的是 1"而不是"加的是元素本身"。**

> **关键点**：`if` 在**循环里面**——**每轮都要判断一次**。
> **`for` + `if` 是这个组合的核心。**

## 2.3 找最大：先假定第一个，然后一路打擂

```python
nums = [3, 8, 12, 5, 20, 7]
biggest = nums[0]        # ← 先假定第一个是最大的
for n in nums:
    if n > biggest:      # ← 如果碰到更大的
        biggest = n      # ← 就换掉
print(biggest)
```

实际输出：

```
20
```

> **这就是 `max()` 的内部做法。** 你已经会用 `max()`——现在你知道它怎么算的了。

# 第 3 节 · `for` + `if`

> **这是二级操作题里最常用的组合。** 上一节的 B2、B3 已经是它了，这一节专门练。

## 3.1 筛选：只处理符合条件的

```python
for i in range(1, 11):
    if i % 2 == 0:
        print(i)
```

实际输出：

```
2
4
6
8
10
```

**`if` 在循环里面 → 每轮判断一次 → 只对符合条件的动手。**

## 3.2 查找：找到就报告

```python
fruits = ["苹果", "香蕉", "橘子"]
for f in fruits:
    if f == "香蕉":
        print("找到了")
```

实际输出：

```
找到了
```

## 3.3 遍历字符串 + 判断

```python
s = "hello world"
count = 0
for ch in s:
    if ch == "l":
        count = count + 1
print(count)
```

实际输出：

```
3
```

> **注意**：`for ch in s` 遍历的是**每一个字符**。
> **这是"统计字符"类题目的固定套路。**

# 第 4 节 · `while` 循环

> **`for` 是"对一堆东西逐个处理"，`while` 是"只要条件成立就一直做"。**

## 4.1 `while` 基本结构

```python
i = 1
while i <= 5:
    print(i)
    i = i + 1        # ← 这一行千万不能忘
```

实际输出：

```
1
2
3
4
5
```

**结构**：

```
i = 1                  ① 循环之前：准备变量
while 条件:             ② 条件为真就一直做
    做事
    改条件变量          ③ ← 忘了这行就是死循环
```

## 4.2 `while` 最擅长的事：**不知道要循环几次**

**`for` 适合"次数已知"，`while` 适合"做到满足条件为止"。**

```python
# 一张纸厚 0.1 毫米，对折多少次能超过 1 米（1000 毫米）？
thickness = 0.1
count = 0
while thickness < 1000:
    thickness = thickness * 2
    count = count + 1
print(count)
```

实际输出：

```
14
```

**你不知道要折几次——只能一直折，直到厚度达标。这就是 `while` 的场合。**

> 顺带：这题和复习一 甲3（对折算厚度）是同一个场景，
> 但那次是"**算 10 次之后的厚度**"（次数已知 → 用乘方），
> 这次是"**算要几次才够**"（次数未知 → 用 `while`）。

## ⚠️ 4.3 死循环 —— `while` 唯一的危险

```python
i = 1
while i <= 5:
    print(i)      # ← 忘了 i = i + 1
```

**这个程序会永远打印 1。** 因为 `i` 一直不变，条件永远成立。

**遇到死循环怎么办**：在终端里按 **`Ctrl + C`** 强制停止。

> **防止死循环的口诀**：**写 `while` 时，先写"改条件变量"那行，再写中间的代码。**

# 第 5 节 · `break` 和 `continue`

> **这两个词用来"提前干预"循环。**

## 5.1 `break` —— 立刻跳出整个循环

```python
for i in range(1, 11):
    if i == 5:
        break          # ← 到 5 就不干了，整个循环结束
    print(i)
```

实际输出：

```
1
2
3
4
```

**`break` = "别循环了，走人"。**

## 5.2 `continue` —— 跳过这一轮，继续下一轮

```python
for i in range(1, 6):
    if i == 3:
        continue       # ← 跳过 3，但循环继续
    print(i)
```

实际输出：

```
1
2
4
5
```

**`continue` = "这轮不算，下一轮"**——注意 **3 被跳过了，但 4 和 5 还在**。

## 5.3 对比记

| | 作用 | 循环还继续吗 |
|---|---|---|
| `break` | **跳出整个循环** | ❌ 不继续了 |
| `continue` | **跳过本轮剩下的代码** | ✅ 继续下一轮 |

> **记忆法**：`break` = **打断**（整个结束）；`continue` = **继续**（跳到下一轮）。

# 附录

## A. 本课常见报错速查

| 报错 | 原因 | 怎么改 |
|---|---|---|
| `SyntaxError: expected ':'` | `for` / `while` 那行**漏了冒号** | 条件后面加 `:` |
| `IndentationError: expected an indented block after 'for' statement` | 冒号后面**没缩进** | 下一行缩进 4 空格 |
| 程序**一直不结束**（不是报错） | **死循环** | 按 `Ctrl + C`；检查有没有"改条件变量" |
| `NameError: name 'xxx' is not defined` | 拼错 / 没定义 | 检查拼写 |

## B. 本课语法速查

```python
# for + range
for i in range(5):        # 0 1 2 3 4      含头不含尾
for i in range(1, 6):     # 1 2 3 4 5
for i in range(1, 10, 2): # 1 3 5 7 9      步长

# for 遍历
for x in 列表:             # 依次取出每个元素
for ch in 字符串:          # 依次取出每个字符

# 累加器（死格式）
total = 0
for n in nums:
    total = total + n

# 计数器（死格式）
count = 0
for n in nums:
    if 条件:
        count = count + 1

# 找最大（打擂法）
biggest = nums[0]
for n in nums:
    if n > biggest:
        biggest = n

# while
i = 1
while i <= 5:
    print(i)
    i = i + 1            # ← 千万别忘

# 干预
break        # 跳出整个循环
continue     # 跳过本轮，继续下一轮
```
