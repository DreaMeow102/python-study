## 三、规矩

**结构**（从上面的形状里看不全的）：

1. **题跟着节走** —— `★ X 组习题` 嵌在每一节**末尾**，教完一节立刻考那一节。**不许集中放。**
2. **组号跟着教学节走**：一节一组，从 **A** 起顺序排。**字母数 = 教学节数**——
   **不按题量定，也不按题型定。**（同理，字母到哪结束，由知识点说了算。）
3. **特殊题接在最后一个组之后，取下一个字母**；**关卡不占字母**（它编号 `关卡 1` `关卡 2`）。
4. **关卡是最后一节**，排在特殊题之后、附录之前。**它是这一课的考核**，不是普通习题。
   （这一课**没有**特殊题时，关卡就是第 N 节。）
5. **子节编号 `N.m` 跟着节号走**（1.1 1.2 … 2.1 …）。
6. **只有"特殊题"标了 `← 可选`** —— 要不要由内容决定（本格式不规定）。**关卡不在此列。**

**句式照抄，不要改写**：
`**要求**：…` · `**实际输出：**` · `**【自检】**（真实输出）` · `**用注释回答**：` · `**运行示例**` · `**目标**：`

可选用（需要时才写）：`**提示**：`

**编号照抄**：
`# 第 N 节 ·` · `## N.m` · `## ★ X 组习题 · <组名>（k 题）` · `### X1 · 题目名 【新】` · `## 关卡 K ·` · `## I1 ·`
**题目那一行四个部分缺一不可**：题号、` · `、题目名、类别（`【新】` / `【复习】`）。

**例题和题块都是"三件套"**：代码块 + 标记（`**实际输出：**` / `**【自检】**（真实输出）`）+ 输出块。
**不许写"应该输出"这种没跑过的话。**
