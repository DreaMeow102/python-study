# 二、报错速查

> **读报错的顺序**：先看**最后一行**（错误类型 + 原因），再往上找 `line N` 定位行号。

| 报错 | 原因 | 怎么改 |
|---|---|---|
| `SyntaxError: invalid syntax` | 语法错，常见于少括号、少冒号 | 看报错指的行 |
| `SyntaxError: unterminated string literal` | **引号没闭合** | 补上右边的引号 |
| `SyntaxError: invalid character '“' (U+201C)` | **用了中文引号** | 换成英文半角 `"` |
| `IndentationError: expected an indented block` | 冒号后面没缩进 | 下一行缩进 4 空格 |
| `IndentationError: unexpected indent` | 不该缩进的地方缩进了 | 去掉缩进 |
| `NameError: name 'xxx' is not defined` | 用了没定义过的变量 / 拼错 | 检查拼写 |
| `TypeError: can only concatenate str (not "int") to str` | 拿**字符串**去加数字 | 先 `int()` / `float()` 转换 |
| `ValueError: invalid literal for int() with base 10: '24.5'` | `int()` 吃不了带小数点的字符串 | 两步：`int(float("24.5"))` |
| `ValueError: invalid literal for int() with base 10: 'A'` | `int()` 吃不了非数字 | 检查输入内容 |
| `IndexError: list index out of range` | **下标越界** | 3 个元素只能用 `0~2` / `-1~-3` |
| `TypeError: 'str' object does not support item assignment` | 想改**字符串**的某个字符 | 字符串不能改，只能整个重新赋值 |
| `TypeError: 'int' object is not callable` | 变量名**覆盖**了内置函数 | 换个变量名（如 `total` 而不是 `sum`） |
| `TypeError: 'list' object is not callable` | 把列表当函数调了 | 应该是 `fruits.append(x)` |
| `AttributeError: 'list' object has no attribute 'appnd'` | 方法名拼错 | 检查 `append` / `remove` / `sort` |
| `TypeError: unsupported operand type(s) for +: 'int' and 'str'` | `sum()` 里混了字符串 | 只能算纯数字列表 |
| `TypeError: '>' not supported between instances of 'str' and 'int'` | `max()`/`min()` 里混了字符串 | 同上 |
| `TypeError: can't multiply sequence by non-int of type 'str'` | 拿**字符串**去乘字符串 | **字符串只能乘整数**（`"ab" * 2` → `"abab"`）。想算乘法先转换 |
| `TypeError: int() argument must be a string, a bytes-like object or a real number, not 'list'` | `int()` 吃了一个**列表** | `int()`/`float()` **只能接受一个值**，不能作用于列表 |
| `TypeError: float expected at most 1 argument, got 3` | `float(a,b,c)` 传了三个 | `float()` **只接受一个参数**，要转三个就写三行 |

## 1. 函数返回值必须**接住**

**发生时间**：第三课 d4 → 复习一 丙3 → **复习一 乙1（第三次）**

```python
a = input("请输入价格")
float(a)          # ❌ 白写了，结果被丢掉
```

**`float(a)` 不会改变 `a`**，它只是算出一个新值交给你。

```python
a = float(input("请输入价格"))     # ✅ 接住
```

> ### ⚠️ 已复发两次（d4 → 丙3 → 乙1）
> **一眼判断法**：**一行只有 `float(x)` 而左边没有 `=` → 99% 是错的。**
>
> **换个比喻记**：
> - **函数像「计算器」**——按一下，它吐出**一张结果纸片**。**你不拿走，纸片就飘走了。**
> - **方法像「遥控器」**——按一下，**电视自己就变了**，遥控器什么也不给你。

**通用规律：**

| | 例子 | 改原来的吗 |
|---|---|---|
| **函数** | `float(x)` `int(x)` `str(x)` `sorted(x)` `len(x)` `sum(x)` | ❌ **不改，返回值必须接住** |
| **方法** | `x.append()` `x.insert()` `x.remove()` `x.sort()` | ✅ **改自己，不用接** |
| 例外 | `x.pop()` | 既改自己，**又返回**被删的那个 |

> **阴在哪**：这个错误**不报错**。`print(f"{price} 元")` 输出看起来完全正常，
> 因为字符串 `"19.9"` 和浮点数 `19.9` 打印出来长得一样。
> **只有等你拿它算数的时候才会炸。**

## 2. `insert(0, ...)` 才是插到**开头**

**发生时间**：第三课 d2

```python
fruits = ["Apple", "Banana", "Orange"]
fruits.insert(3, "Watermelon")    # ❌ 加到了末尾
```

**`insert(下标, 值)` 的准确含义**：把值插到**那个下标的位置上**，后面的往后挪。

| 写法 | 效果 |
|---|---|
| `insert(0, x)` | **最前面** |
| `insert(2, x)` | 插到下标 2 的位置 |
| `insert(len(a), x)` | **末尾**（等于 `append`） |

## 3. 切片是**含头不含尾**

**发生时间**：第三课（正文 3.1）

```python
nums = [10, 20, 30, 40, 50]
nums[1:4]      # → [20, 30, 40]，不包含下标 4 的 50
```

**记忆法**：元素个数 = `stop - start`。`4 - 1 = 3` 个 ✅

## 4. 步长 N = **隔 (N-1) 个**取一个

**发生时间**：第三课 c3（**你指出我正文措辞有歧义**）

| 写法 | 步长 | 取到的下标 | 说法 |
|---|---|---|---|
| `a[::2]` | 2 | `0, 2, 4` | **隔 1 个**取 1 个 |
| `a[::3]` | 3 | `0, 3, 6` | **隔 2 个**取 1 个 |

> ⚠️ **"每 2 个取 1 个"这种说法要避免**——它能读成"步长 2"，也能读成"跳过 2 个"。
> **只要说法有歧义，就回到下标去看。下标不会骗人。**

## 5. `b = a` **不是**复制

**发生时间**：第三课 f1

```python
a = [1, 2, 3]
b = a
b.append(4)
print(a)       # [1, 2, 3, 4]   ← a 也变了！
```

| 写法 | 效果 |
|---|---|
| `b = a` | **同一个列表，两个名字** |
| `b = a[:]` | **两个独立的列表** |

## 6. `//` 是**向下取整**，不是"砍掉小数"

**发生时间**：第二课 A1（**你问出这个问题，我原文写错了**）

```python
-7 // 2         # -4   向下取整
int(-7 / 2)     # -3   截断（向零取整）
```

**C# 的 `-7 / 2` 是 `-3`，Python 的 `-7 // 2` 是 `-4`。同一个算式两个答案。**

`%` 也受影响：`-7 % 3` 在 Python 里是 `2`，在 C# 里是 `-1`。

> 正数时看不出来，**负数时才分家**。

## 7. `print` 用逗号会**自动加空格**

**发生时间**：第一课作业

```python
print("我叫", name, ",我今年", age, "岁")   # → 我叫 YN4 ,我今年 24 岁
```

## 10. 不要用内置函数名当变量名

**发生时间**：第二课讨论（`int = (age)`）

Python 里有 **151 个**内置名字，它们**不是关键字，可以被覆盖**：

```python
sum = 10
sum([1, 2, 3])     # TypeError: 'int' object is not callable
```

**最容易被顺手用掉的**：`list`、`dict`、`sum`、`max`、`min`、`input`、`id`、`type`。

| 别写 | 改写 |
|---|---|
| `list = [...]` | `nums = [...]` |
| `sum = 0` | `total = 0` |
| `max = ...` | `maximum` |
| `input = ...` | `user_input` |

> **`del sum` 就能恢复**——内置函数没坏，只是被你的名字挡住了。

## 11. ⚠️ 转换不要**滥加**

**发生时间**：复习一（`jia3` / `yi3` / `yi1` 三处）

你现在的倾向是：**不确定就加个 `int()` / `float()`**。

| 位置 | 写法 | 情况 |
|---|---|---|
| `jia3.py` | `float(thickness*(2**times))` | **多余**（本来就是浮点） |
| `yi3.py` | `sum(int(scores))` | **报错**（`int()` 吃不了列表） |
| `yi1.py` | `float(a)` 单独一行 | **白写**（没接住） |

**这个倾向是从第 1 条那个坑里长出来的**——那次是"该转换没转换"，所以你现在到处加。
**方向对，但矫枉过正了。**

> ### 规律：转换只加在「数据的来源」上
>
> | 该加 | 不该加 |
> |---|---|
> | `input()` 的结果 | 列表（`int(scores)` ❌） |
> | 字符串字面量 `"24"` | 算式的结果（本来就是数字） |
> | 从文件/网络读进来的文本 | **已经转换过的值** |

**判断法**：问自己"**这个东西现在是什么类型？**"
- 不知道 → 先用 `type()` 看一眼，**别猜着加转换**

## 12. 这些名字要背牢

**发生时间**：复习一（`yi4` 忘了 `append`、`bing2` 不确定 `sort` 方向）

**真实的提取失败** —— 不是不会用，是**想不起名字/方向**。

| 名字 | 意思 | 记忆点 |
|---|---|---|
| `append(x)` | **加到末尾** | append = "附加"（**不是 `end`**，Python 里没有 `list.end()`） |
| `insert(i, x)` | 插到下标 `i` | `insert(0, x)` 才是插到**开头** |
| `remove(x)` | 按**值**删 | |
| `pop()` | 删末尾并**返回**它 | |
| `sort()` | **原地**排序，**默认升序** | |
| `sorted()` | **返回新列表**，默认升序 | |

> **`sort()` 默认升序（1 2 3），不是降序。** 要降序是后面课的内容。

## 列表

```python
fruits = ["苹果", "香蕉", "橘子"]
empty  = []

len(fruits)          # 3

fruits[0]            # 第一个
fruits[-1]           # 最后一个

fruits[:3]           # 前三个
fruits[2:]           # 从下标 2 到尾
fruits[:]            # 整个的副本
fruits[::2]          # 隔 1 个取 1 个
fruits[::-1]         # 反转

```
