# §5 与计算机二级 Python 的对照

**Python 只在二级考**（一级是 Office，三级/四级不考 Python）。

### 分值结构

| 部分 | 分值 |
|---|---|
| 选择题 | **40 分**（含**公共基础 10 分**） |
| 操作题 | **60 分** = **简单编程 40 + 综合编程 20** |

> ⚠️ **及格不只是 60 分**：编程类科目**自 2019 年起增设选择题门槛**——
> **必须同时满足「总分 ≥ 60」且「选择题得分率 ≥ 50%」**（即 **选择题 ≥ 20 分**）才能拿证。
> **所以选择题不能放弃。**

### 操作题实际考什么（看过真题之后）

| 真题例子 | 用到什么 |
|---|---|
| "五个彩色圈圈" | **`turtle` + `random`** |
| "中文分词写文件" | **`jieba` + 字典词频 + 文件写入** |
| "价值链 · 词频 Top10" | **`jieba` + 字典 + `sorted(key=)` + 文件读** |
| "价值链 · 分句输出" | **`re` 正则 + `jieba` + 文件读写** |

**共同点**：
1. **核心是 `turtle` / `jieba` / 文件读写 / 字典词频统计**
2. **题型以「填空补全」为主**——给模板，填横线 / 改框错的代码，**不是从零写**
3. **几乎不考"纯逻辑题"**（闰年、水仙花数这类是**教材题**，不是真题形态）

> **结论**：**闰年不是"二级经典题"，是"教材经典题"。** 它仍然留着，是因为它练的 `%` + `and`/`or` + `if` 是上面所有大题的基础。

### 覆盖对照

| 二级大纲板块 | 对应阶梯 | 当前覆盖 |
|---|---|---|
| （一）基本语法元素 | 0 | ~75% |
| （二）基本数据类型 | 1、**4** | ~45%（**第六课补字符串方法**；还缺复数） |
| （三）程序的控制结构 | **2 ✅、3 ✅、10** | **~70%**（分支 ✅、循环 ✅，**只缺异常处理**） |
| （四）函数和代码复用 | 7 | **0%** |
| （五）组合数据类型 | **5 ✅**、6 | ~40%（列表 ✅，字典/集合/元组未学） |
| （六）文件和数据格式化 | **4**、9 | **~5%** |
| （七）Python 计算生态 | 11、**12** | ~5% |

**现在去考大约 40 分。**（分支和循环已会，但操作题主力——**字典/文件/`jieba`/`turtle`——全没学**。）

**走完第 0~12 级 ≈ 二级水平**（第 13 级是二级不考的类与模块）。

> ⚠️ **目标不是 60 分**（学生定的）："这个以后是我吃饭的东西，不只是过二级，**我二级也不是只要 60 分，我要能多高多高**。"
>
> | | 只想 60 分 | **要的：拿高分** |
> |---|---|---|
> | 操作题大块得分 | 够 | 够 |
> | **选择题的细节** | 可以放弃一些 | **必须全覆盖** |
> | "了解"级的内容 | 可略过 | **不能略** |
> | 阶梯能不能空格 | 能 | **一格都不能空** |
>
> > **二级是「地板」，不是「天花板」。**
> > 它不考 NumPy / PyTorch，所以**离 AI 方向还有一段**。

### 公共基础 10 分

真题选择题 40 分里有 **10 分是"公共基础"**（数据结构、算法、数据库、软件工程），**和 Python 无关，而且不在阶梯里**。
**处理**：等 Python 部分走完（约第 7~8 课后），再单独补一块。**现在不用管它。**
