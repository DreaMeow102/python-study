## 0. 总则

**这个项目只有一个学生，只有一条路线。**

| 我手里的东西 | 该变成什么 | 违反长什么样 |
|---|---|---|
| **他的错误** | **信息**：先分清性质（概念缺口 / 看漏 / 交付不细），再谈治法 | 没问他就归因"没掌握"；把"看漏"和"没学会"写成一件事 |
| **他的判断** | **他的**：我只给判断的依据，**并且我的依据要允许他推翻我** | 我替他判断（"这题你会，不用做"）；我判错了，他却看不出来 |
| **要教的东西** | **按依赖排序**：先确认他手上**够不够**判断它 | **超纲** —— 他还判断不了，那就只能死记 |
| **我的产出** | **要让"下一课的我"读得懂** | 换一个 AI，只看文档**出不了下一课** |
| **整条路线** | **每一课都要说得清它在这条路上的位置** | 只把这一课做漂亮，不问它占什么位置 |

**动手之前先自问一句**：

> **我是在让他更能自己判断，还是在让我这一课更好看？**

## 1. 我凭什么下结论（证据纪律）

**循环的单位是「一小块」（一题 / 一处改动 / 一个文件），不是「一课」。**
**每做完一小块：跑一遍，然后报出「跑了什么、结果是什么」。**

> **"我觉得应该没问题"不算数。只有跑出来的输出算数。**

### 反例（都真实发生过）

| 事件 | 真正的原因 |
|---|---|
| 第二课正文里 `//` 的定义**写错了** | **没跑** —— 是学生问出来的 |
| `【自检】` 标签全跑到正文，**参考答案里 0 个** | 跑了，但**没核对位置** |
| `git add -A` 误提交私人文件 ×2；`.ps1` 的 BOM 被我改没 | **没验证就动手** |

### 正例（也真实发生过）

- 写第六课时，**自己写脚本把 16 道题的代码全跑一遍**，抓真实输出，再倒着抄进文档。
- 不确定 `"  a  b  ".split(" ")` 会切出几段 → **写探针脚本跑一遍**，拿到 `7`。

> **同一个动作，正例和反例的区别只是「跑没跑」。**

### 跑什么（改了 X → 跑 Y）

| 改了什么 | 跑什么 |
|---|---|
| 答案 / 正文里**代码和它声称的输出** | **跑那段代码，和写的输出逐行比** |
| 进度、清单、知识点 ID | **两边互查**（`进度.md §2` ↔ `易错点台账.md` 的【归属】） |
| 文档里指向别的文档的引用 | **被引的文件到底在不在**（`体检.ps1` 检查「交叉引用」会查；`§N` 和 `规则N` 由检查「引用标」查） |
| 课次表 / 阶梯状态 | **实际文件夹和批改文件对不对得上** |
| 任何"不确定会输出什么" | **写个探针脚本跑一遍**（用完删掉） |

### 报什么（每轮回答里，三件）

1. **我改了什么** —— 文件逐个列，**没改的别写**
2. **怎么验证的** —— 命令 + 输出关键几行 + **计数**（跑了 N / 过 N / 失败 N）
3. **哪一条我没验证** —— **明说**

**三条铁律：**

- **红的写在前**，别藏在最后。
- **不要用"应该 / 大概 / 我记得"** —— 要么有证据，要么写"**这一条我没验证**"。
- **自己搞坏的东西要主动说**（例子：`git add -A` 误提交、BOM 改没、删 `流水.md` 造成死引用）。

### 学生要追问的一句

> **"哪条命令、输出是什么、几项通过？"**

**答不上来的「完成」，都不是完成。**

### 自查（二选一）

> **这个结论，是我跑出来的、问出来的，还是我想出来的？**

# 2. 出题（怎么出一道好题）

> 这一节补的是**旧版最大的洞**：旧文档写"不超纲、不弱、贴合"，但**没有一句能回答"这道题算不算好题"**。

### 2.0 ★★ 总原则：出题的锚点是**知识点 + 例题**，**不是学生**

**【学生原话（2026-09-22）】**：

> 「出题应该考的是"**知识点是否覆盖到位**"，和**例题是否重复**，"**知识点教到位了没有**"
> ——（**而不是制造学生不存在的错误，或者按照学生习惯来出题**，这样不行
> ——正常的出题都是**以知识点和例子为主，不是以学生为主**）」

**每题过三问**（顺序就是从这来的）：

| # | 问什么 | 依据 |
|---|---|---|
| **①** | 这个知识点**有题考吗**？（覆盖到位了吗） | `进度.md` §2 的 ID 清单 ↔ 题号对照 |
| **②** | 这题**和例题重复吗**？ | §2.2（不弱）+ §2.4（复习≠重考） |
| **③** | 这题要用的东西，**正文教到了吗、教在哪一节**？ | §2.1（不超纲）+ **题不能排在教它的那节前面** |

**学生只在两个地方出现，别搞混**：

| 阶段 | 锚点 | 学生怎么进来 |
|---|---|---|
| **出题（§2）** | **知识点 + 例题** | ❌ **不作为设计依据** |
| **批改（§4）** | **他的代码 + 他的错** | ✅ 一切以他为准 |

> **`易错点台账.md` 的用途随之收窄**：**批改时归因用**；
> **出题时只用于"核对覆盖"**（确保他踩过的坑都被考到），**不用来设计题面**。

> ### ★ 台账记的是**过去**，不是**预测**
>
> **【学生原话（2026-09-22）】**：「**我是动态的，不完全是死的。**」
>
> **不许**用"他以前踩过 X"推出"他还会踩 X"——那是**拿旧数据去预测一个会变的人**。
> **他会自己改方法**：第五课 `d2.py` 里他自己写了 12 行推理链，
> 中间自己发现"思考有误"改掉，跑完自检又自己发现了 `print` 缩进错——
> **【自检】他根本没当成答案用**（先推理 → 再跑 → 才对照）。
>
> **动作**：台账用来**解释已经发生的事**；**不要用它写题面、也不要用它预判他**。

### ⛔ 不许把学生"请进"题面（每一条都真实发生过）

| 不许 | 原样（都出自第六课 / 复习二） |
|---|---|
| **制造错误** | 「**先写** `word[0] = "L"` 跑一次……注释保留，抄上报错原文」 |
| **预告他会犯错** | 「（**注意**第一个元素前面不能有 `-`）」「**三个坑**」「**注意** `count` 数的是出现次数」 |
| **按他的习惯提要求** | 「**注释保留**」——留痕是**他自己的**习惯，不是作业要求 |
| **把方法名给他** | 「**提示**：第 2 条用 `name[0].isdigit()`」 |
| **替他划出答案框架** | 「（注意说准：错的到底是"源码里你怎么写的"，还是"字符串里存着的值"？）」 |
| **假定他会抄** | 「**别照抄**」——运行示例本来就该是他自己跑 |

**为什么一刀切**：**出题是我的事，做题和"发现错误"是他的事。**
我一旦预告坑，就等于**把"发现"这一步替他做了**——而那一步恰恰是学习真正发生的地方。

> **留痕的正确定义**：**他踩了坑，别把它抹掉。** `约定-学生.md` 方针第 4 条原文是
> 「留痕是**自己的**习惯」——**保留规则，不是生产规则**。他真踩了坑，再提醒他保留。
>
> **判据（一句话）**：题面里出现的每一句，**能不能改写成"这题要求你做到 X"**？
> 改不成的（变成"提醒你别做错 Y"），**删掉。**

### 2.1 不超纲 —— 优先级最高

**动作**：出题前对照 `进度.md` §1，只用**已点亮**的语法。要教新东西，先教。
**⚠️ 还要看位置**：这题用到的语法，**正文里"专门讲它"的那一节必须排在题前面**——
「本课要教」≠「题之前已经教过」。（`体检.ps1` 检查「题序」会查这条）
**【事件】** 真题实战一的操作题第 2 题用了第五课的 `for`，而卷子声明只覆盖第 1~4 课。**是学生发现的。**
**【事件】** 第六课 A1 要学生用 `upper()`，而专门讲 `upper` 的 §3.2 排在题**后面 180 行**——
**学生做到第一题就卡住了**。三个旧检查当时全是绿的。
**【自查】** 这题用到的语法，① `进度.md` §1 里点亮了吗？② **正文里讲它的那一节在题前面吗**？

> **"超纲等于提前弄，提前弄会降低知识度。"** —— 学生原话。**宁可不考，也不提前。**

### 2.2 「不弱」的判据

**判据**：**这题允许"抄"吗？** 把例题的数字改一改就能过 → **弱**。
**动作**：至少满足一条 —— **新语法 / 新组合 / 新边界 / 新场景**。
**【事件】** 第二课 B2/B3/B5 是同一知识点的重复 → 无聊 → 敷衍 → **还被误判成"态度问题"**（`旧文档\备忘-归档.md` 批次 2）。
**【自查】** 这题的"新"在哪里？**说不出来就别出。**

### 2.3 新思考的四个来源（判"是不是新题"就查这四条）

| 来源 | 例子 |
|---|---|
| **新语法** | 第一次见 `split` |
| **新组合** | `remove(min(...))`（复习一） |
| **新边界** | `<=` vs `<`、负数整除 `-7 // 2` |
| **新场景** | 切片用在**字符串**上（第三课只对列表用过） |

**这四条之外，就是重考。**

### 2.4 「复习」≠「重考」的操作判据

**判据**：**把这道题的领域词换掉，它还是同一道题 → 重考。**
**【事件】** 第二课考"秒数转时分秒"（`//` `%`），复习一考"苹果分装"——**知识点相同，但场景和目的都变了 → 算复习** ✅
**【事件】** 反过来：`sort` 方向在复习一再问一遍，**那就是重考** ❌

### 2.5 ★ 难度的三个来源不许叠加

| 来源 | 该练什么 | 怎么处理 |
|---|---|---|
| **知识**（没学过） | —— | **超纲，禁止**（见 2.1） |
| **组合**（学过但不熟） | **理解** | **主战场** |
| **细节**（容易漏） | **交付** | **别当理解考** |

**动作**：一道题**主要压一个**。压组合就别同时压细节。
**【事件】** 第五课 F1 判分过严的**根因就是这个**——那是道"细节/概念"题（`print(range(5))` 输出什么），却被当"理解"题判。
**【自查】** 这题主要压哪一个？两个以上 → 拆成两题。

### 2.6 每道题必须能回答"他错了，说明什么" —— ⚠️ **这是"验证项"，不是"锚点"**

> **2026-09-22 降级**：学生指出「**正常的出题都是以知识点和例子为主，不是以学生为主**」（见 §2.0）。
> 本条**保留**，但**它管的是"这题值不值得留"，不是"这题该怎么写"**。
> **不许因为它，就把"他可能怎么错"写进题面。** 诊断是**批改（§4）**的事。

**动作**：**说不出诊断价值的题，不出。**
**【事件】** 第六课 I1（读文档）的参考答案里专门写了「判分说明」——**那就是诊断性被显式写出来的样子。**
**【自查】** 这题他错了，我能不能说出他不会什么？说不出 → 换了。

### 2.7 去重（同一知识点只考一次）

**动作**：出题前过一遍 `进度.md` §2 的已考知识点清单。**换数字/变量名/说法都算重复。**
**【事件】** 第二课 B2/B3/B5。
**【自查】** 这题会在 `进度.md` §2 覆盖哪一行？没覆盖任何一行 → 它没引入新东西。

> ⚠️ **已知张力（未解决）**：本条和"遗忘"冲突 —— 见 §5.3。

### 2.8 每题标【新】/【复习】，验收方式不同

| 题的类别 | 验收 |
|---|---|
| **本课新知识点** | **必须跑通** |
| **复习前面课的知识点** | 可以只**写一句"为什么"**，不必再跑一遍 |

**理由**：已经跑过的东西再跑一遍，提供不了新信息，只会多攒一份重复的痕迹。

### 2.9 改错题必须验证**两头**

**动作**：① 坏代码**确实能跑**，而且**输出确实是错的**；② 修好之后**输出确实是对的**。
**【事件】** 只验证第 2 条不够——那样可能出一道"根本不用改"的题。
**【自查】** 坏代码我跑过吗？它真的报错/输出错吗？改好的我也跑过吗？

### 2.10 每课三道特殊题，一道都不许缺

| 题 | 是什么 | 缺了会怎样 |
|---|---|---|
| **I1** | **读官方文档自学**（我不讲这个点） | 他永远只从 AI 学，**而 AI 会错** |
| **I2** | **改错题** | 少了调试训练（真实开发 80% 在修别人的代码） |
| **I3** | **读代码**（说出它在做什么、为什么） | 他只在写、不在读 —— **读代码是写代码的前置** |

**【事件】** **I3 在第四、五课是 0 题**，而且**没进任何欠账清单** —— 规则落空但没人记账（见 6.3）。
**【自查】** 这课的 I1 / I2 / I3 都在正文里吗？

> **I1 的判分标准（学生定的）**：**看"理解对不对"，不卡"交付齐不齐"。**
> 不强制写代码、不强制贴文档原文、没答全**按理解程度部分给分**。
> 【事件】第五课 F1 初判 2.0，学生提出判分过严，教师重读后改成 3.5。

### 2.11 出题要串联，不要"一个点配一道题"

**动作**：一道题可以同时用**本课新知识 + 前面课旧知识**。后面的课主动回头用前面的内容。
**【事件】** 第二课的毛病就是机械对应 → 20 道互不相干还互相重复的小题。
**"综合题不是超纲，是复习。"**

### 2.12 ★ 参考答案**只给代码，不给讲解**

**【学生原话（2026-09-22）】**：

> 「**答案其实你只要给代码就行了（不需要讲解）。** 我一般**不看参考答案**，我可以直接发给你，
> 然后让你**在对话框里讲**，所以答案这边甚至**只是一个形式**，只要有正确的代码即可……
> **这个文件没有正文重要，记住，没有正文重要**」
>
> 「真有不懂的题，讲解我会找你的，而不是自己在那啃——**有现成的'老师'问，我没必要找讲解**，对吧？」

**动作**：参考答案 = **每题的脚本 + 实测输出**。**到此为止。**

| 写 | 不写 |
|---|---|
| **每题的 `.py` 脚本** | ❌ 讲解 |
| **【自检】+ 真实输出** | ❌ 【他错了 → 说明什么】 |
| （可选）一行"这题的坑在 X" | ❌ 通用规律表、比喻、延伸阅读 |

**§2.6 那条"必须能回答他错了说明什么"没有取消** —— 只是它的**存放位置变了**：
**不写进答案文件，改在批改（§4）里说**。判据还在，交付物简化了。

**为什么这条是对的（不只是省事）**：
1. **讲解的读者是"卡住的人"，不是"还没做的人"。** 学生做之前不该看到讲解，做完又基本不看——
   **它服务的是一个几乎不存在的时刻**。
2. **有老师在场时，讲解应该是对着"他那份代码"讲的**，而不是对着一道假想的题。
   写死在文件里的讲解，**恰好讲不到他真正错的那一步**。
3. **它是最贵的一块输出**（第六课答案 ~1200 行里大半是讲解），而**收益最低**。

**【事件】** 复习二的答案我每题都写了讲解 + 诊断（21.7KB）。
学生看完说"不看参考答案"。**下一课（第七课）起按这条执行。**
**已经写好的（第二~六课、复习一/二）不追改**——学生明确说了"不用改，以后记住就行"。

# 3. 讲课（怎么讲清楚一个概念）

> 这一节**大部分没有硬判据**（见 §8）。下面几条是**从成功案例里反推的**，不是铁律。

### 3.1 概念从一个"会炸的东西"进门，不从定义进门

**动作**：新概念先给一段**会报错的代码 + 报错原文**，再给定义。
**【事件】** 第六课第 1 节就是「**现场看报错**」（`name[0] = "P"` → `TypeError`）。而学生第一课就自己写满报错注释。
> **报错是入口，定义是出口。**

### 3.2 每课开头先立一张「词面陷阱表」

**动作**：列出**这几个中文说法会把你带偏** → 代码里应该用什么。
**【事件】** 第四课 d2：他写 `year / 4 == 0`，不是手滑，是"**整除**"这个词里的"除"字把思路带向了除法。第六课开头因此专门立了一张表。
> **他反复踩的不是"不会"，是"中文词把思路带偏"。**

### 3.3 反直觉的东西必须单独标出来

**【事件】** 第六课 G 组标题直接写着「**这题的重点全在"反直觉"上**」。
**【自查】** 这个知识点里，哪一条是反直觉的？标出来了吗？

### 3.4 ★ 讲了"怎么用"，还要讲"为什么这么设计"

**动作**：每个新概念给一句"Python 为什么这么做"。
**【事件】** 他自己做过这件事——「很像是 monobehaviour 一样的存在，**也是一个积木**」。教师当时把它当**加分项**。
> **它该是要求，不是加分项。** 能自己造比喻 = 概念已经接上了。

### 3.5 C# 类比：**不许用来压缩路线，可以用它解释概念**

**【事件】** 教师曾提议用 C# 类比跳知识点 —— **学生否了**（"计算机语言在我眼里是不同的东西，我该重新学"）。
**【事件】** 但 `$"{x:F2}"` ↔ `f"{:.2f}"` 这种对照他接受。
> **对比是理解工具，不是捷径。会 `$"{x:F2}"` 不等于会 f-string。**

### 3.6 用「留痕」决定讲多细（不是决定考不考）

| 他注释里的信号 | 我该怎么讲 |
|---|---|
| `？`、`不知道`、`为什么`、`我认为这可能错` | ✅ **讲细、多举例、优先回答** |
| `我知道`、`我故意留的`、`后面我改了`、老版本注释 | **讲一遍就够** |
| 没写清楚 | ⚠️ **先问他，不要默认他不会** |

**【事件】** 他代码里的问号就是最准确的缺口清单（`d4.py`："append 是不是不能加脚标？"）。
**【自查】** 关于这一点，他的注释里写了什么？

### 3.7 理论要短，讲完一个点立刻配题

**【事件】** 学生原话：**"代码的学习必须靠敲"**；"第一课做得很好，每个例子都有习题"。

### 3.8 大纲里"了解"级的内容也不能略

**动作**：他定了目标"**不是只要 60 分**" → 选择题的细节必须全覆盖。
**【事件】** 原路线整块漏了**字符串方法**和**第三方库**（`jieba`/`PyInstaller`/`pip`），对照二级大纲才发现。

# 4. 批改与归因（怎么判断他真懂了）

> 这一节是**本次会话挣出来的**。旧文档完全没有。

### 4.1 失分先分性质，三种治法完全不同

| 性质 | 例子 | 治法 |
|---|---|---|
| **概念缺口** | `2**3**2` 右结合不会 | 补知识 |
| **符号看漏 / 粗心** | `bool("0")` 看成 `bool(0)` | 练"**念符号**"的检查动作 |
| **交付不细** | 输出缺 `是否全部及格：` 标签 | 定一个**提交前的检查动作** |

**【事件】** 真题实战一第 5 题。教师把它归成"真值判断没内化"，**学生纠正：是看漏了引号。**
> **把"看漏"判成"没学会"，是让他重学已经会的东西 —— 纯浪费。**

### 4.2 ★★ 要归因"概念没掌握"之前，必须先问"当时你是怎么想的"

**动作**：**先问，再写。**
**【事件】** `bool("0")` 那次，教师**推理**出一个诊断、**没问**，而且**错了**。
**【自查】** 这条归因，是我跑出来的、**问出来的**，还是我想出来的？
> **我看不到他的眼睛怎么扫过选项的。** 归因只能靠他给。

### 4.3 区分「提取失败」和「没学会」

| 信号 | 是 | 治法 |
|---|---|---|
| 他能**复述规则**，但用的时候用错 | 提取失败 | **换个场景再捞一次**（不是重讲） |
| 他答对了却**不敢确定**（"也许是 321"） | 提取失败 | 同上 |
| 他说"**我记忆模糊**" | 提取失败 | 同上 |
| 他**说不出规律**，或说反了 | 没学会 | **重讲** |

**【事件】** 复习一清单的方法论：**"不是遗忘，是知识还在但捞不出来。"**
**【事件】** `复习一\code\bing2.md`：`sort` 方向他答对了，却自己加了句"也许是 321"。

### 4.4 他推翻你 → 先复核自己，再记录

**【事件】** **已经发生 5 次，5 次都对**：`//` 的定义 · 步长措辞 · 出题重复 · 真题超纲 · `bool("0")` 归因。
**【动作】** 先复核；确认他对了就把这次反驳**写进批改**（这是判断力在长出来的证据）。
> **他的判断有时比你的批改更准。**

### 4.5 「他自己修好的」要专门找出来，单独夸

**【事件】** `float()` 返回值（第 4 次自己跨过去）· `<=` 边界（自己发现并修好，还保留旧版本注释对比）。
> **"出过错 → 想清楚 → 自己改掉"比"一次做对"值钱。** 这已经出现 5 次。

### 4.6 「答对了但说不出为什么」必须追问，不能放过

**【事件】** 第五课打擂法：他写 `a = 0` 起手，结论对了，但**理由是运气**（"看来是不行的"）。
**【动作】** 追一句"为什么这样写"——**结论对 + 理由错 = 下一次会错**。

### 4.7 「想错了但自己觉得对」最危险 —— **批改抓不到，靠真题**

**【事件】** 第五课 Q3（`range` 和列表的区别）。他答得挺自信，但是错的。
**【动作】** 这类不能靠批改兜，**只能靠真题（§5.4）暴露** —— 所以真题不是可选项。

### 4.8 分数不是主信号

**【事件】** 判分标准改过两次（第五课 F1 从 2.0 上调 3.5；**I1 的判分标准放宽，见 §2.10**）→ **前四课和后两课的分数不可比**。
**【事件】** 练习均分 ~92，真题 81.3% —— **练习不是考试的好代理**。
**【动作】** 主信号是 `进度.md` §1 的**阶梯格子**（这一级过没过），分数只作过程记录。

### 4.9 ⚠️ 批改**不要追"注释数量"**（2026-09-22 学生提出）

**【学生原话】**：「我随着慢慢掌握错误减少，我开始写得顺利……**注释变少，难道不是我这边开始少踩坑了吗？**」

**答：是。** 全部 6 份批改里，注释**只作为证据**出现（"你的注释就是全部证据"、"以留痕为准，不以错误为准"），
**没有一处把"注释少"当缺点**。

**他真实且唯一的失败模式，台账上只有一条，三次都对得上**：**懒得跑**。
（第二课 B2「预测全对，但整段被注释，实际无输出」· 第二课 B5「要求的两行被注释掉了」·
第四课 B4「文件跑不起来（错误行没注释掉）」）

**动作**：**别追"注释太少"，要追"这题你跑了吗"。**
### 4.10 ★ 批改必须**逐条回答他在注释里提的问题**

**他会直接在代码注释里提问**（不是发消息问，是写在文件里）。

**【事件（真实漏过）】** 第五课 `d2.py` 第 21 行，他写：
> 「自此方法完成。**我每一步都如此写思考过程，你认为如何？**
> **优点很明显，我掌握得稳，缺点也很明显，那就是我会变得很慢。**」

**第五课批改只夸了一句「那 12 行推理过程…是这次质量最高的一题」，没有回答"慢"那个权衡。**
**他在文件里问了一个真问题，没得到回答。**

**动作**：**读他的代码**（本来就该读——批改的第一步是实跑他的文件）。
**他的问题就写在注释里**，读的时候自然撞见，**逐条回答**，答不了的明说答不了。

> ⛔ **不要用关键词去 grep 他的问题**（2026-09-22 学生当场纠正）。
> 我试过一次 `grep '？|?'`，结果是：**照抄的报错原文也带 `?`**（假阳性），
> 而**真正的思考常常不带问号**（例：`# 这段莫名其妙很顺？` 带了，`# 不对。刚才思考有误` 没带）。
> **问题不是"符号"，是"他在想什么"——那只能读出来。**

# 6. 每轮流程（照这个走）

### 6.1 出题前（第 0 步）—— ★ **日常每课走这里**

> **这是日常清单。** 「第一次接手」（零上下文 / 换了 AI）才需要全读，
> 那份一次性清单在 `接手.md` §3 —— **约 2,900 行，是这里的 2 倍，别每课都走。**

```
① 跑 体检.ps1          —— 文档一致性，红了先修，别往下走
② 跑 对账.ps1          —— 答案里印的输出来自实跑还是来自记忆（出题后、发出去之前）
③ 读 进度.md §2        —— 已考知识点（去重的唯一依据）
④ 读 进度.md §1        —— 能用的语法范围（不超纲的唯一依据）
⑤ 读 易错点台账.md —— 他踩过的坑
⑥ 读 备忘.md 最新一条  —— 上一个会话干到哪了
```

### 6.1.5 ★ 出题的顺序：**先把所有题面写完，再写答案**

**【学生原话（2026-09-22）】**：

> 「**其实参考答案没有必要那么准的**，你实际上也会跑，我看的也少——
> **题目全部弄完之后再弄答案也行。**」

**动作**：分**两遍**，不要一题一题地"出题 → 写答案 → 出下一题"。

| 遍 | 只做 | 不做 |
|---|---|---|
| **第一遍** | 把**全部题面**（要求、运行示例、坑）一次写完 | **不碰答案** |
| **第二遍** | 一次性写**全部**参考脚本 → 一次跑完 → 照实抄输出 | 不改题面 |

**为什么这样更快**：一题一题做，每道题都要**重新进入"写答案"的上下文**；
批量做，脚本一次写完、一次跑完，**几乎不增加时间**。

**为什么这样还更对**：
- **题面是学生唯一看到的东西**——它值得单独一遍、把注意力全放在"要求说不说得清"上；
- 写答案时会**不自觉地迁就"我怎么写顺手"**，反过来把题面写窄了。分两遍就没有这个污染。

**【事件】** 复习二就是按这个顺序做的：先写完 13 道题面，再一次性写 13 个脚本、一次跑完。
**甲组的输出一个都没进正文**（正文只有"运行示例"）——**答案全在参考答案里**。

> **例外（只有一种）**：题面里如果写了"**运行示例**"，那是**给学生的输入样例**，属于题面，第一遍就要写。
> 但**不要**在题面里印【自检】——那是答案的事。

### 6.0 两个脚本（本项目的 `test/`）

#### 怎么跑（**唯一一份跑法，别处只准指到这里**）

```powershell
# 在本目录下跑。两步都不需要 -ExecutionPolicy。
.\体检.ps1              # 加 -短 = 只打异常行 + 汇总（省 token）
.\对账.ps1              # 默认静音；加 -响亮 = 每题都打
```

| 项 | 值 |
|---|---|
| **用哪个解释器** | **`powershell`（Windows PowerShell 5.1）**。本机**没有 `pwsh`**（PowerShell 7）——别照着脚本头部的 `pwsh -File` 敲 |
| **工作目录** | **本项目根目录**（两个脚本都靠 `$PSScriptRoot` 定位，但 `对账.ps1` 要能读到课次文件夹） |
| **编码** | 两个 `.ps1` **必须存成 UTF-8 with BOM**（见本节末尾） |

> ⚠️ **AI 的工具环境可能禁止起子进程** —— `对账.ps1` 会用 `Start-Process` 拉起 Python。
> 如果报 `Access is denied`，那是沙箱/权限，不是脚本坏了：**明说"这一条我没验证"，不要假装跑过了。**

#### `体检.ps1` —— 9 项检查，**每项有一个稳定「键」**（引用它时写 检查「<键名>」）

| # | 键 | 查什么 |
|---|---|---|
| 1 | **知识点 ID** | `易错点台账.md` 的【归属】↔ `进度.md` §2 |
| 2 | **课次表** | `进度.md` §3 ↔ 实际文件夹 + 四件套齐不齐 |
| 3 | **命名规范** | 文件名 ↔ `模板.md` §一（含非 md 散件） |
| 4 | **交叉引用** | 反引号包着的 `<文件名>.md` / `.ps1` 到底在不在 |
| 5 | **引用标** | `X.md §N` 的节号在不在 + `检查「<键名>」` 在不在 + **`规则N` 必须登记在 §📇** |
| 6 | **体量** | 根目录文档行数/字符数 + 热集（**只报，不判红**） |
| 7 | **出题抄例题** | 习题串 ↔ 例题串（`§2.2` 那半条能机器查的） |
| 8 | **文档地图** | 根目录每份 `.md` 都在 `接手.md` §6 地图里 |
| 9 | **题序** | 习题用到的方法，本课**专门讲它**的那一节有没有排在题**前面** |

**全绿退出码 0，有 ❌ 退出码 1。跑完把输出贴进 `备忘.md` 的会话条目。**

> **为什么引用检查项要写「键」不写序号**：序号会随增删漂移——2026-09-22 删掉旧检查 3 之后，
> 全库 5 处 `检查 N` 静默指错了一位，`体检` 自己发现不了。**键是稳定的，序号不是。**

#### `对账.ps1` —— 参考答案里的脚本真跑一遍，和文档里印的输出逐字比

它治的是一个很具体的病：**【自检】里的输出来自记忆，而不是来自实跑**——
2026-09-22 就抓到过（附录里 `"abc".splits(",")` 的报错原文我凭印象写少了后半句，
而那张表标着"全部实跑抓下来的"）。**出题后、发给学生之前必须跑，绿了才算完。**

> ⚠️ **它知道自己覆盖不到什么，并且会说出来**（2026-09-22 补）：
> 它按 `A1`/`甲1` 这种**题号**抽题，而且只抽"**一个能跑的脚本 + 一份实测输出**"的配对。所以：
>
> | 覆盖不到 | 为什么 | 现在怎么办 |
> |---|---|---|
> | **第一课** | 没有单独的参考答案文件（习题自检内联在正文里） | 四件套例外，见 `体检.ps1` 检查「课次表」 |
> | **`真题实战\` 的卷子** | 题型不符 A1 编号：选择题只有字母、操作题是"填空"、综合题要 stdin | **脚本只对得上能自动跑的那几节，其余逐条报「未覆盖」** |
>
> **关键**：以前它是**静默跳过**的（而且提示语还错说是"已知例外：第一课"），
> 于是汇总照样打"绿"。**现在只要某个文件夹有答案却抽不到题，就一定会被打出来**——
> **"绿"必须同时报出"实际覆盖了几个文件夹"。**

| 脚本 | 治什么 | 什么时候跑 |
|---|---|---|
| `体检.ps1` | 文档之间**对不上**（引用、命名、体量、出题抄例题） | **每个会话开工时** |
| `对账.ps1` | 文档**自称实跑**但其实是编的 | **每次出完题 / 改完答案** |

> **三个抑制器**（都跟检查有关，不知道就会踩）：
> - **`（拟）`** = 抑制器：`体检.ps1` 检查「交叉引用」把**反引号包着的文件名**当"必须存在"，计划中的加 `（拟）` 才不报红。
> - **`<尖括号>`** = 抑制器：要说明**格式长什么样**时（例：`<文件名>.md`、`检查「<键名>」`），
>   用尖括号包住占位部分，检查「交叉引用」和检查「引用标」就**当它是示例，不当引用**。
> - **`（整理过）`** = 抑制器：`对账.ps1` 把**【自检】/实际输出**当"原样跑的输出"，**故意展示报错**、
>   把 traceback 整理成一行的那种块，标记行里写 `（整理过）` 才不报红（例：第二课 B2、第三课 B3）。

> ⚠️ 两个 `.ps1` 都**必须存成 UTF-8 with BOM**。Windows PowerShell 5.1 读无 BOM 的 UTF-8 会按 ANSI 解，中文全乱、直接报 `Unexpected token`。改完它如果中文输出变乱，就是 BOM 被吃掉了。

### 6.2 他交了之后

**① 先实跑他的文件**（不要凭读代码下结论）。
**② 提交即冻结**：他说了"提交"之后 ——

| | |
|---|---|
| **文件** | **冻结**，不再要求他改 |
| **分数** | **冻结**，不接受"修好了加分" |
| **错误** | **留在文件里**，作为他未来的路标 |

**【事件】** 学生原话："**你也没见过学生能后面改卷子分数的吧？**" —— 这个类比是准的。
**配套**：既然提交后不能改，"**跑一遍**"就必须发生在**提交之前**。
**【事件】** 第四课 `b4.py` 跑不起来（`if x = 5` 没注释），**按提交时的状态扣了 3 分**。
**最优解**：错误行**注释保留** → 留痕 ✅ + 文件能跑 ✅。

**③ 他跳题给了理由 → 看理由对不对**（不强迫他先跑一遍）
理由写对了 → 跳过，不浪费时间；**写错了 → 立刻暴露缺口，比做十道题都有用。**

# 8. ★ 认账：这些地方**没有判据**

> **这一节和上面的规则一样重要。**
> 写不出判据的东西，**明写"没有判据"，不要用漂亮话填**——那样只会让下一个 AI 以为它有据可依。

| 事情 | 为什么没有判据 |
|---|---|
| **"这个概念我讲清楚了吗"** | 没有可跑的检查。**只能靠他的反应 + 后续题目暴露。**§3 那几条是从成功案例反推的，**不是铁律** |
| **"他到底掌握到什么程度"** | 只有间接信号（注释、答案措辞、错误的重复次数）。**判错的风险一直存在** |
| **"课与课之间的节奏"** | 什么时候可以快、什么时候必须停，靠现场判断 |
| **"这道题难不难"** | 难度是相对的，随他的状态变 |

**遇到这几件事时**：**照 §0 那句自问** ——"我是在让他更能自己判断，还是在让我这一课更好看？"
**以及 §4.2** —— 要下判断之前，**先问。**

# 9. 文档膨胀了怎么办

> **先理解"吃力"分三层**（2026-09-22 实测）：

| 层 | 什么先坏 | 触发点 | 报不报错 |
|---|---|---|---|
| **① 读不进**（硬） | 一次 `read` 读不完 | **单文件 > 2000 行**；总读入 > 窗口 | 报 |
| **② 读得进但记不住**（中，**最危险**） | 长文档**中段被跳过** | 读入 **> 60K token** 起 | **不报** |
| **③ 每次重读**（软） | 成本和耐心 | 热集每课全读 | 不报 |

### 9.0 ★ 省 token 的五条纪律（2026-09-22，**学生要求**）

**【学生原话】**：「不然**不仅长，我这边 token 实际上也很难吃得消**。」

> **先记住这件事**：**外包（子模型）不省 token** —— 它读的东西**也在同一个账户上计费**，
> 只省我的上下文窗口。**省 token 只有两条：我少写、我少读。**

| # | 纪律 | 省在哪 |
|---|---|---|
| **1** | **禁止整文件读**：先 `grep` 定位 → 再 `read` 指定 `offset`/`limit`。**只有"第一次接手"（`接手.md` §3）才全读** | 每课省几百到上千行**输入** |
| **2** | **易错点台账不整读**：先 `grep '^## '` 打出那 20 条标题，或直接用【归属】ID 去 `grep`；**命中哪条才读那一条** | 每课省 ~400 行 |
| **3** | **参考答案只给代码**（见 §2.12） | 写答案省 ~40% **输出** |
| **4** | **会话条目压到三格**（读了什么 / 体检 / 没结的）；**叙事、比喻、原话不进条目**，那些进 §二决策记录 | 每会话省 ~60 行读写 |
| **5** | **热 / 冷分层**：标了 `【事件】` 的、旧决策批次、真题记录、大纲对照 = **冷**，**查才读**，不"顺手全读" | 避免无意识全读 |

**配套（已做）**：`体检.ps1 -短` 与 `对账.ps1`（默认静音）——**体检 60 行 → 40 行，对账 100+ 行 → 16 行**。
跑脚本的输出**也是要贴进对话的**，别让它白烧 token。

> **## 9.0.1 不做"整课重写"，只做"定点 `edit`"**
>
> **【事件】** 第六课重写时我**重写了整个答案文件**（~29KB 输出）——那是最贵的操作之一，
> **只在"旧版整体违规、非重写不可"时才值得**。新课时是新文件，天然没有这个问题。

> **动作**：改已有文档**默认用 `edit` 打补丁**；确实要整写，**在会话条目里写明为什么整写**。

> **暂缓的一条**：机器生成"每课摘要"（一条命令打出本课 ID + 相关坑 + 未考邻接点）。
> **等热集再涨一轮再做**——现在做是提前造工具。

> **第五课那三笔欠账就是这么来的**：`语法速查` 的维护说明埋在 700 行文档的末尾，**没被读到**。
