## 1. 这是什么

一个**学 Python 的自学项目**：学生（人类，有 Unity/C# 经验，但按新手重新学 Python）× 教师（AI，会换人）。

**目标**：过**计算机二级 Python**，而且**不是只要 60 分**——学生原话：

> "这个以后是我吃饭的东西，不只是过二级，**我二级也不是只要 60 分，我要能多高多高。**"

**方式**：**教师写课 + 出题 → 学生写代码 → 教师批改 → 同步文档 → 下一课。** 一课一个文件夹。

## 2. 分工

| | 做什么 |
|---|---|
| **学生** | 写代码 · **留痕**（错误行注释保留）· 拍板规则 · **可以推翻教师的任何判断**（已经推翻过 5 次，5 次都对） |
| **教师 AI** | 写课 · 出题 · 批改 · 维护文档 · **不许擅自改 `学习规定-AI.md` / `约定-学生.md`** |

**一句话记住这个学生的特点**：
- 代码里**注释写得极多**，`？`、"我记忆模糊"、"为什么" 就是他的缺口清单——**先读注释，再读代码**（`学习规定-AI.md` §3.6）
- 他**会自己发现错误并修好**，而且会**在卷子上写出题人的错**。**不要把他当被动接受者。**

## 6. 文档地图

```
python学习\
├── 接手.md          ← 本文档（新教师先读它）        【全读一次】
├── 学习规定-AI.md    ← **约束教师 AI** + **规则编号对照**（旧编号回这查）        【按节查】
├── 约定-学生.md      ← **约束学生**                              【查：判"能不能要求他"时才开】
├── 进度.md          ← 现在到哪了                                【按节：§1 §2 每课读；§3~§7 收尾时改】
├── 易错点台账.md    ← **学生踩过的坑**                          【批改时归因用；**出题时只用来核对覆盖，不拿它设计题面**（§2.0）】
├── 备忘.md          ← 会话流水（只追加）                        【只读最新一条】
├── 模板.md          ← 正文 / 参考答案 / 批改 / 清单 的格式        【不读：写课时照抄骨架】
├── 体检.ps1         ← **本项目的 `test/`**：9 项检查              【跑，不读】
├── 对账.ps1         ← **答案印的输出来自实跑还是记忆**             【跑，不读；出完题必跑】
├── 愿景.md          ← 学生的私人备忘（见下）                      【我不读】
├── 旧文档\          ← 作废的旧版 + 瘦身归档（含 `语法速查.md` / `语法速查-报错.md`）【查才读】
│
├── 第一课\ … 第六课\    ← 每课：正文 + 作业批改 + 参考答案 + code\
├── 复习一\ 复习二\      ← 复习课（含必交的 code\_清单.md）
└── 真题实战\            ← 真题卷 + 答案 + 批改 + code\
```

> ### ★ `【】` 里的是"**怎么读**"——**这是这张地图最重要的一列**
>
> **判据（学生 2026-09-22 问的就是这个）**：
> > **全读 = 这份文档里，"下一句话"依赖"上一句话"。**
> >
> > - **跳读会漏掉前提 → 全读**（有顺序的清单、叙事）
> > - **每节都能独立回答"什么时候查我" → 按节查**（规则、条目、表格）
>
> **于是有五种读法**，不是两种：
>
> | 读法 | 什么时候 | 例 |
> |---|---|---|
> | **全读一次** | 第一次接手 / 换 AI / 隔很久 | `接手.md`（**有顺序的清单，跳步会漏**） |
> | **按节查** | 每次出题/批改 | `学习规定-AI.md`（每条规则**互相独立**） |
> | **全读** | 出题/批改前 | `易错点台账.md`（20 条，都是他真踩过的） |
> | **照抄骨架** | 写课时 | `模板.md`（**用的时候才打开**） |
> | **不读 / 跑** | | 学生的三份、两个脚本、`愿景.md` |
>
> **⚠️ 这张地图必须完整**：**根目录每份 `.md` 都要在这里出现**——
> 新增文档而没想过"它该怎么读"，就是给下一个 AI 埋坑。**`体检.ps1` 检查「文档地图」会查这件事。**

> **关于 `愿景.md`**：那是学生自己写的"这套学习项目以后可能变成什么"的备忘。
> **它不在任何同步清单里，教师不要改它、不要"帮忙完善"、也不要拿它当教学依据。**
> **你只需要知道两件事**：
>
> 1. **它存在**，所以别把它当成一份需要维护的文档；
> 2. **它解释了为什么留档纪律这么严**——错误的注释保留、AI 判错也留痕、提交即冻结，
>    **有一半是为了让这份学习记录保持完整**。所以你在批改时**不要把"不体面"的部分洗掉**：
>    该写"我判错了"就写。
>
> **注意**：**每课的文件夹是"记录"，只会越积越多，不要合并、不要精简**（`学习规定-AI.md` §6.2：提交即冻结）。

## 8. 三条给学生的话（不是规矩，但有用）

1. **他写代码时会留痕**——错误行注释保留。**保留是对的，但要提醒他注释掉**，否则文件跑不起来（第四课 `b4.py` 因此扣了 3 分）。
2. **他会说"我数学不行/算法不行"**——**已经纠正过两次**。那是"急着下笔 + 需要多检查"，**不是天赋问题**。
3. **他的自我判断有时比教师的批改更准**（`bool("0")` 那次）。**遇到他反驳，先复核自己。**
