# 〇、★ 陷阱表（最先看这一节）

> **为什么放最前面**：报错是**写完之后**才知道错了；
> 这一节管的是**不报错就错了**的情况——**更难发现，因为程序看起来很对。**

## 〇.1 词面陷阱（中文说法把人带偏）

> **来源**：第四课 d2（闰年）。学生写 `year / 4 == 0`，不是手滑，
> 是"**整除**"这个词里的"**除**"字把思路带向了除法。

| 中文说法 | 字面容易想到 | **代码里应该用** |
|---|---|---|
| **能被 4 整除** | 除法 `/` | **`% 4 == 0`** ← 最反直觉的一条 |
| 还剩几个 / 余下多少 | — | `%` |
| 能装满几盒 / 有几个完整的 | — | `//` |
| 是不是偶数 | — | `% 2 == 0` |
| 是不是奇数 | — | `% 2 == 1` |
| 个位数是几 | — | `% 10` |
| 去掉个位 | — | `// 10` |
| 十位数是几 | — | `// 10 % 10` |
| 把秒数拆成时分秒 | — | `// 3600`、`% 3600 // 60`、`% 60` |
| **切分 / 拆开 / 分成几瓣** | 切片 `[a:b]` | **`split()`**（第六课） |
| **拼起来 / 接起来 / 连成一串** | `+` 一个个加 | **`join()`**（第六课） |
| **去掉空格** | `replace(" ", "")` | **`strip()`** ← 而且它只管**首尾**（第六课） |
| 找某个词在不在 | 只能 `in` | `find()`（要位置）、`count()`（要次数）（第六课） |
| 这段文字**是不是**数字 | 用 `int(s)` 试一下 | `s.isdigit()`（第六课） |

> **一句话**：**"整除"在代码里不是除法，是"余数为 0"。**
>
> **写完这类题，拿一个具体数字代进去念一遍**：
> `2024 % 4 == 0` → "2024 除以 4 余数是 0" → 念得通就是对。
> `2024 / 4 == 0` → "2024 除以 4 等于 0" → **念不通，明显错了。**
>
> **这个"念一遍"的动作，比记住任何规则都有用。**

## 〇.2 符号级陷阱（写和**读题**都会踩）★ 本次新增

> **来源**：真题实战一第 5 题。学生把 `bool("0")` 看成 `bool(0)` 而答错。
> **他的原话**："我是下意识看到的 0 没注意引号…… **恰恰因为知识总结没啥问题，
> 0 本身输出就是 false，但字符串输出是 true——这也是人才会犯的错误，AI 很注意双引号在不在。**"
>
> **这条很重要**：这类错**不报错、也不代表没学会**，但**考试照样扣分**（选择题就是这么丢的）。

| 你以为看到的 | 实际是 | 区别 |
|---|---|---|
| `bool(0)` | **`bool("0")`** | 引号在不在 → **`False` vs `True`** |
| `/` | **`//`** | 小数 vs 整除 → **`3.5` vs `3`** |
| `=` | **`==`** | 赋值 vs 比较 |
| `("苹果","香蕉")` | **`["苹果","香蕉"]`** | **元组** vs **列表**（类型不同，输出一样！） |
| `s[3,5]` | **`s[3:5]`** | **逗号**建元组 vs **冒号**切片 |

> **解法只有一个动作：读题/写题时，把符号念出来。**
> - 念"**引号零**"而不是"零"
> - 念"**整除二**"而不是"除二"
> - 念"**等号等号**"而不是"等于"
>
> **和〇.1"念一遍"是同一个动作，只是念的对象从"中文词"换成了"符号"。**
>
> **为什么这一条对 AI 没意义、对人很有意义**：AI 不会漏看一个引号。
> **所以这类错误只能靠人自己的检查动作兜住。**
> 具体事件见 **第三节第 20 条**。

# 一、按任务查（★ 最常用的一节）

> 遇到问题时想的是"我要做什么"，不是"我要用哪个函数"。所以从这一节开始找。

## 输出与输入

| 我想…… | 用什么 | 例子 |
|---|---|---|
| 在屏幕上输出东西 | `print()` | `print("你好")` |
| 输出**带变量的句子** | **f-string** | `print(f"我叫{name}，今年{age}岁")` |
| 输出保留几位小数 | `:.2f` | `print(f"{price:.2f} 元")` |
| 输出一个空行 | `print()` | `print()` |
| 从键盘读输入 | `input()` | `name = input("请输入名字：")` |
| 把输入变成**整数** | `int()` | `age = int(input("年龄："))` |
| 把输入变成**小数** | `float()` | `p = float(input("价格："))` |

> ⚠️ **`input()` 读进来的永远是字符串。** 要算数就必须转换。
> ⚠️ **`int()` / `float()` 的返回值必须接住**，见第三节第 1 条。

## 看类型

| 我想…… | 用什么 | 例子 |
|---|---|---|
| 看某个东西是什么类型 | `type()` | `print(type(24))` → `<class 'int'>` |

## 列表（一堆数据）

| 我想…… | 用什么 | 例子 |
|---|---|---|
| 建一个列表 | `[]` | `fruits = ["苹果", "香蕉"]` |
| 建一个空列表 | `[]` | `box = []` |
| 知道**有几个** | `len()` | `len(fruits)` → `2` |
| 取**第 1 个** | `[0]` | `fruits[0]` |
| 取**最后一个** | `[-1]` | `fruits[-1]` |
| 取**某一段** | 切片 | `fruits[1:3]` |
| 取**前 n 个** | `[:n]` | `fruits[:2]` |
| 取**从 n 开始到结尾** | `[n:]` | `fruits[2:]` |
| **倒过来** | `[::-1]` | `fruits[::-1]` |
| 每隔几个取一个 | `[::2]` | `fruits[::2]` |
| **复制**一份 | `[:]` | `b = a[:]` |
| **改**其中一个 | `[i] = 值` | `fruits[1] = "葡萄"` |
| **加到末尾** | `.append()` | `fruits.append("橘子")` |
| **插到某个位置** | `.insert()` | `fruits.insert(0, "西瓜")` |
| **按值删** | `.remove()` | `fruits.remove("香蕉")` |
| **删最后一个**（并拿到它） | `.pop()` | `last = fruits.pop()` |
| **按下标删** | `del` | `del fruits[0]` |
| **求和 / 最大 / 最小** | `sum` `max` `min` | `sum(scores)` |
| **排序**（不改原来的） | `sorted()` | `sorted(nums)` |
| **排序**（改原来的） | `.sort()` | `nums.sort()` |
| 判断**在不在里面** | `in` | `"香蕉" in fruits` → `True` |

## 循环（重复做事）

| 我想…… | 用什么 | 例子 |
|---|---|---|
| **重复 n 次** | `range(n)` | `for i in range(5):` → 0 1 2 3 4 |
| 从 a 到 **b-1** | `range(a, b)` | `range(1, 6)` → 1 2 3 4 5 |
| **隔一个取一个** | `range(a, b, 2)` | `range(1, 10, 2)` → 1 3 5 7 9 |
| **把列表/字符串一个个拿出来** | `for x in 序列` | `for f in fruits:` / `for c in "abc":` |
| **累加**（求和） | **`total = total + n`** | 见第四节死格式 |
| **数个数** | **`cnt = cnt + 1`** | 上面那个 |
| **找最大** | 打擂法，**从 `nums[0]` 起打** | 上面那个 |
| **不知道要循环几次** | `while 条件:` | 折纸、猜数字 |
| **提前跳出整个循环** | `break` | 找到了就走 |
| **跳过这一轮，继续下一轮** | `continue` | 不想要的那个不管 |

> ⚠️ **`range()` 只吃整数，不吃字符串。**
> `range("abc")` → `TypeError: 'str' object cannot be interpreted as an integer`
> **想一个个拿字符串的字符，直接 `for c in s:`。**（第五课 C3 踩过这个坑）
>
> ⚠️ **`<` 还是 `<=`，必须和起点配套**（第五课 d1）：
>
> | 起点 | 边界 | 打印和加的顺序 | 输出 |
> |---|---|---|---|
> | `a = 1` | `while a <= 5:` | 先打印、后加 | 1 2 3 4 5 ✅ |
> | `a = 0` | `while a < 5:` | 先加、后打印 | 1 2 3 4 5 ✅ |
> | `a = 0` | `while a <= 5:` | 先加、后打印 | **1 2 3 4 5 6** ❌ 多一个 |
>
> ⚠️ **`print` 和 `break` 谁在前，决定谁执行。**
> `print` 写在 `break` 后面 → 那一轮**不会被打印**。
> 这**不是** `break` 有"不带当前元素"的性质（第五课 E1 猜的是这个）——**纯粹是顺序**。

## 数字

| 我想…… | 用什么 | 例子 |
|---|---|---|
| 加 / 减 / 乘 | `+` `-` `*` | `7 * 2` → `14` |
| **除**（结果一定是小数） | `/` | `7 / 2` → `3.5` |
| **整除**（向下取整） | `//` | `7 // 2` → `3` |
| **取余数** | `%` | `10 % 3` → `1` |
| **幂** | `**` | `2 ** 8` → `256` |
| 判断**相等** | `==` | `"24" == 24` → `False` |
| 比大小 | `>` `<` `>=` `<=` | `max(spend) > 50` → `True` |
| 文本 → 数字 | `int()` `float()` | `int("24")` → `24` |
| 数字 → 文本 | `str()` | `str(24)` → `"24"` |
| 四舍五入 | `round()` | `round(3.9)` → `4` |

> ⚠️ **优先级两条（真题一答错过，见 `进度.md` §4）**：
> - **`**` 是右结合**：`2 ** 3 ** 2` = `2 ** (3 ** 2)` = **512**，不是 64
> - **`*` 先于 `+`**：`"a" + "b" * 2` = `"a" + "bb"` = **`"abb"`**，不是 `abab`

# 四、语法速查表（传统版）

## 字符串与输出

```python
print("你好")
print(f"{name} 今年 {age} 岁")
print(f"{pi:.2f}")            # 保留 2 位小数
print(f"{a} + {b} = {a + b}") # {} 里可以放算式
```

## 输入与转换

```python
name = input("名字：")                    # 永远是字符串
age  = int(input("年龄："))
price = float(input("价格："))
type(x)     int(x)     float(x)     str(x)     round(x)
```

## 列表

```python
fruits = ["苹果", "香蕉", "橘子"]
empty  = []

len(fruits)          # 3

fruits[0]            # 第一个
fruits[-1]           # 最后一个

fruits[1:4]          # 下标 1~3    含头不含尾
fruits[:3]           # 前三个
fruits[2:]           # 从下标 2 到尾
fruits[:]            # 整个的副本
fruits[::2]          # 隔 1 个取 1 个
fruits[::-1]         # 反转

fruits[1] = "葡萄"    # 改

fruits.append("橘子")        # 加末尾
fruits.insert(0, "西瓜")     # 插到下标 0
fruits.remove("香蕉")        # 按值删
last = fruits.pop()          # 删末尾并返回
del fruits[0]                # 按下标删

sum(scores)   max(scores)   min(scores)
sorted(nums)     # 返回新列表，不改原来的
nums.sort()      # 改原列表

"香蕉" in fruits      # True / False
```

## 循环

```python
# for + range
for i in range(5):         # 0 1 2 3 4
for i in range(1, 6):      # 1 2 3 4 5
for i in range(1, 10, 2):  # 1 3 5 7 9

# for 遍历序列
for f in fruits:           # 列表
for c in "abc":            # 字符串

# 累加器（死格式）
total = 0
for n in nums:
    total = total + n

# 计数器（死格式）
cnt = 0
for n in nums:
    if n > 10:
        cnt = cnt + 1

# 找最大（打擂法：从 nums[0] 起打）
big = nums[0]
for n in nums:
    if n > big:
        big = n

# while（不知道要几次时用）
a = 0
while a < 5:
    a = a + 1

# 干预
break        # 跳出整个循环
continue     # 跳过这一轮
```
