## 1. 函数返回值必须**接住** ✅ 已解决

**发生时间**：第三课 d4 → 复习一 丙3 → 复习一 乙1 → **第四课 b3（自己解决）**
**【归属】1.5**（`int()`/`float()`/`str()` 转换）· 字符串版本见 **4.2**

```python
a = input("请输入价格")
float(a)          # ❌ 白写了，结果被丢掉
```

**`float(a)` 不会改变 `a`**，它只是算出一个新值交给你。

```python
a = float(input("请输入价格"))     # ✅ 接住
```

**通用规律：**

| | 例子 | 改原来的吗 |
|---|---|---|
| **函数** | `float(x)` `int(x)` `str(x)` `sorted(x)` `len(x)` `sum(x)` | ❌ **不改，返回值必须接住** |
| **方法** | `x.append()` `x.insert()` `x.remove()` `x.sort()` | ✅ **改自己，不用接** |
| 例外 | `x.pop()` | 既改自己，**又返回**被删的那个 |

> **阴在哪**：这个错误**不报错**。`print(f"{price} 元")` 输出看起来完全正常，
> 因为字符串 `"19.9"` 和浮点数 `19.9` 打印出来长得一样。
> **只有等拿它算数的时候才会炸。**
>
> ⚠️ **第六课会再考一次（换了马甲）**：所有字符串方法（`upper` / `strip` / `split`…）
> **都返回新串，都不改原来的**。**同一个坑的字符串版本。**

## 2. `insert(0, ...)` 才是插到**开头**

**发生时间**：第三课 d2
**【归属】5.6**

```python
fruits = ["Apple", "Banana", "Orange"]
fruits.insert(3, "Watermelon")    # ❌ 加到了末尾
```

**`insert(下标, 值)` 的准确含义**：把值插到**那个下标的位置上**，后面的往后挪。

| 写法 | 效果 |
|---|---|
| `insert(0, x)` | **最前面** |
| `insert(2, x)` | 插到下标 2 的位置 |
| `insert(len(a), x)` | **末尾**（等于 `append`） |

## 4. 步长 N = **隔 (N-1) 个**取一个

**发生时间**：第三课 c3（**学生指出教师正文措辞有歧义**）
**【归属】5.3**

| 写法 | 步长 | 取到的下标 | 说法 |
|---|---|---|---|
| `a[::2]` | 2 | `0, 2, 4` | **隔 1 个**取 1 个 |
| `a[::3]` | 3 | `0, 3, 6` | **隔 2 个**取 1 个 |

> ⚠️ **"每 2 个取 1 个"这种说法要避免**——它能读成"步长 2"，也能读成"跳过 2 个"。
> **只要说法有歧义，就回到下标去看。下标不会骗人。**

## 6. `//` 是**向下取整**，不是"砍掉小数"

**发生时间**：第二课 A1（**学生问出这个问题，教师原文写错了**）
**【归属】1.2**

```python
-7 // 2         # -4   向下取整
int(-7 / 2)     # -3   截断（向零取整）
```

**C# 的 `-7 / 2` 是 `-3`，Python 的 `-7 // 2` 是 `-4`。同一个算式两个答案。**

`%` 也受影响：`-7 % 3` 在 Python 里是 `2`，在 C# 里是 `-1`。

> 正数时看不出来，**负数时才分家**。

## 10. 不要用内置函数名当变量名

**发生时间**：第二课讨论（`int = (age)`）
**【归属】0.3**

Python 里有 **151 个**内置名字，它们**不是关键字，可以被覆盖**：

```python
sum = 10
sum([1, 2, 3])     # TypeError: 'int' object is not callable
```

**最容易被顺手用掉的**：`list`、`dict`、`sum`、`max`、`min`、`input`、`id`、`type`。

| 别写 | 改写 |
|---|---|
| `list = [...]` | `nums = [...]` |
| `sum = 0` | `total = 0` |
| `max = ...` | `maximum` |
| `input = ...` | `user_input` |

> **`del sum` 就能恢复**——内置函数没坏，只是被你的名字挡住了。

## 11. ⚠️ 转换不要**滥加**

**发生时间**：复习一（`jia3` / `yi3` / `yi1` 三处）
**【归属】1.5**

当时的倾向是：**不确定就加个 `int()` / `float()`**。

| 位置 | 写法 | 情况 |
|---|---|---|
| `jia3.py` | `float(thickness*(2**times))` | **多余**（本来就是浮点） |
| `yi3.py` | `sum(int(scores))` | **报错**（`int()` 吃不了列表） |
| `yi1.py` | `float(a)` 单独一行 | **白写**（没接住） |

**这个倾向是从第 1 条那个坑里长出来的**——那次是"该转换没转换"，所以到处加。
**方向对，但矫枉过正了。**

> ### 规律：转换只加在「数据的来源」上
>
> | 该加 | 不该加 |
> |---|---|
> | `input()` 的结果 | 列表（`int(scores)` ❌） |
> | 字符串字面量 `"24"` | 算式的结果（本来就是数字） |
> | 从文件/网络读进来的文本 | **已经转换过的值** |
>
> **判断法**：问自己"**这个东西现在是什么类型？**"
> - 不知道 → 先用 `type()` 看一眼，**别猜着加转换**

## 12. 这些名字要背牢

**发生时间**：复习一（`yi4` 忘了 `append`、`bing2` 不确定 `sort` 方向）
**【归属】5.6 / 5.7 / 5.10**

**真实的提取失败** —— 不是不会用，是**想不起名字/方向**。

| 名字 | 意思 | 记忆点 |
|---|---|---|
| `append(x)` | **加到末尾** | append = "附加"（**不是 `end`**，Python 里没有 `list.end()`） |
| `insert(i, x)` | 插到下标 `i` | `insert(0, x)` 才是插到**开头** |
| `remove(x)` | 按**值**删 | |
| `pop()` | 删末尾并**返回**它 | |
| `sort()` | **原地**排序，**默认升序** | |
| `sorted()` | **返回新列表**，默认升序 | |

> **`sort()` 默认升序（1 2 3），不是降序。** 要降序是后面课的内容。

## 13. `and` / `or` 的返回规则 ★★

**发生时间**：第四课 e1（**说反了**）→ **真题一答对，修好了**
**【归属】2.13**

> **一句话记法：往右走的条件 —— `and` 看到【真】，`or` 看到【假】。**

**这四行背下来就不会错**（左边真假 → 往右走吗 → 返回什么）：

| 式子 | 左边 | 往右走吗 | 结果 |
|---|---|---|---|
| `5 and 3` | 真 | ✅ 走 | **`3`** |
| `0 or "abc"` | 假 | ✅ 走 | **`"abc"`** |
| `"" and 5` | 假 | ❌ 停 | **`""`** |
| `"abc" and 5` | 真 | ✅ 走 | **`5`** |

**为什么容易记反**：直觉上会想成"和/或的**结果**"，但实际是**"挑一个操作数"**。
**校验方法**：写完拿一个具体例子对一遍。

## 14. `if 布尔变量 == True:` → 直接写 `if 布尔变量:`

**发生时间**：第四课 d1
**【归属】2.3**

```python
if haveTicket == True:      # ❌ 多余
if haveTicket:              # ✅ 就够了
```

**理由**：`True` 本身就是"真"，**不需要再和 `True` 比一次**。

**同样**：`if not haveTicket:` 比 `if haveTicket == False:` 好。

> 这和真值判断是同一条规则：**`0` / `""` / `[]` / `None` 都自带"假"，不用显式比较。**

## 16. 累加必须**写回变量**

**发生时间**：第五课 b2（**学生自己注释留痕的**）
**【归属】3.4**

```python
for b in num:
    if b > 10:
        a + 1        # ❌ 算完就丢，a 一点没变
```

**这和「1. 函数返回值必须接住」是同一个错的两个面孔：**

| | 例子 | 谁的值被丢了 |
|---|---|---|
| 函数 | `float(a)` | **函数**吐出的返回值 |
| 算式 | `a + 1` | **算式**算出的结果 |

```python
a = a + 1        # ✅ 写回变量
```

> ⚠️ **不报错、不提示，只是数字悄悄不对。**
> **唯一的发现手段就是跑一遍看结果。**（以后会见到 `a += 1`，是同一件事的简写。）

## 17. `range()` 只吃整数，不吃字符串

**发生时间**：第五课 C3（**自己爬出来的**）
**【归属】3.12**

```python
s = "hello"
for a in range(s):     # ❌
# TypeError: 'str' object cannot be interpreted as an integer
for a in s:            # ✅ 直接遍历字符串
```

| 写法 | 给的是 |
|---|---|
| `for i in range(5)` | **数字** 0 1 2 3 4 |
| `for c in "abc"` | **字符** 'a' 'b' 'c' |

**这句总结是准的**（学生原话）：

> "`range` 函数不应该这样用（他应该是直接建立了循环组，而不是和 for 这样进行循环本身）"

## 18. `<` / `<=` 要和**起点配套**

**发生时间**：第五课 d1（**自己发现并修好**）
**【归属】3.8**

```python
a = 0
while a <= 5:      # ❌ 会打印到 6
    a = a + 1
    print(a)
```

**判断法**：**看最后一次循环**。想打印到 5，就让"最后一次"刚好落在 5 上。

| 起点 | 边界 | 打印和加的顺序 | 输出 |
|---|---|---|---|
| `1` | `<= 5` | 先打印、后加 | 1 2 3 4 5 ✅ |
| `0` | `< 5` | 先加、后打印 | 1 2 3 4 5 ✅ |
| `0` | `<= 5` | 先加、后打印 | 1 2 3 4 5 **6** ❌ |

## 20. ★ 引号看漏（读题陷阱，本次新增）

**发生时间**：真题实战一 · 选择题第 5 题
**【归属】2.3**

**题目**：`bool("")` 和 `bool("0")` 的结果分别是？
**学生答**：`False 和 False`（选项 C）。**正确答案**：`False 和 True`（选项 A）。

**学生的自述（本次补充，一句话）**：**"我下意识只看到 0、没注意引号"**——粗心，不是概念错。
（他还补了一句值得记的：**"AI 很注意双引号在不在"**。）

**这个解释是成立的，而且有证据**：

| 证据 | 说明 |
|---|---|
| 同一张卷子第 7 题 `5 and 0` → **答对** | 说明"`0` 是假"他没问题 |
| 他答的 `False 和 False` | **正好是把他在第四课 a3 写的规律用在 `bool(0)` 上的结果**——**答案和他的规则自洽，只是喂进去的输入是看错的那个** |
| 如果是概念没掌握 | 更可能答成 `True 和 False`（把"非空字符串都是真"搞反）——**他没搞反** |

> **⚠️ 教师的原始归因是错的，已更正。**
> 原批写的是"**真值判断没内化**"（= 提取失败 / 概念问题）。
> **这条已按 `学习规定-AI.md` §4.2（归因前先问）改为"符号看漏"。**
> **补救不是"复习真值判断"，是"读题时把引号念出来"（见〇.2）。**

**他自己在第四课 a3 写的规律**（**比教师的表更好，保留**）：
> **不用死记——"没装东西"、"数字本身代表'没有'"、"意义本身代表'否定'"→ 假值。**

**用这条规律推一遍**：

| 值 | 装了东西吗？ | 按他的规律 |
|---|---|---|
| `""` | **没装**（长度 0） | **假** ✅ |
| `"0"` | **装了**（长度 1，装了个 `0` 字符） | **真** ← 他本该答对 |

> **他自己的规律能推出正确答案——但看题时没看见引号。**
> **→ 这正是"知识没问题、但检查动作不到位"的典型。靠刷题 + 念符号兜住。**
