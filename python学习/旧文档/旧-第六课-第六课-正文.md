# 第 1 节 · 第一件事：字符串是**不可变**的

**这一节是本课的地基。地基歪了，后面每一节都会跟着歪。**

## 1.1 现场看报错

```python
name = "python"
name[0] = "P"
```

**实际输出：**

```
TypeError: 'str' object does not support item assignment
```

**读这条报错**：`str` 对象**不支持给某一项赋值**。

**而列表是可以的**（第三课学过）：

```python
nums = [1, 2, 3]
nums[0] = 99        # ✅ 行
name[0] = "P"       # ❌ 不行
```

| | 能不能改其中一个元素 |
|---|---|
| **列表 `list`** | ✅ **能**（可变的） |
| **字符串 `str`** | ❌ **不能**（**不可变的**） |

> **顺便解释第三课那个伏笔**：`b = a` 让两个名字指向**同一个列表**，所以改一个另一个也变。
> **字符串根本没有这个问题**——因为它**改不了**，压根不会有"另一个也变"这种事。
> （`b = s` 之后你怎么折腾 `b`，`s` 都不会变。）

## 1.2 所以：**所有字符串方法都是"返回一个新串"**

**这一条是本课最重要的规矩。**

```python
name = "python"

big = name.upper()      # ✅ 接住新串
print(big)              # PYTHON

name.upper()            # ❌ 忘了接住 —— 等于这行白写
print(name)             # python   （一点没变！）
```

**实际输出：**

```
PYTHON
python
```

> **这就是易错点第 1 条（返回值必须接住）的字符串版本。**
> 你在 `float()` 上跨过这道坎了，**现在换了个马甲又出现一次**。
>
> **判断法**：**一行只有 `s.方法()` 而左边没有 `=`，99% 是错的。**
> （唯一例外是后面 §2/§3 里"只为了看结果"的 `print(s.find(...))`。）

## 1.3 那怎么"改"字符串？

**答案：拼一个新的。**

```python
s = "cat"
s = "b" + s[1:]     # ✅ 造一个新串，再赋回去
print(s)            # bat
```

**读是可以的**（读不会改变它）：`name[0]` → `p`。

# 第 2 节 · 找：`find` / `index` / `count` / `startswith` / `endswith`

**这一节全是"问字符串一个问题"。它们都**不改变**原串。**

## 2.1 `find` —— 找不到给 **-1**

```python
s = "hello world"
print(s.find("o"))      # 4   第一次出现在下标 4
print(s.rfind("o"))     # 7   最后一次出现在下标 7（r = right，从右往左找）
print(s.find("z"))      # -1  找不到
```

**实际输出：**

```
4
7
-1
```

**注意**：`find` **永远不报错**，找不到就给 `-1`。

## 2.2 `index` —— 找不到就**报错**

```python
s.index("z")
```

**实际输出：**

```
ValueError: substring not found
```

| 方法 | 找不到时 |
|---|---|
| **`find`** | 返回 **`-1`** |
| **`index`** | **报错** `ValueError: substring not found` |

> **选择题常考这个差别。** 实际写代码时**优先用 `find`**——因为它不炸。
> 想判断"在不在"，更直接的是第三课学过的 **`"z" in s`**（给 `True` / `False`）。

## 2.3 `count` —— 数出现几次

```python
text = "banana"
print(text.count("an"))     # 2
print(text.count("a"))      # 3
```

**实际输出：**

```
2
3
```

> **冷知识（选择题爱考）**：`"abc".count("")` 是 **4**，不是 0。
> 空字符串被认为"在每个位置之间都出现一次"，3 个字符的串有 4 个缝隙。

## 2.4 `startswith` / `endswith` —— 开头 / 结尾是不是它

```python
filename = "2026-09-21.txt"
print(filename.startswith("2026"))     # True
print(filename.endswith(".txt"))       # True
```

**实际输出：**

```
True
True
```

> ⚠️ **是 `startswith` / `endswith`，不是 `startswiths`。**中间**没有** `s`。
> （`start` + `s` + `with` → **`startswith`**，别被"是不是"带出一个多余的 s。）

# 第 3 节 · 改：`replace` / `upper` / `lower` / `strip`

**再强调一遍：它们**都返回新串**，**都不改原串**。**

## 3.1 `replace(old, new)` —— 替换

```python
text = "I like cat. cat is cute."

new = text.replace("cat", "dog")        # ✅ 接住
print(new)
print(text)                             # 原串没变

print(text.replace("cat", "dog", 1))    # 只换前 1 个
print(text.replace("c", "C"))           # 所有 c 都换
```

**实际输出：**

```
I like dog. dog is cute.
I like cat. cat is cute.
I like dog. cat is cute.
I like Cat. Cat is Cute.
```

**第三个参数是"最多换几次"**：`replace("cat", "dog", 1)` 只换**前 1 个**。

> **第 2 行是重点**：`text` 一点没变。**`replace` 不会改 `text`，它给你一个新串。**

## 3.2 `upper` / `lower`

```python
print("abc".upper())     # ABC
print("ABC".lower())     # abc
```

**顺带认识两个（二级"了解"级，见到认得出就行）：**

| 方法 | 效果 | 例子 |
|---|---|---|
| `.title()` | 每个单词首字母大写 | `"abc def".title()` → `Abc Def` |
| `.capitalize()` | **只有整句第一个**字母大写 | `"abc def".capitalize()` → `Abc def` |

## 3.3 `strip` —— 它到底在去什么？

**`strip()` 不写参数 = 去掉首尾的"空白"（空格、Tab、换行）。**

```python
print("  x  ".strip())      # x
```

**它去的是"首尾"，中间不管：**

```python
print("  a  b  ".strip())   # 'a  b'  ← 中间那两个空格还在
```

> ### ⚠️ 陷阱：`strip("x")` 不是"去掉开头的 x"
>
> ```python
> print("xxaxx".strip("x"))     # 'a'
> ```
>
> **`strip` 的参数是"要剥掉的字符集合"**，不是前缀。它会把**首尾所有属于这个集合的字符**都剥掉。
>
> **所以 `strip("x")` 会把两头的 x 全剥光，剥到不是 x 为止。**
> 想"去掉开头两个字符"要用**切片** `s[2:]`，不是 `strip`。

**为什么这个方法这么重要**：`input()` 读进来的字符串**带着行尾的换行符**。

```python
s = input()          # 你敲了 yes 回车，s 其实是 "yes\n"
if s == "yes":       # ❌ 不成立！因为多了一个 \n
if s.strip() == "yes":   # ✅
```

## 3.4 链式调用

**方法返回的还是字符串，所以可以接着点下去：**

```python
"   YeS  ".strip().lower()     # 'yes'
```

**读法：先 `strip()` 得到一个干净的串，再对它 `.lower()`。**

> ### ⚠️ 顺序什么时候**有关系**
>
> `.lower().strip()` 和 `.strip().lower()` **结果一样**——因为这两个**互不干扰**。
> **但这不等于"链式调用的顺序永远无所谓"**：**只要前一个方法的输出去影响后一个方法的边界，顺序就变了。**
>
> 拿一个带横线的串试：
>
> ```python
> s = "--  你好  --"
> print(f"[{s.strip().replace('-', '')}]")    # [  你好  ]  ← strip 先做，什么也没剥到
> print(f"[{s.replace('-', '').strip()}]")    # [你好]      ← 先挖掉横线，strip 才剥得动空格
> ```
>
> **一句话**：链式调用的读法是"**每一步吃什么、吐什么**"——
> **顺序对不对，取决于"前一步改变了什么，后一步要靠什么"。**

# 第 4 节 · 切与拼：`split` / `join`（本课核心）

> **这一节是二级操作题的地基。** 文本处理的每一步都从这里开始。

## 4.1 `split()` 不写参数 = 按**任意空白**切

**这是最容易想错的一个细节。**

```python
messy = "  a  b  "
print(messy.split())        # ['a', 'b']
print(messy.split(" "))     # ['', '', 'a', '', 'b', '', '']   ← 完全不一样！
```

**实际输出：**

```
['a', 'b']
['', '', 'a', '', 'b', '', '']
```

| 写法 | 怎么切 | 结果 |
|---|---|---|
| **`split()`** | 按**任意长度的空白**切，**并且丢掉空段** | `['a', 'b']` —— **2 个** |
| `split(" ")` | **严格按"一个空格"**切，**空段全保留** | `['', '', 'a', '', 'b', '', '']` —— **7 个** |

> **一句话**：**不写参数 = 智能切；写了参数 = 死板切。**
> **处理"人打的字"用 `split()`；处理"格式固定的数据"才写参数。**

## 4.2 `split(",")` 指定分隔符

```python
line = "apple,banana,,cherry"
parts = line.split(",")
print(parts)            # ['apple', 'banana', '', 'cherry']
print(len(parts))       # 4
print(f"[{parts[2]}]")  # []   ← 第三个是空字符串
```

**实际输出：**

```
['apple', 'banana', '', 'cherry']
4
[]
```

> **⚠️ 关键**：**两个逗号之间什么都没有，就会切出一个空字符串**。
> `split` **不会**帮你把空字段扔掉。这正是 I2 改错题要处理的东西。

## 4.3 `split(分隔符, 最多切几次)`

```python
path = "D:/study/python/lesson6.txt"
print(path.split("/", 1))     # ['D:', 'study/python/lesson6.txt']
```

**实际输出：**

```
['D:', 'study/python/lesson6.txt']
```

**只切 1 次** → 得到 **2 个**元素：`['D:', 'study/python/lesson6.txt']`。

> **记法**：`split(sep, n)` 的结果**最多有 `n + 1` 段**。
> 用途：**只想从左边剥掉一层**的时候（比如拆 `键=值` 只拆第一个 `=`）。

## 4.4 `join` —— 方向正好**相反**

**`split` 把字符串变列表；`join` 把列表变字符串。**

```python
print("-".join(["2026", "09", "21"]))     # 2026-09-21
print("".join(["p", "y", "t", "h", "o", "n"]))   # python
```

**实际输出：**

```
2026-09-21
python
```

**读法**：**`"分隔符".join(列表)`** —— 用这个分隔符，把列表里的东西**串起来**。

> ### ⚠️ 注意方向！这是全课最容易写反的一处
>
> | 想要 | 写 | 谁在前 |
> |---|---|---|
> | 字符串 → 列表 | **`s.split(",")`** | **分隔符写在括号里** |
> | 列表 → 字符串 | **`",".join(列表)`** | **分隔符写在点前面** |
>
> **`join` 是唯一一个"分隔符在前、列表在后"的写法**，因为它本质是**分隔符的方法**。

> ### ⚠️ `join` 只能拼**字符串**
>
> ```python
> "".join([1, 2, 3])
> ```
>
> **实际输出：**
>
> ```
> TypeError: sequence item 0: expected str instance, int found
> ```
>
> **读报错**：`item 0`（第 0 项）期待的是 `str`，实际给了 `int`。
> **要拼数字，先用 `str()` 转换。**

## 4.5 数字列表 → 字符串：两种做法

```python
nums = [1, 2, 3]

# 做法一：循环 + 累加（第五课的死格式）
s = ""
for n in nums:
    s = s + str(n)          # 累加器 + str() 转换
print(s)                    # 123

# 做法二：join + 先把每个元素转成字符串
# 注：这种做法要配合推导式或循环，第八课（推导式）之后再回来看
```

**实际输出：**

```
123
```

> **注意这里是第五课的累加器原封不动搬到字符串上**：
> `total = total + n` 变成了 `s = s + str(n)`。**同一个模式，换了材料。**

# 第 5 节 · 判断：`isdigit` / `isalpha` / `isspace` / `isalnum`

**这一组方法全部返回 `True` / `False`。**二级选择题用它们出题非常频繁。

## 5.1 四个方法

| 方法 | 问的是 |
|---|---|
| `.isdigit()` | 是不是**全是数字字符** |
| `.isalpha()` | 是不是**全是字母** |
| `.isspace()` | 是不是**全是空白** |
| `.isalnum()` | 是不是**全是数字或字母**（alnum = alphanumeric） |

## 5.2 实际跑一遍（**预测之后再对照**）

```python
tests = ["123", "-1", "3.14", "abc", "a1", " ", "", "１２３"]
for t in tests:
    print(f"[{t}] isdigit={t.isdigit()} isalpha={t.isalpha()} isspace={t.isspace()}")
```

**实际输出：**

```
[123] isdigit=True isalpha=False isspace=False
[-1] isdigit=False isalpha=False isspace=False
[3.14] isdigit=False isalpha=False isspace=False
[abc] isdigit=False isalpha=True isspace=False
[a1] isdigit=False isalpha=False isspace=False
[ ] isdigit=False isalpha=False isspace=True
[] isdigit=False isalpha=False isspace=False
[１２３] isdigit=True isalpha=False isspace=False
```

> ### ⚠️ 三个反直觉的地方（选择题就考这些）
>
> | 现象 | 为什么 |
> |---|---|
> | **`"-1".isdigit()` → `False`** | **负号不是数字字符**。它只认 `0-9` |
> | **`"3.14".isdigit()` → `False`** | **小数点也不是数字字符**。`isdigit` ≠ "能不能转成数" |
> | **`"".isspace()` → `False`** | **空串什么都不满足**（连"全是空白"都不算） |
>
> **另外两条值得记：**
>
> | 现象 | 说明 |
> |---|---|
> | **`"１２３".isdigit()` → `True`** | 全角数字**也是数字字符**（`isdigit` 认它） |
> | **`"你好".isalpha()` → `True`** | **中文汉字也算字母**（Python 认的是 Unicode 分类，不是"英文"） |
>
> **所以 `isdigit()` 的准确含义是"全是数字类字符"，不是"这是个合法的整数"。**
> **要判断"能不能转成整数"，最稳的还是 `try`（第十课会学）。**

## 5.3 用法：转数字之前先问一句

```python
s = "2026"
if s.isdigit():
    print(int(s) + 1)       # 2027
else:
    print("不是纯数字")
```

**实际输出：**

```
2027
```

# 第 6 节 · 格式化：`format()`

**你已经会 f-string 了。`format()` 是它的"老前辈"，但二级会考，所以要认识。**

## 6.1 三种写法

```python
name = "小明"
score = 95.5

print("{} 的分数是 {}".format(name, score))       # 按顺序填空
print("{0} 的分数是 {1}".format(name, score))     # 按下标填
print("{1} 分，{0} 同学".format(name, score))     # 下标可以调换顺序
print("{n} 的分数是 {s}".format(n=name, s=score)) # 按名字填
```

**实际输出：**

```
小明 的分数是 95.5
小明 的分数是 95.5
95.5 分，小明 同学
小明 的分数是 95.5
```

| 写法 | 特点 |
|---|---|
| `{}` | **按位置顺序**填，最简单 |
| `{0}` `{1}` | **按编号**填，**可以重复用同一个**（`{0}{1}{0}`）、**可以换顺序** |
| `{name}` | **按关键字**填，`format(n=..., s=...)`。**顺序随便** |

## 6.2 和 f-string 的关系

```python
print(f"{name} 的分数是 {score}")     # 和上面第一条完全一样
```

**实际输出：**

```
小明 的分数是 95.5
```

> **f-string 是 `format()` 的语法糖**（更好写的版本）。
> **实际写代码用 f-string；但二级选择题会让你读 `format()`。**两种都要认得出。

## 6.3 ⚠️ 格式说明符**这一节不讲**

**`{:>10}`、`{:.2f}`、`{:,}` 这一套（冒号后面那部分）——**

|---|---|
| **归谁讲** | **你自己读官方文档**（规则七） |

# 第 7 节 · 字符与编码：`ord` / `chr` / `bin` / `oct` / `hex`

> **这一节是"纯选择题细节"。** 操作题几乎不用，但选择题拿高分必须有它。

## 7.1 `ord`：字符 → 编码数字；`chr`：数字 → 字符

```python
print(ord("a"))      # 97
print(ord("A"))      # 65
print(ord("0"))      # 48
print(chr(97))       # a
```

**实际输出：**

```
97
65
48
a
```

### ★ 这三个数字要背下来

| 字符 | 编码 |
|---|---|
| `"0"` | **48** |
| `"A"` | **65** |
| `"a"` | **97** |

**顺带记住两条推论（选择题常考）：**

```python
print(ord("a") - ord("A"))      # 32
```

**实际输出：**

```
32
```

1. **大写和小写相差 32**（小写更大）
2. **`"a"` 到 `"z"` 是连续的**，所以 `chr(ord("k") - 32)` 就是它的大写

```python
c = "k"
print(chr(ord(c) - 32))     # K   ← 手算出来
print(c.upper())            # K   ← 本课方法
```

**实际输出：**

```
K
K
```

> **同一件事两种做法**：`ord`/`chr` 是"底层做法"，`upper()` 是"高层做法"。
> **知道它们等价，你就同时看懂了编译原理的味道和 Python 的设计意图。**

## 7.2 `bin` / `oct` / `hex`：转成二 / 八 / 十六进制**字符串**

```python
print(bin(10))       # 0b1010
print(oct(10))       # 0o12
print(hex(255))      # 0xff
print(hex(10))       # 0xa
```

**实际输出：**

```
0b1010
0o12
0xff
0xa
```

> ### ⚠️ 三个坑（选择题全在这儿）
>
> | 坑 | 说明 |
> |---|---|
> | **返回值是字符串** | `type(bin(10))` → `<class 'str'>` |
> | **带前缀** | 二进制 `0b`、八进制 `0o`、十六进制 `0x`。**前缀算在长度里** |
> | **长度不是你想的那个数** | `len(bin(10))` 是 **6**（`0b1010`），**不是 4** |
>
> ```python
> print(len(bin(10)))          # 6
> print(type(bin(10)))         # <class 'str'>
> ```
>
> **实际输出：**
>
> ```
> 6
> <class 'str'>
> ```

> | **① 返回值是字符串** | `type(bin(5))` → **`<class 'str'>`** —— **不是数字！** |
> | **② 带前缀** | `0b` / `0o` / `0x` **都算字符** |
> | **③ 长度 ≠ 位数** | `len(bin(5))` 是 **5**，不是 3 |
>
> **第 4 问答案**：`'0b101'` 是 `0` `b` `1` `0` `1` —— **5 个字符**，`0b` 前缀占了 2 个。

# 第 8 节 · 字面量里的细节

**这一节全是"写在引号里面的东西"。它们都是选择题的常客。**

## 8.1 转义字符：`\n` / `\t` / `\\`

**反斜杠 `\` 加上一个字母，表示一个"看不见的字符"。**

| 写法 | 是什么 | 占几个字符 |
|---|---|---|
| `\n` | **换行** | **1** |
| `\t` | **Tab（制表符）** | **1** |
| `\\` | 一个反斜杠本身 | 1 |
| `\"` | 一个引号本身（引号里要打引号时用） | 1 |

```python
print("第一行\n第二行")
print(len("a\nb"))        # 3 —— \n 只占 1 个位置
```

**实际输出：**

```
第一行
第二行
3
```

> **`"a\nb"` 看起来是 4 个字符，实际是 3 个**：`a`、换行、`b`。**这是选择题陷阱。**

**`\t` 的实际用途是"对齐"：**

```python
print("姓名\t年龄")
print("小明\t18")
```

**实际输出：**

```
姓名	年龄
小明	18
```

## 8.2 原始字符串 `r"..."`：让 `\` 不再特殊

```python
print(r"a\nb")        # a\nb   ← 四个字符，\ 和 n 分开的
```

**实际输出：**

```
a\nb
```

| 写法 | `len` | 内容 |
|---|---|---|
| `"a\nb"` | **3** | a、换行、b |
| **`r"a\nb"`** | **4** | a、`\`、n、b |

> **`r` 的用途**：**路径**和**正则表达式**。Windows 路径 `r"D:\note\test"` —— 不加 `r`，
> `\n` 会被当成换行、`\t` 会被当成 Tab，路径就毁了。**（第九课读文件时你会天天用。）**
>
> **另一种不改语义的写法是 `\\`**：`"D:\\note\\test"` 和 `r"D:\note\test"` **值完全一样**。
> **一个靠"关掉转义"，一个靠"转义出反斜杠"**——这两种写法选择题都考。

## 8.3 三引号：一次写多行

```python
print("""
第一行
第二行
""")
```

**实际输出：**（**注意首尾各有一个空行**——这是真的）

```

第一行
第二行

```

> **三引号 `"""..."""` 里的换行是"真的换行"**，不用写 `\n`。
> **注意**：紧跟在 `"""` 后面的那个换行**也会被算进去**，所以输出**开头有个空行**。

## 8.4 字符串乘法 `*`

```python
print("-" * 30)
```

**实际输出：**

```
------------------------------
```

**字符串 `*` 整数 = 重复那么多次。**用途：**打印分隔线**、造测试数据。

> ### ⚠️ 顺便补一个你上次真题里丢分的点
>
> **真题实战一的选择题里有一道 `"a" + "b" * 2`，你答成了 `abab`。**
>
> **正确答案是 `"abb"`** —— 因为 **`*` 的优先级高于 `+`**：
>
> ```
> "a" + "b" * 2
>   ↓ 先算乘法
> "a" + "bb"
>   ↓ 再算加法
> "abb"
> ```
>
> **（`("a" + "b") * 2` 才是 `"abab"`。）**
>
> **这题已经考过，不会再考第二遍**（规则三）。
> **但它是你真题里的一个缺口，写在这里，让你把"`*` 比 `+` 优先"这件事记住。**

**要求**：新建 `h2.py`。下面三条，**先都别改，原样写进去跑一遍**：

**【自检】**（真实输出；前两行是第 1 步，中间两行是第 3 步，最后一行是第 4 步）

```
C:
ew	est
C:\new\test
C:\new\test
11 11
```

> ### ★ 第 1 步：路径当场碎了
>
> ```
> bad = "C:\new\test"
>          ↓  \n 被当成"换行"
>          ↓  \t 被当成"制表符"
> C:
> ew	est
> ```
>
> **⚠️ 说准这件事**：`bad` 的**值里确实有换行符和 Tab**（所以才打成两行）。
> 出问题的是**源码里的写法**——你打的是"**反斜杠 + 字母 n**"，
> 但在**普通字符串**里 `\` 是**转义符**，它把后面的 `n` 变成了换行。
> **一句话：你打进去的 ≠ 字符串里存着的。**
>
> **第 3 步：两种改法，值完全一样**
>
> | 写法 | 靠什么 | `len` |
> |---|---|---|
> | `r"C:\new\test"` | **`r` = raw**：`\` **不是转义符**，就是个普通字符 | **11** |
> | `"C:\\new\\test"` | **`\\` = 一个反斜杠**：还是转义，但转义的对象是 `\` 自己 | **11** |
>
> **第 5 步：`r"\"` 不能跑**——它是 **SyntaxError（语法错误）**，
> 连"运行起来"都到不了。原因是 **`r` 关掉了转义的"效果"，但没关掉转义符"占位"的性质**：
> `r"\")` 里的 `\"` 仍然被当成一个整体，于是这个字符串**没有结束引号**了。
> **记法：原始字符串不能以单个 `\` 结尾。**

# 附录

## A. 本课常见报错速查

> **全部是实跑抓下来的原文**（规则一）。

| 报错 | 原因 | 怎么改 |
|---|---|---|
| `TypeError: 'str' object does not support item assignment` | 想改字符串的某个字符 | **字符串不可变**，只能拼一个新串再赋值 |
| `AttributeError: 'str' object has no attribute 'splits'. Did you mean: 'split'?` | 方法名拼错（`splits` 多了个 s） | 是 **`split`** |
| `ValueError: substring not found` | `index()` 找不到 | 用 **`find()`**（找不到给 `-1`，不报错） |
| `TypeError: sequence item 0: expected str instance, int found` | `join` 的列表里**有非字符串** | 先 `str()` 转换 |
| `TypeError: str.upper() takes no arguments (1 given)` | `upper` 传了参数 | `upper()` **括号里什么都不写** |
| `TypeError: strip arg must be None or str` | `strip` 传了数字 | `strip()` 不写，或写**字符串** |
| `TypeError: find expected at least 1 argument, got 0` | `find()` 括号里空的 | 要告诉它**找什么**：`find("x")` |
| `TypeError: object of type 'int' has no len()` | 对数字用了 `len()` | `len()` 只能量**序列**（字符串、列表） |

文本"""

```
