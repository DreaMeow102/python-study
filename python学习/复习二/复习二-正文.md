### 关于"不看资料"

**先完全不看资料做。** 遇到想不起来的，**别立刻翻文档**。

> **卡超过 10 分钟，允许查——但查完必须写进代码注释**（清单由教师从这里提取，见最后一节）。

**为什么这样设计**：你现在感觉到的"记不住"，**不是遗忘，是提取失败**——知识还在，但你想不起来、或者想起来很慢。

**重做原题治不了这个。只有"逼自己往外捞"才治。**

而**从你注释里提取出来的那份清单，比做对题更值钱**——它就是你真实缺口的分布图。

### 要交两样东西

1. **代码**（写在 `复习二\code\`）

### 甲1 · 名片 【第一课】

**要求**：新建 `jia1.py`。

用 `input()` 依次读入**姓名**和**职业**，然后打印**三行**（值用你输入的内容）：

```
姓名：李雷
职业：程序员
签名："今天也要写代码"
```

**三个要求**：

1. **第三行的双引号是输出的一部分**——要真的打印出来。
2. **不许用中文引号**（`“ ”`）。中文引号不是引号，是普通字符。
3. 文件**第一行**写一条注释，写上你的名字。

**考的是**：`print` / 一个引号包另一个引号 / 注释 / `input()`（第一课）

### 甲2 · 三位数拆解 【第二课】

**要求**：新建 `jia2.py`。

用 `input()` 读入一个**三位整数**（例子里用 `407`），输出**四行**：

```
各位数字之和：11
倒过来：704
是 7 的倍数吗：False
平均每个数字：3.67
```

**要求**：

- 用 `//` 和 `%` 把三位**拆出来**（不许用切片、不许用字符串）
- 第四行**保留两位小数**
- 第三行是 `True` / `False`，不是文字

**运行示例**（`407` 是你输入的）：

```
请输入一个三位数：407
各位数字之和：11
倒过来：704
是 7 的倍数吗：False
平均每个数字：3.67
```

**考的是**：`input` + `int()` + `//` `%` + f-string + `.2f`（第二课）

### 甲3 · 购物车 【第三课】

**要求**：新建 `jia3.py`。开头照抄这一行：

```python
cart = ["牛奶", "面包", "鸡蛋", "苹果"]
```

然后**依次**做这 8 件事（每件都 `print` 出结果）：

1. 打印列表**长度**
2. 打印**第一个**和**最后一个**元素（**最后一个必须用负索引**）
3. 把 `"面包"` **改成** `"全麦面包"`
4. **追加** `"酸奶"`
5. **删除** `"鸡蛋"`
6. 打印**最终的列表**
7. 用 `in` 判断 `"牛奶"` 还在不在，打印 `True` / `False`
8. 打印 `cart[1:3]` 这一段

**考的是**：列表 / `len` / 正负索引 / 改元素 / `append` / `remove` / `in` / 切片（第三课）

### 甲4 · 成绩等级 【第四课】

**要求**：新建 `jia4.py`。**两问，都要做。**

**第一问**：用 `input()` 读入一个**分数**（整数），按下面分级打印：

| 分数 | 打印 |
|---|---|
| ≥ 90 | `优秀` |
| ≥ 80 | `良好` |
| ≥ 60 | `及格` |
| 其它 | `不及格` |

**第二问**：再读入**一行文字**（**什么都不输、直接回车也算一种输入**）。

- 如果它是**空的** → 打印 `没有输入`

**运行示例**：

```

```

**考的是**：`if` / `elif` / `else` / 比较运算符 / **真值判断**（空串是假）（第四课）

### 甲5 · 两个"算到什么时候" 【第五课】

**要求**：新建 `jia5.py`。**三问，都要做。**

**第一问**：用 `for` 和 `range`，算 **1 到 200 之间**所有**能被 3 或 5 整除**的数**之和**，打印。

**第二问**：用 `while` 算：

> 一张厚度 **0.1 毫米**的纸，**对折多少次**之后厚度会**超过 8848 米**？

打印**次数**。（提示：0.1 毫米 = 0.0001 米；每折一次厚度 × 2）

**第三问**：打印**最后那次对折之后**的厚度（**单位：米**，保留两位小数）。

**运行示例**（数值是示意，**别照抄**）：

```
第一问：xxxxx
第二问：xx 次
第三问：xxxxx.xx 米
```

**三个要求**：

1. 第一问是"能被 3 **或** 5 整除"。
2. 第二问**用 `while`**（不要用 `for` 硬凑次数）。
3. 第三问问的是**停下来那一刻**的厚度。

**考的是**：`for` / `range` / `if` / 累加器 / `while` / 浮点数 / `.2f`（第五课 + 第二、四课）

### 甲6 · 清洗一条乱记录 【第六课】

**要求**：新建 `jia6.py`。开头照抄这一行：

```python

```

然后**依次**做这 5 件事（每件都 `print` 出结果）：

1. 用 `split(";")` 切成几段，**打印这个列表**
2. 把每段**两头空白去掉**，拼成一条 `李四|25|上海`，打印

3. 打印**字段个数**
4. 打印 `"上海"` 在**第几段**（从 0 数）——**并在注释里写明你用的是 `find` 还是 `index`、为什么**
5. 打印 `raw.strip()` 的**长度**

**运行示例**（**别照抄**，自己跑）：

```
['  李四 ', ' 25 ', '  上海  ']
李四|25|上海
3
2
13
```

**考的是**：`split` / `strip` / `join` / `len` / `find` 或 `index`（第六课）

```python
names = ["小明", "小红", "小刚", "小美"]
```

- **最高分用"打擂法"**（先立擂主，再一个个比），**不许用 `max()`**

**考的是**：`for` + `range` + 下标 / 条件分级 / 累加器 / 打擂法 / `.2f`（第三、四、五、二课）

### 丙1

```python

b = a
```

**要回答的问题**（写进 `bing1.py` 的注释）：

1. 四行各输出什么？
2. `b = a` 和 `c = a[:]` **差在哪**？

### 丙2

```python
total = 0
for i in range(1, 5):
    total = total + i
print(total)

n = 0
while n < 3:
    n = n + 1
    print(n)

print(n)
```

**要回答的问题**（写进 `bing2.py` 的注释）：

1. 整段**输出什么**（按行写）？
2. `range(1, 5)` 一共走了**几个数**？分别是几？
3. 如果把 `while n < 3` 改成 `while n <= 3`，**最后那行 `print(n)` 会变成几**？
4. `while` 里的 `print(n)` 和 `n = n + 1` **谁先谁后**，换过来结果一样吗？
