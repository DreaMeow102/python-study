# 第六课 知识点拟定

> 把 `学习路线.md` 里「第六课」那一行展开。
> 知识点按**教的顺序**排；顺序由「依赖」决定。

## 覆盖

字符串的：**不可变 → 找 → 改 → 切与拼 → 判断 → 格式化 → 字符与编码 → 字面量**

---

## 知识点

### 1. 字符串**不可变**

- **出处**：`https://docs.python.org/zh-cn/3/library/stdtypes.html#text-sequence-type-str`
  实跑：`s = "lemon"` 然后 `s[0] = "L"` →
  `TypeError: 'str' object does not support item assignment`
- **怎么教清楚**：**先跑那行报错**，不解释；再说一句"建好之后，哪个位置都改不了"
- **依赖**：第三课的索引（`s[0]` 会取字符）
- **反直觉**：列表能改、字符串不能 —— **长得一样的东西，行为不一样**
- **深度**：认得出（报错原文）

### 2. 所以所有字符串方法都是"**返回一个新串**"

- **出处**：官方 docstring，`str.upper.__doc__` 原文：
  > `Return a copy of the string converted to uppercase.`
  （`lower` / `strip` / `replace` 同样是 `Return a copy ...`）
  实跑：`s = "abc"` → `s.upper()` → 打印 `s` 还是 `"abc"`
- **怎么教清楚**：**"copy"这个词是关键**——方法不动作在原串上，它**交回一个新串**
- **依赖**：第 1 条（不可变）
- **反直觉**：`s.upper()` 单独一行等于白写（和 `float(a)` 那个坑同源）
- **深度**：会用

### 3. `find` / `index` / `count` / `startswith` / `endswith` —— **找**

- **出处**：`https://docs.python.org/zh-cn/3/library/stdtypes.html#string-methods`，原文：
  > `find`：`Return the lowest index in S where substring sub is found ... `
  > `index`：`Return the lowest index in S where substring sub is found ... `（找不到时**抛异常**）
  > `count`：`Return the number of non-overlapping occurrences of substring sub in string S[start:end].`
  > `startswith`：`Return True if the string starts with the specified prefix, False otherwise.`
  > `endswith`：`Return True if the string ends with the specified suffix, False otherwise.`
- **怎么教清楚**：**`find` 和 `index` 一起讲**，只差"找不到时怎么办"：`find` 给 `-1`，`index` 报错
- **依赖**：第 1、2 条
- **反直觉**：**`-1` 在真值判断里是"真"** —— 不能写 `if s.find(x):`
- **深度**：会用

### 4. `replace` / `upper` / `lower` / `strip` —— **改**

- **出处**：同上，原文：
  > `replace`：`Return a copy with all occurrences of substring old replaced by new.`
  > `upper`：`Return a copy of the string converted to uppercase.`
  > `strip`：`Return a copy of the string with leading and trailing whitespace removed. If chars is given and not None, remove characters in chars instead.`
- **怎么教清楚**：`strip()` 不写参数 = 去**空白**；写了参数 = 去**这些字符**
- **依赖**：第 2 条
- **反直觉**：**`strip("ab")` 剥的是"a 或 b"这个集合，不是前缀 `"ab"`**
- **深度**：会用

### 5. **链式调用**

- **出处**：实跑（`"  A,b  ".strip().lower().split(",")`）
- **怎么教清楚**：每个方法交回一个**新串**，所以可以接着往下点
- **依赖**：第 2、4 条
- **反直觉**：链一长就"看不见中间是什么" —— 卡住就把中间那步单独打印
- **深度**：会用

### 6. `split` / `join` —— **切与拼**（本课核心）

- **出处**：同上，原文：
  > `split`：`Return a list of the substrings in the string, using sep as the separator string.`
  > `join`：`Concatenate any number of strings. The string whose method is called is inserted in between each given string. The result is returned as a new string.`
- **怎么教清楚**：**`split()` 不写参数 = 按任意空白切，并且自动去掉空串**
- **依赖**：第三课的列表（`split` 交回列表）、第 2 条
- **反直觉**：**方向相反** —— `split` 是"串 → 列表"，`join` 是"列表 → 串"；而且 `join` 是**分隔符**去点，不是列表去点
- **深度**：会用

### 7. `isdigit` / `isalpha` / `isspace` / `isalnum` —— **判断**

- **出处**：同上，原文：
  > `isdigit`：`Return True if the string is a digit string, False otherwise. A string is a digit string if all characters in the string are digits and there is at least one character`
  > `isalpha`：`... if all characters in the string are alphabetic ...`
  > `isspace`：`... if all characters in the string are whitespace ...`
  > `isalnum`：`... if all characters in the string are alpha-numeric ...`
- **怎么教清楚**：四个一起跑一遍**对照表**（`"42"` `"+7"` `"2.5"` `" 9 "` `"²"` `"４５"`）
- **依赖**：第二课的 `int()` 转换
- **反直觉**：**`isdigit()` ≠ "能不能 `int()`"** —— 两边对不上（`"²"`、全角数字）
- **深度**：会用

### 8. `format()`

- **出处**：同上，原文：
  > `format`：`Return a formatted version of the string, using substitutions from args and kwargs. The substitutions are identified by braces ('{' and '}').`
- **怎么教清楚**：**先给 f-string**（已学），再说 `format` 是同一件事的另一种写法
- **依赖**：第二课的 f-string
- **反直觉**：无
- **深度**：认得出（读代码时看得懂就够）

### 9. `ord` / `chr`

- **出处**：`https://docs.python.org/zh-cn/3/library/functions.html#ord`，原文：
  > `ord`：`Return the ordinal value of a character. If the argument is a one-character string, return the Unicode code point of that character.`
  > `chr`：`Return a Unicode string of one character with ordinal i; 0 <= i <= 0x10ffff.`
- **怎么教清楚**：一对反操作，`ord("A")` → `65`，`chr(65)` → `"A"`
- **依赖**：无（独立）
- **反直觉**：无
- **深度**：会用

### 10. `bin` / `oct` / `hex`

- **出处**：`https://docs.python.org/zh-cn/3/library/functions.html#bin`，原文：
  > `bin`：`Return the binary representation of an integer.`
  > `oct`：`Return the octal representation of an integer.`
  > `hex`：`Return the hexadecimal representation of an integer.`
- **怎么教清楚**：**它们交回的是字符串**，不是数字 —— 所以带前缀、所以有长度
- **依赖**：无（独立）
- **反直觉**：**`bin(5)` 有 4 个字符，不是 3** —— 因为有 `0b`
- **深度**：会用

### 11. 转义字符 `\n` `\t` `\\`

- **出处**：`https://docs.python.org/zh-cn/3/reference/lexical_analysis.html#string-and-bytes-literals`
  实跑：`print("C:\new\test")` → 换行 + 制表
- **怎么教清楚**：**跑给他看 `"C:\new\test"` 打印成什么**，再解释 `\n` 被当成换行
- **依赖**：无
- **反直觉**：**源码里写的一行，和字符串里存的值，不是一回事**
- **深度**：会用

### 12. 原始字符串 `r"..."`

- **出处**：同上，原文：
  > `Even in a raw literal, quotes can be escaped with a backslash, but the backslash remains in the result`
- **怎么教清楚**：`r"C:\new\test"` 打印出来就是原样
- **依赖**：第 11 条
- **反直觉**：**`r` 只是"不让 `\` 特殊"，不是"什么都能写"** —— `r"\"` 仍然不合法
- **深度**：会用

### 13. 三引号

- **出处**：同上（`"""..."""` 可以跨行）
- **怎么教清楚**：一次写多行，`\n` 都省了
- **依赖**：第 11 条
- **反直觉**：无
- **深度**：会用

### 14. 字符串乘法 `*`

- **出处**：实跑（`"-" * 20` → 20 个短横）
- **怎么教清楚**：和数字乘法长一样，但结果是串
- **依赖**：无
- **反直觉**：无
- **深度**：会用

## 故意不碰的

- **`format()` 的格式说明符**（`{:>10}` `{:.2f}` 之类）—— 只讲到"三种写法"，说明符留给特殊题自己读文档
- **`encode()` / `decode()` / 正则** —— 不在本课范围

## 只要求"认得出"的

- **第 8 条 `format()`**：会读、会改，不要求默写
- **第 1 条**：要认得出那行报错，不要求会解释 CPython 内部
