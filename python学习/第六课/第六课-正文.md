# 第 1 节 · 字符串是**不可变**的

## 1.1 先跑这一行

```python
name = "lemon"
name[0] = "L"
```

**实际输出：**

```
TypeError: 'str' object does not support item assignment
```

**提示**：完整回溯里还有三行（`Traceback` / `File "…a1.py", line 2` / 出错的那一行）。
**真正要记住的只有最后这一行** —— 错误类型 + 原因。

**列表能这么改，字符串不能。**

## 1.2 所以：所有字符串方法都是"**返回一个新串**"

```python
s = "abc"
s.upper()
print(s)
```

**实际输出：**

```
abc
```

`s.upper()` **一个字符都没改到 `s` 上** —— 它把结果**交回来**，我把它丢了。

> **官方文档原话**（`str.upper.__doc__`）：`Return a copy of the string converted to uppercase.`
> **关键是 `copy` 这个词** —— 它不动作在原串上。

## 1.3 那怎么"改"字符串？

**拼一个新的。**

```python
word = "lemon"
print("L" + word[1:])
```

**实际输出：**

```
Lemon
```

**老串一动不动，新串是我拼出来的。**

# 第 2 节 · 找

## 2.1 `find` —— 找不到给 **-1**

```python
line = "2026-09-21 ERROR 磁盘已满"
print(line.find("ERROR"))
print(line.find("WARN"))
```

**实际输出：**

```
11
-1
```

`find` **不报错**，它给你 `-1`。**位置从 0 数起。**

## 2.2 `index` —— 找不到就**报错**

```python
print(line.index("ERROR"))
```

**实际输出：**

```
11
```

找得到时，`find` 和 `index` **一模一样**；差别只在找不到的时候。

## 2.3 `count` / `startswith` / `endswith`

```python
print(line.count("-"))
print(line.startswith("2026"), line.endswith("满"))
```

**实际输出：**

```
2
True True
```

# 第 3 节 · 改

## 3.1 `replace` / `upper`

```python
s = "  Hello, World  "
print(f"[{s.replace('World', 'Python')}]")
print(f"[{s.upper()}]")
```

**实际输出：**

```
[  Hello, Python  ]
[  HELLO, WORLD  ]
```

**用 `f"[{...}]"` 包起来**，前后有没有空格立刻现形。

## 3.2 `strip` —— 它到底在去什么？

```python
s = "  Hello, World  "
print(f"[{s.strip()}]")
```

**实际输出：**

```
[Hello, World]
```

**`strip()` 不写参数 = 去掉两端的空白**（空格、`\t`、`\n`）。

## 3.3 写了参数就是另一回事

```python
print("xxabcxx".strip("x"))
print("xyabcyx".strip("xy"))
```

**实际输出：**

```
abc
abc
```

**`strip("xy")` 去掉的是"x 或 y"**，从两端一路剥到不是为止 —— **不是去前缀 `"xy"`。**

## 3.4 链式调用

```python
print("  A,b  ".strip().lower().split(","))
```

**实际输出：**

```
['a', 'b']
```

每一步都**交回一个新东西**，所以可以接着往下点。

# 第 4 节 · 切与拼（**本课核心**）

## 4.1 `split()` 不写参数

```python
line = "  张 三   20  北京  "
print(line.split())
```

**实际输出：**

```
['张', '三', '20', '北京']
```

**按任意空白切**（一个空格、两个空格、`\t` 都算），**而且自动扔掉空串**。

## 4.2 写了分隔符就按它切

```python
print("a,b,,c".split(","))
```

**实际输出：**

```
['a', 'b', '', 'c']
```

**这里有空的** —— 因为两个逗号挨着，中间**确实**夹着一个空串。

## 4.3 最多切几次

```python
print("a,b,c,d".split(",", 2))
```

**实际输出：**

```
['a', 'b', 'c,d']
```

**切 2 次 = 得到 3 段**，剩下的整块留给最后一段。

## 4.4 `join` —— 方向正好相反

```python
print("-".join(["2026", "09", "21"]))
```

**实际输出：**

```
2026-09-21
```

**`join` 是"分隔符"去点**，不是列表去点：`"-".join(列表)`。

## 4.5 数字列表怎么办 —— 两种做法

**做法一：循环 + 累加（第五课的死格式）**

```python
nums = [3, 1, 4]
s = ""
for n in nums:
    s = s + str(n)
print(s)
```

**实际输出：**

```
314
```

**做法二：先把每个元素转成字符串，再 `join`**

```python
nums = [3, 1, 4]
parts = []
for n in nums:
    parts.append(str(n))
print("-".join(parts))
```

**实际输出：**

```
3-1-4
```

> **做法一就是第五课的累加器原封不动搬到字符串上**：
> `total = total + n` 变成了 `s = s + str(n)`。**同一个模式，换了材料。**
>
> **做法二的好处是能插分隔符** —— 累加器要插分隔符，得额外判断"桶是不是空的"。
>
> **`join` 只吃字符串** —— 所以两种做法都要先 `str()` 一遍。

# 第 5 节 · 判断

## 5.1 四个方法

| 方法 | 问你 |
|---|---|
| `isdigit()` | 全是数字吗 |
| `isalpha()` | 全是字母吗 |
| `isspace()` | 全是空白吗 |
| `isalnum()` | 全是字母或数字吗 |

**四个都交回 `True` / `False`。**

## 5.2 跑一遍再看

```python
for t in ["42", "+7", "2.5", "４５", " 9 ", "²"]:
    print(f"[{t}] isdigit={t.isdigit()} isalnum={t.isalnum()}")
```

**实际输出：**

```
[42] isdigit=True isalnum=True
[+7] isdigit=False isalnum=False
[2.5] isdigit=False isalnum=False
[４５] isdigit=True isalnum=True
[ 9 ] isdigit=False isalnum=False
[²] isdigit=True isalnum=True
```

## 5.3 `isdigit()` **不等于**"能不能 `int()`"

```python
print(int(" 9 "))
```

**实际输出：**

```
9
```

**`isdigit()` 说"不行"的 `" 9 "`，`int()` 收下了；`isdigit()` 说"行"的 `"²"`，`int()` 不要。**

**两边不是一回事** —— 想安全转换，用 `try`（第十课）。

# 第 6 节 · 格式化 `format()`

## 6.1 同一件事的两种写法

```python
name, age = "李雷", 24
print("{} 今年 {} 岁".format(name, age))
print(f"{name} 今年 {age} 岁")
```

**实际输出：**

```
李雷 今年 24 岁
李雷 今年 24 岁
```

## 6.2 `format` 的三种写法

```python
print("{0} 今年 {1} 岁".format(name, age))
print("{n} 今年 {a} 岁".format(n=name, a=age))
```

**实际输出：**

```
李雷 今年 24 岁
李雷 今年 24 岁
```

1. `{}` —— **按顺序**填
2. `{0}` `{1}` —— 按**编号**填（同一个编号能重复用）
3. `{n}` —— 按**名字**填

## 6.3 ⚠️ 格式说明符这一节**不讲**

`{:.2f}` `{:>10}` `{:,}` 这些东西 —— **自己读文档**（这就是特殊题 **I1**）。

# 第 7 节 · 字符与编码

## 7.1 `ord` / `chr` —— 一对反操作

```python
print(ord("A"), chr(65), chr(ord("A") + 1))
```

**实际输出：**

```
65 A B
```

- `ord("A")` → **字符变成数字**
- `chr(65)` → **数字变成字符**
- **套起来用**：`chr(ord("A") + 1)` → `"B"`

## 7.2 `bin` / `oct` / `hex`

```python
print(bin(5), oct(8), hex(255))
print(len(bin(5)))
```

**实际输出：**

```
0b101 0o10 0xff
5
```

**它们交回的是字符串**，不是数字 —— 所以带你看见的 `0b` / `0o` / `0x`，**所以 `len(bin(5))` 不是 3**。

# 第 8 节 · 字面量里的细节

## 8.1 转义字符

```python
bad = "C:\new\test"
print(bad == "C:" + chr(10) + "ew" + chr(9) + "est")
print(len(bad))
```

**实际输出：**

```
True
9
```

**源码里写的一行，和字符串里存的值，不是一回事** —— `\n` 变成了一个换行符，`\t` 变成了一个制表符。

## 8.2 原始字符串 `r"..."`

```python
print(r"C:\new\test")
```

**实际输出：**

```
C:\new\test
```

**`r` 让 `\` 不再特殊。** 但它只是"不让 `\` 特殊"，**不是"什么都能写"**。

## 8.3 三引号 + 8.4 字符串乘法

```python
print("-" * 10)
print("""第一行
第二行""")
```

**实际输出：**

```
----------
第一行
第二行
```

# 附录

## A. 本课常见报错速查

> **全部是实跑抓下来的原文。**

| 报错 | 原因 | 怎么改 |
|---|---|---|
| `TypeError: 'str' object does not support item assignment` | 想给字符串的某一位赋值（`s[0] = "A"`） | 字符串改不了 —— **用切片拼一个新串** |
| `AttributeError: 'str' object has no attribute 'splits'. Did you mean: 'split'?` | 方法名拼错（`splits`） | **看它给你的建议** —— 就在后半句 |
| `ValueError: substring not found` | `index()` 找不到 | 找不到别用 `index` —— **用 `find()`**（它给 `-1`） |
| `TypeError: sequence item 0: expected str instance, int found` | `join` 的列表里有数字 | **先把每个元素 `str()` 一遍** |
| `TypeError: str.upper() takes no arguments (1 given)` | 给不需要参数的方法传了参数（`s.upper("x")`） | 这些方法**不吃参数**，直接 `s.upper()` |
| `TypeError: find expected at least 1 argument, got 0` | 忘了给参数（`s.find()`） | `find` 要找什么，得告诉它 |
| `TypeError: strip arg must be None or str` | `strip` 给了数字（`s.strip(1)`） | 参数只能是**字符串** |
| `TypeError: object of type 'int' has no len()` | 把数字交给 `len()` | `len()` 只吃**序列**（字符串、列表…） |
| `TypeError: 'str' object cannot be interpreted as an integer` | `range("ab")` | `range()` 只吃整数 |
| `SyntaxError: invalid character '”' (U+201D)` | 用了中文引号 | **切到英文半角**（注释里用中文引号没关系） |

## B. 卡住了怎么办

| 情况 | 做法 |
|---|---|
| 忘了方法名 | 直接问教师 |
| 报错了看不懂 | 先看**最后一行**（错误类型 + 原因），再往上找 `line N` |
| 结果和预期不一样 | 用 `f"[{...}]"` 包起来打印 —— 空白字符立刻现形 |
| 觉得"应该对"但不对 | **先猜再跑**，别直接改 |
| 卡了很久 | **写下你卡在哪**，然后问教师 |
