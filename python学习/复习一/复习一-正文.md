### 关于"不看资料"

**先完全不看资料做。** 遇到想不起来的，**别立刻翻文档**。

> **卡超过 10 分钟，允许查——但查完必须记进「想不起来」清单。**

**为什么这样设计**：你现在感觉到的"记不住"，**不是遗忘，是提取失败**——知识还在，但你想不起来、或者想起来很慢。

**重做原题治不了这个。只有"逼自己往外捞"才治。**

而**那份清单比做对题更值钱**——它就是你真实缺口的分布图。

### 甲1 · 读两个数，做四则运算 【第二课】

**要求**：新建 `jia1.py`：

- 用 `input()` 读入**两个整数**（记得转换）
- 输出两行：第一行是**和**，第二行是**积**
- 用 f-string，格式照下面

**运行示例**（`3` 和 `4` 是你输入的）：

```
请输入第一个数：3
请输入第二个数：4
3 + 4 = 7
3 × 4 = 12
```

**考的是**：`input()` + `int()` 转换 + 算术 + f-string（第二课）

# 乙 · 综合任务（4 题）

> 这组**跨多课**。每题都会用到至少两课的东西。

### 乙1 · 记账

**要求**：新建 `yi1.py`：

- 用 `input()` 读入 **3 笔支出**（可能是小数，用 `float()`）
- 把它们**存进一个列表**
- 输出五句话

**运行示例**（`12.5`、`80`、`30` 是你输入的）：

```
第1笔支出：12.5
第2笔支出：80
第3笔支出：30
共 3 笔
总额 122.50 元
平均 40.83 元
最大 80.00 元，最小 12.50 元
最大的一笔超过 50 了吗：True
```

**【自检】** 上面五行就是真实输出。

> **提示**：
> - 最后一句问的是"**最大的一笔**有没有超过 50"，
>   **不是**"每一笔有没有超过 50" → 所以先 `max()` 取出最大的一笔，再和 50 比
> - 比较运算 `>` **直接给出 `True` / `False`，不需要 `if`**
> - 平均要**算出来**，不许手写
>
> **考的是**：`input`+`float`+列表+`append`+`len`+`sum`/`max`/`min`+f-string（第二、三课）
>
> **📌 出题订正（见参考答案里的说明）**：
> 初版题面写的是"有超过 50 的吗"，**这个说法有歧义**——
> 它可以读成"每一笔有没有超过 50"，那样就需要 `or` 把三个比较连起来（**`or` 还没教，那才叫超纲**）。
> 现已改成"**最大的一笔**有没有超过 50"，`max()` 就是唯一自然的解法。

### 乙4 · 抄一份再改（陷阱复习）

**要求**：新建 `yi4.py`，分两段做：

**第一段**：

```python
original = [1, 2, 3, 4, 5]
```

- 做一份**独立的副本**，叫 `copy1`
- 把 `copy1` 的第一个元素改成 `99`
- 输出 `original` 和 `copy1`
- **确认 `original` 没变**

**第二段**：

- 用 `same = original` 的方式再拿一个名字
- 对 `same` 追加一个 `6`
- 输出 `original` 和 `same`
- **看看这次 `original` 变了没有**

**【自检】**（真实输出）

```
original = [1, 2, 3, 4, 5]
copy1    = [99, 2, 3, 4, 5]
original = [1, 2, 3, 4, 5, 6]
same     = [1, 2, 3, 4, 5, 6]
```

> **考的是**：`a[:]`（复制）vs `a`（引用）（第三课 6.1 / 6.2）
>
> **这题的重点不是"做对"，是让你亲眼看到两段的结果不同。**

### 丙1

```python
nums = [10, 20, 30, 40, 50]
part = nums[1:4]
part[0] = 999

print(part)
```

**问**：两行分别输出什么？**为什么 `nums` 没变？**

**问**：两行分别输出什么？`q.sort()` 影响到 `p` 了吗？
