# 复习一（覆盖 第 1~3 课）

> **这不是新课。规则和平时不一样，请先读下面这段再动手。**
>
> **题量**：10 题（甲 3 + 乙 4 + 丙 3）
> **预计时间**：1.5~2.5 小时（**不限时**，做透为止）

---

## 复习课怎么上（★ 先读）

**四条规则，和平时不同：**

| | 平时 | 复习一 |
|---|---|---|
| 内容 | 新知识点 | **全是旧知识，但没有一道是原题** |
| 范围 | 本课 | **累积：第 1~3 课全部** |
| 时间 | — | **不限时** |
| 资料 | 可查 | **先不看资料**（见下） |

### 关于"不看资料"

**先完全不看资料做。** 遇到想不起来的，**别立刻翻文档**。

> **卡超过 10 分钟，允许查——但查完必须记进「想不起来」清单。**

**为什么这样设计**：你现在感觉到的"记不住"，**不是遗忘，是提取失败**——知识还在，但你想不起来、或者想起来很慢。

**重做原题治不了这个。只有"逼自己往外捞"才治。**

而**那份清单比做对题更值钱**——它就是你真实缺口的分布图。

### 要交两样东西

1. **代码**（写在 `复习一\code\`）
2. **`_清单.md`**（写在 `复习一\code\` 里）——包含「想不起来」清单 + 三行总结，格式见最后一节

# 甲 · 空白自测（3 题）

> **这组题先完全不看资料。** 卡住就跳过，记进清单。

> 每组做完再翻 [参考答案](复习一-参考答案.md)。

### 甲1 · 读两个数，做四则运算

**要求**：新建 `jia1.py`：

- 用 `input()` 读入**两个整数**（记得转换）
- 输出两行：第一行是**和**，第二行是**积**
- 用 f-string，格式照下面

**运行示例**（`3` 和 `4` 是你输入的）：

```
请输入第一个数：3
请输入第二个数：4
3 + 4 = 7
3 × 4 = 12
```

**考的是**：`input()` + `int()` 转换 + 算术 + f-string（第二课）

### 甲2 · 切一个字符串

**要求**：新建 `jia2.py`：

```python
s = "Python"
```

用**切片**输出三行：

1. 前 3 个字母
2. 后 3 个字母
3. 整个反过来

**考的是**：切片用在**字符串**上（第三课学的切片 + 第二课的字符串）

> ⚠️ **这题是本次复习的重点之一。**
> 你在第三课只对**列表**用过切片。**字符串能不能切片？** 自己试。

### 甲3 · 先写答案，再验证

**要求**：新建 `jia3.py`：

1. **先在纸上/注释里写下**：下面这段跑完，`a` 和 `b` 分别是什么？
2. **再运行验证**

```python
a = [1, 2, 3]
b = a
b.append(9)
print(a)
print(b)
```

**考的是**：`b = a` 是引用还是复制（第三课 6.1）

# 乙 · 综合任务（4 题）

> 这组**跨多课**。每题都会用到至少两课的东西。

### 乙1 · 记账

**要求**：新建 `yi1.py`：

- 用 `input()` 读入 **3 笔支出**（可能是小数，用 `float()`）
- 把它们**存进一个列表**
- 输出五句话

**运行示例**（`12.5`、`80`、`30` 是你输入的）：

```
第1笔支出：12.5
第2笔支出：80
第3笔支出：30
共 3 笔
总额 122.50 元
平均 40.83 元
最大 80.00 元，最小 12.50 元
有超过 50 的吗：True
```

**【自检】** 上面五行就是真实输出。

> **提示**：
> - 最后一句要用**比较运算**（`>`），它直接给出 `True` / `False`
> - 平均要**算出来**，不许手写
>
> **考的是**：`input`+`float`+列表+`append`+`len`+`sum`/`max`/`min`+f-string（第二、三课）

---

### 乙2 · 处理名字

**要求**：新建 `yi2.py`：

```python
names = ["alice", "bob", "carol"]
```

输出四行：

1. 第一个名字的**第一个字母**
2. 第二个名字的**前两个字母**
3. `carol` 的**后三个字母**
4. 三个名字**拼成一串**

**【自检】**（真实输出）

```
a
bo
rol
alicebobcarol
```

> **提示**：第 1 题要从列表里先取出一个名字，**再从那个名字里取字母**——所以是**两次 `[]`**。
>
> **考的是**：索引 + 切片**层层套用**（第三课，但组合方式是新的）

---

### 乙3 · 改成绩

**要求**：新建 `yi3.py`：

```python
scores = [88, 92, 75, 96, 81]
```

1. 把 `75` 改成 `85`
2. **删掉最低的那个分数**
3. 输出剩下的列表、人数、平均分（2 位小数）

**【自检】**（真实输出）

```
[88, 92, 85, 96]
人数 4
平均 90.25
```

> **提示**：第 2 步要想清楚——**"最低的那个"怎么表示成代码？**
> （第三课的 `min()` 和 `remove()` 可以一起用）
>
> **考的是**：改元素 + `min` + `remove` + `len` + `sum` + f-string（第三课）

---

### 乙4 · 抄一份再改（陷阱复习）

**要求**：新建 `yi4.py`，分两段做：

**第一段**：

```python
original = [1, 2, 3, 4, 5]
```

- 做一份**独立的副本**，叫 `copy1`
- 把 `copy1` 的第一个元素改成 `99`
- 输出 `original` 和 `copy1`
- **确认 `original` 没变**

**第二段**：

- 用 `same = original` 的方式再拿一个名字
- 对 `same` 追加一个 `6`
- 输出 `original` 和 `same`
- **看看这次 `original` 变了没有**

**【自检】**（真实输出）

```
original = [1, 2, 3, 4, 5]
copy1    = [99, 2, 3, 4, 5]
original = [1, 2, 3, 4, 5, 6]
same     = [1, 2, 3, 4, 5, 6]
```

> **考的是**：`a[:]`（复制）vs `a`（引用）（第三课 6.1 / 6.2）
>
> **这题的重点不是"做对"，是让你亲眼看到两段的结果不同。**

# 丙 · 读代码（3 题）

> **这组不给答案，也不要求你写代码。**
>
> 每段代码**读一遍**，用**中文**说出：
> 1. **输出什么？**
> 2. **为什么？**
>
> 写在 `bing1.md`、`bing2.md`、`bing3.md` 里（用记事本或 VS Code 都行）。
>
> **做完再翻参考答案对照。**
>
> **为什么要练这个**：真实开发里，读别人的代码比写新代码多得多。
> 你到现在只在写，还没在读。

---

### 丙1

```python
nums = [10, 20, 30, 40, 50]
part = nums[1:4]
part[0] = 999
print(nums)
print(part)
```

**问**：两行分别输出什么？**为什么 `nums` 没变？**

---

### 丙2

```python
p = [3, 1, 2]
q = p[:]
q.sort()
p.append(4)
print(p)
print(q)
```

**问**：两行分别输出什么？`q.sort()` 影响到 `p` 了吗？

---

### 丙3

```python
price = "19.9"
float(price)
print(f"价格是 {price} 元")
```

**问**：

1. 这段**能跑吗**？
2. 输出什么？
3. **`float(price)` 这一行有没有起作用？** 如果没有，问题在哪？

> ⚠️ **这题和你第三课 d4 的错误是同一个坑。** 想想你在 d4 里是怎么补救的。
