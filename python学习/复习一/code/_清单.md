## 1. 切片省略 stop 的写法 ★

**你的原话**（`jia5.py`）：
> "第一次写 b 的时候写的是 `b=s[-1:-4]`，第二次写的 `[3,5]`，最后我才想到空值代表着直接到尾部。"

**正确的知识点：**

| 写法 | 结果 | 说明 |
|---|---|---|
| `s[3:]` | 从下标 3 到**结尾** | 省略 stop = "一直到尾" |
| `s[-1:-4]` | **空的 `''`** | **正步长时，start 必须小于 stop**。`-1` 大于 `-4`，所以取不到东西 |
| `s[3,5]` | **报错** | `3,5` 是一个**元组**，不是切片。切片必须用**冒号** `3:5` |

**一句话**：**切片用冒号，不是逗号；省略的一边就是"那一头到底"。**

## 2. `float()` / `int()` 的返回值要接住 ★★★（这是第三次）

**你的原话**（`yi1.py`）：
> "float (a) / float (b) / float (c) 之前在这个位置，似乎报错。"

**正确的知识点：**

```python
float(a)          # ❌ 算出来就丢了，a 还是字符串
a = float(a)      # ✅ 接住
a = float(input("价格："))    # ✅ 更好：一步到位
```

**规律（记这一张表就够）：**

| | 例子 | 改原来的吗 |
|---|---|---|
| **函数** | `float(x)` `int(x)` `str(x)` `sorted(x)` `len(x)` `sum(x)` | ❌ **不改，返回值必须接住** |
| **方法** | `x.append()` `x.insert()` `x.remove()` `x.sort()` | ✅ **改自己，不用接** |
| 例外 | `x.pop()` | 既改自己，**又返回**被删的 |

**一眼判断法**：**一行只有 `float(x)` 而左边没有 `=` → 99% 是错的。**

**⚠️ 这是第三次**（第三课 d4 → 复习一丙3 → 复习一乙1）。

## 4. `int()` / `float()` 不能作用于列表 ★

**你的原话**（`yi3.py`）：
> "`sum(int(scores))` 报错……忘了点东西导致的。其实本质已经是整数组了。"

**正确的知识点：**

`int()` / `float()` 只能接受**一个值**：字符串或数字。**列表不行。**

```
TypeError: int() argument must be a string, a bytes-like object or a real number, not 'list'
```

`scores` 已经是**数字列表**了，`sum(scores)` 直接就能用，**不需要任何转换**。

**⚠️ 这里有个倾向要留意**：你现在遇到不确定就**加个 `int()` / `float()`**。
- `jia3.py` 里写了 `float(thickness*(2**times))` —— 多余的
- `yi3.py` 里写了 `sum(int(scores))` —— 报错

**转换应该加在"数据的来源"上**（`input()` 的结果、字符串），**不是加在列表或算式上。**

> 这个倾向是**从 d4 那个坑里长出来的**（那次是"该转换没转换"），方向是对的，**只是矫枉过正了**。

## 7. 切片的元素个数 — 丙1 值算错 ★

**你的原话**（`bing1.md`）：
> "part 输出为 `999 20 30 40`"
> "至于为什么 part 输出没有 50——因为它只取到 4，4 这个位值本身不取，**到 3**。"

**你说的规则是对的，但算出来的值不对。**

**正确的知识点：**

```python
nums = [10, 20, 30, 40, 50]
part = nums[1:4]      # 下标 1、2、3 → [20, 30, 40]   ← 3 个元素
part[0] = 999
print(part)           # [999, 30, 40]     ← 不是 999 20 30 40
print(nums)           # [10, 20, 30, 40, 50]
```

**你写了 4 个元素（999 20 30 40），但那说明你按 `[0:4]` 去数了。**

**校验方法**：**元素个数 = `stop - start`**。`4 - 1 = 3` 个 → 不可能是 4 个。
**自己动手数一遍下标，比凭感觉快。**
