```python
a = int(input("请输入第一个数："))
```

### 甲2 · 分装 【第二课】

```python
total = 47
per_box = 5

print(f"能装满 {total // per_box} 盒")
print(f"还剩 {total % per_box} 个")
```

**实际输出**

```
能装满 9 盒
还剩 2 个
```

> **`//` 取整，`%` 取余**——这一对是"分装问题"的标准解法：
>
> | 问 | 用什么 | 为什么 |
> |---|---|---|
> | 能装满几盒 | `47 // 5` = `9` | 只要**整盒**的，装不满的不算 |
> | 还剩几个 | `47 % 5` = `2` | 余数就是剩下的零头 |
>
> **第二课你做过"秒数转时分秒"，用的是同一对运算符。**
> 这题的价值在于：**换个场景你还能不能想起来用它。**
>
> **也可以直接写在 f-string 里**（不用先存变量）：
> ```python
> print(f"能装满 {47 // 5} 盒")
> ```

### 甲3 · 对折 【第二课】

```python
thickness = 0.1
times = 10

print(f"对折 {times} 次后，厚度是 {thickness * 2 ** times:.1f} 毫米")
```

**实际输出**

```
对折 10 次后，厚度是 102.4 毫米
```

> **`**` 是幂运算**（第二课）。对折 10 次 = 厚度 × 2¹⁰ = 0.1 × 1024 = **102.4**
>
> **注意这里同时用到了三样东西**：
> 1. `**` 算幂（第二课）
> 2. 普通乘法 `*`（第二课）
> 3. `:.1f` 保留 1 位小数（第二课）
>
> **C# 里没有 `**` 这个运算符**——C# 要写 `Math.Pow(2, 10)`。
> Python 直接 `2 ** 10`，这是它更顺手的地方之一。

### 甲4 · 两种写法 【第一课】

```python
name = "YN4"
age = 24

print("我叫", name, "，今年", age, "岁")
print(f"我叫{name}，今年{age}岁")
```

**实际输出**

```
我叫 YN4 ，今年 24 岁
我叫YN4，今年24岁
```

> **对比第一行和第二行的空格：**
>
> | 写法 | 输出 | 空格 |
> |---|---|---|
> | `print` 逗号版 | `我叫 YN4 ，今年 24 岁` | **每个逗号处自动加一个空格** |
> | f-string | `我叫YN4，今年24岁` | **你写什么就是什么** |
>
> **这不是新知识**——你第一课作业就遇到过。这里换个形式再碰一次。
>
> **结论：要精确控制空格，就用 f-string。** 逗号版适合"随便打点东西看看"。

### 甲5 · 切一个字符串 ★ 本次重点

```python
s = "Python"

print(s[:3])
print(s[-3:])
print(s[::-1])
```

**实际输出**

```
Pyt
hon
nohtyP
```

> **核心结论：字符串也能切片，规则和列表完全一样。**
>
> - `s[:3]` → 前 3 个字符
> - `s[-3:]` → 后 3 个字符（负索引在字符串上一样有效）
> - `s[::-1]` → 反转
>
> **为什么这题重要**：你在第三课只对**列表**用过切片。
> 现在你应该知道——**切片是"序列"的操作，不是"列表"的操作。**
> 字符串、列表都能用，规则一模一样。
>
> 这个"同一个操作适用于多种东西"的意识，是学语言时最值钱的东西之一。

### 乙1 · 记账

```python
s1 = float(input("第1笔支出："))
s2 = float(input("第2笔支出："))
s3 = float(input("第3笔支出："))

spend = []
spend.append(s1)
spend.append(s2)
spend.append(s3)

print(f"共 {len(spend)} 笔")
print(f"总额 {sum(spend):.2f} 元")
print(f"平均 {sum(spend) / len(spend):.2f} 元")
```

**运行（输入 `12.5`、`80`、`30`）**

### 乙2 · 处理名字

```python
names = ["alice", "bob", "carol"]

print(names[0][0])
print(names[1][:2])
print(names[2][-3:])
print(names[0] + names[1] + names[2])
```

**实际输出**

```
a
bo
rol
alicebobcarol
```

> **`names[0][0]` 的读法（从里往外）：**
>
> ```
> names[0]      → "alice"      （先从列表里取出第一个元素）
> names[0][0]   → "a"          （再从那个字符串里取第一个字符）
> ```
>
> **两次 `[]` 套着用**，第一次的结果是第二次的输入。
>
> `names[1][:2]` 同理：先取 `"bob"`，再切片取前两个 → `"bo"`。
>
> **第 4 行是字符串拼接**：`+` 用在字符串上是"接在一起"（第二课讲过）。

### 乙3 · 改成绩

```python
scores = [88, 92, 75, 96, 81]

scores[2] = 85
scores.remove(min(scores))

print(scores)
print(f"人数 {len(scores)}")
print(f"平均 {sum(scores) / len(scores):.2f}")
```

**实际输出**

```
[88, 92, 85, 96]
人数 4
平均 90.25
```

**逐步拆解：**

| 步骤 | `scores` |
|---|---|
| 初始 | `[88, 92, 75, 96, 81]` |
| `scores[2] = 85` | `[88, 92, 85, 96, 81]` |
| `min(scores)` → `81` | |
| `scores.remove(81)` | `[88, 92, 85, 96]` |
| `sum` = 361，`len` = 4 | 平均 = 361 ÷ 4 = **90.25** |

> **关键点**：`remove(min(scores))` 这个写法。
> **`min()` 先算出最低分是多少，`remove()` 再按这个值去删。**
> 两个函数套着用，这在真实代码里很常见。
>
> **另一种写法**：先排序再去掉第一个 —— 但那样更绕（第三课 g2 你自己评价过）。

### 乙4 · 抄一份再改

```python
original = [1, 2, 3, 4, 5]

# 第一段：真复制
copy1 = original[:]
copy1[0] = 99
print("original =", original)
print("copy1    =", copy1)

# 第二段：引用
same = original
same.append(6)
print("original =", original)
print("same     =", same)
```

**实际输出**

```
original = [1, 2, 3, 4, 5]
copy1    = [99, 2, 3, 4, 5]
original = [1, 2, 3, 4, 5, 6]
same     = [1, 2, 3, 4, 5, 6]
```

> **两段对比：**
>
> | 写法 | 效果 | 结果 |
> |---|---|---|
> | `copy1 = original[:]` | **复制**出两个独立列表 | 改了 `copy1`，`original` **没变** |
> | `same = original` | **同一个列表**，两个名字 | 改了 `same`，`original` **也变了** |
>
> **注意第 3 行**：`original` 变成 `[1, 2, 3, 4, 5, 6]` 了——
> 第一段那个 `copy1` 的修改**没有**污染它，第二段的 `same` **污染了**它。

# 丙 · 读代码

> 这组不给"标准代码"，给的是**读法**。

### 丙1

```python
nums = [10, 20, 30, 40, 50]
part = nums[1:4]
part[0] = 999
print(nums)
print(part)
```

**输出**

```
[10, 20, 30, 40, 50]
[999, 30, 40]
```

**为什么 `nums` 没变？**

> `nums[1:4]` **不是"引用其中一段"，而是复制出一份新的列表** `[20, 30, 40]`。
> 所以 `part` 和 `nums` 是两个独立的东西。
> 改 `part[0]` 只改了新的那一份，`nums` 完全不知道。
>
> **一句话**：**切片 = 复制。**（第三课 3.5、6.2）

### 丙2

```python
p = [3, 1, 2]
q = p[:]
q.sort()
p.append(4)
print(p)
print(q)
```

**输出**

```
[3, 1, 2, 4]
[1, 2, 3]
```

**`q.sort()` 影响到 `p` 了吗？**

> **没有。** 因为 `q = p[:]` 已经**复制**出一份独立的列表，
> 之后 `q.sort()` 改的是 `q` 自己。
>
> **两个操作都是"改自己"：**
> - `q.sort()` —— 排序**原地**改 `q`
> - `p.append(4)` —— 追加**原地**改 `p`
>
> 但因为 `p` 和 `q` 本来就是**两个独立列表**，所以互不影响。
>
> **输出里 `p` 是 `[3, 1, 2, 4]`**（没排序，只是多了个 4），
> **`q` 是 `[1, 2, 3]`**（排好了，没有 4）。

### 丙3 ★ 这题和你 d4 的错误是同一个坑

```python
price = "19.9"
float(price)
print(f"价格是 {price} 元")
```

**1. 能跑吗？**

> **能跑**，不报错。

**2. 输出什么？**

```
价格是 19.9 元
```

**3. `float(price)` 起作用了吗？**

> **没有，等于白写。**
>
> `float(price)` 会**算出一个新的浮点数交给你**，但**你没有接住它**——
> 这个值算完就被丢掉了。
>
> `price` **从头到尾都是字符串**。可以验证：
>
> ```python
> price = "19.9"
> float(price)
> print(type(price))       # <class 'str'>   ← 还是字符串
> ```
>
> **正确写法**：
>
> ```python
> price = float("19.9")    # 接住它
> ```
>
> **这就是你第三课 d4 的同一个坑**：
>
> | 写法 | 改原来的吗 |
> |---|---|
> | `float(price)` / `sorted(nums)` | ❌ **不改**，返回值**必须接住** |
> | `q.sort()` / `p.append()` | ✅ **改自己**，不用接 |
>
> **注意这题阴在哪**：输出看起来**完全正常**（`价格是 19.9 元`），
> 因为字符串 `"19.9"` 和浮点数 `19.9` 打印出来长得一样。
> **你不接住，程序不报错，只是后面算数的时候才会炸。**
