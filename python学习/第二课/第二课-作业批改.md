## 五、你 A1 里提的问题，逐个回答

### Q1：`7 // 2` 为什么不是 4？四舍五入应该是 4 吧？

**它不是四舍五入，是向下取整。**

| 做法 | `3.5` 的结果 | `-3.5` 的结果 |
|---|---|---|
| 四舍五入 | `4` | `-4` |
| 截断（砍掉小数） | `3` | `-3` |
| **向下取整（`//`）** | `3` | **`-4`** |

所以 `7 // 2` = `3.5` 向下取整 = **`3`**。

**而且这条原文我写错了**，已经修正（见第四节第 1 点）。

### Q2：`int("24")` 为什么需要字符串？`int` 本身就需要字符串吗？

**不是，`int()` 什么都能吃**（实测）：

```python
int("24")   # 24
int(3.9)    # 3
int(-3.9)   # -3
int(5)      # 5
int(True)   # 1
```

`int(x)` 的意思是"**把 x 变成整数**"：

- `x` 是**字符串** → 按十进制**解析**它
- `x` 是**浮点** → **截断**它（向零取整）
- `x` 本来就是**整数** → 原样返回

### Q3：为什么 `int("24") + 1` 没被当成"名字 + 数字"，反而算出 25？

因为你把 `int("24")` 整体看成了"字符串"，**但加上括号之后，它已经是一个"动作"了**：

| 写法 | Python 的理解 |
|---|---|
| `"24"` | 一个字符串（你说的"名字"） |
| `int` | 一个**内置函数的名字** |
| **`int("24")`** | **"调用 int 这个函数，把 `"24"` 转成整数"——这是一个动作，结果是数字 `24`** |

所以 `int("24") + 1` = `24 + 1` = `25`。**括号一加，就从"名字"变成了"动作"。**

你预测它会报错，是因为把 `int("24")` 当成了"字符串本身"。**这是很自然的误解**，而且你现在搞清楚了。

### Q4：如果里面填 `"A"` 呢？直接报错？

**对，直接报错**（实测原文）：

```
ValueError: invalid literal for int() with base 10: 'A'
```

读法：`literal` = 字面量。意思是"**`'A'` 不是一个合法的十进制数字字面量**"。

`int("24")` 能成，是因为 `"24"` 长得像数字；`"A"` 不像，所以拒绝。

> 顺带：`int("24.5")` 也会报类似的错（B2 第 3 题），因为 `int()` **不解小数点**。
> 想成功就得两步：`int(float("24.5"))`。
