# 第 1 节 · 数字

## 1.1 int 和 float

Python 里数字主要就两种：

| 类型 | 名字 | 例子 |
|---|---|---|
| `int` | 整数 | `24`、`-5`、`0` |
| `float` | 小数 | `3.5`、`24.0`、`-0.1` |

**不用声明类型**（这是和 C# 最大的区别）：

```python
age = 24        # Python 自己知道这是 int
price = 19.9    # Python 自己知道这是 float
```

```csharp
// C# 要写类型
int age = 24;
double price = 19.9;
```

## 1.2 运算

```python
print(7 + 2)     # 9
print(7 - 2)     # 5
print(7 * 2)     # 14
print(7 / 2)     # 3.5     ← 除法
print(7 // 2)    # 3       ← 整除（砍掉小数）
print(7 % 2)     # 1       ← 取余数
print(2 ** 10)   # 1024    ← 幂（C# 没有这个运算符）
```

**速查表**

| 运算符 | 名字 | 例子 | 结果 |
|---|---|---|---|
| `+` | 加 | `7 + 2` | `9` |
| `-` | 减 | `7 - 2` | `5` |
| `*` | 乘 | `7 * 2` | `14` |
| `/` | 除 | `7 / 2` | `3.5` |
| `//` | 整除 | `7 // 2` | `3` |
| `%` | 取余 | `10 % 3` | `1` |
| `**` | 幂 | `2 ** 8` | `256` |

## 1.3 三个必须记住的点

**① `/` 永远返回小数**

```python
print(6 / 2)      # 3.0    ← 不是 3，是 3.0！
```

C# 里 `6 / 2` 是 `3`，Python 里是 `3.0`。

**② `//` 才是整除**

```python
print(7 // 2)     # 3
```

**③ Python 的整数没有上限**

```python
print(2 ** 100)
# 1267650600228229401496703205376
```

C# 的 `int` 到 21 亿就溢出了，Python 的 `int` **要多长有多长**。

# 第 2 节 · 类型：`"24"` 和 `24` 差在哪

> **这是本课最重要的一节。**

## 2.1 先看类型

```python
print(type(24))      # <class 'int'>
print(type(24.0))    # <class 'float'>
print(type("24"))    # <class 'str'>    ← 注意！
```

`str` = string = 字符串。

```python
a = 24       # 数字，可以做算术
b = "24"     # 文本，是两个字符 "2" 和 "4"
```

## 2.2 为什么这个区别要命

```python
a = 24
print(a + 1)     # 25    ✅ 数字可以加

b = "24"
print(b + 1)     # ❌ 直接报错
```

报错是（我实跑的原文）：

```
TypeError: can only concatenate str (not "int") to str
```

**读法**：`concatenate` = 拼接。意思是"**字符串只能和字符串拼接，不能和整数拼**"。

### 那 `"24" + "1"` 呢？

```python
print("24" + "1")    # 241    ← 不是 25！是拼接！
```

**关键：`+` 用在数字上是加法，用在字符串上是"接在一起"。**

```
24 + 1        →  25
"24" + "1"    →  "241"
```

**这个坑比报错更可怕**：它**不报错，只是结果错了**。你写 `age = "24"`，后面写 `age + "1"`，会静默得到 `"241"`。

## 2.3 类型转换

```python
int("24")       # 24      文本 → 整数
float("3.5")    # 3.5     文本 → 小数
str(24)         # "24"    数字 → 文本
```

**两个坑：**

```python
int("24.5")            # ❌ ValueError！带小数点的字符串不能直接转 int
int(float("24.5"))     # ✅ 先转 float 再转 int，得到 24

int(3.9)               # 3       ← 直接砍掉小数，不是四舍五入！
round(3.9)             # 4       ← 这个才是四舍五入
```

# 第 3 节 · f-string —— 一行解决空格问题

## 3.1 先看旧写法的问题

你作业里是这么写的：

```python
name = "YN4"
age = 24
print("我叫", name, ",我今年有", age, "岁。")
```

输出：

```
我叫 YN4 ,我今年有 24 岁。
      ↑          ↑
    多一个空格    多一个空格
```

**原因**：`print` 用逗号分隔时，**会自动在每个逗号位置加一个空格**。你控制不了。

## 3.2 f-string 的写法

```python
name = "YN4"
age = 24
print(f"我叫{name}，我今年{age}岁。")
```

输出：

```
我叫YN4，我今年24岁。
```

**对比：**

```python
print("我叫", name, ",我今年有", age, "岁。")   # 旧：空格自己乱加
print(f"我叫{name}，我今年{age}岁。")            # 新：你写什么就是什么
```

### 语法规则（就三条）

1. 引号前面加一个字母 **`f`**
2. 变量名用 **`{}`** 包起来
3. **引号里面、`{}` 外面的东西全部原样输出**（包括中文标点、空格）

> 第 3 条是关键：`，` 和 `。` 只是普通字符，**原样输出**。
> 所以你不再需要靠逗号分隔，**直接写你想要的句子就行**。

## 3.3 `{}` 里可以放表达式

不只变量名，**任何算式**都行：

```python
age = 24
print(f"明年我就{age + 1}岁了")        # 明年我就25岁了
```

## 3.4 控制小数位数

用 `:.2f` 表示"保留 2 位小数"：

```python
pi = 3.14159
print(f"{pi:.2f}")     # 3.14
print(f"{pi:.0f}")     # 3
```

| 写法 | 含义 |
|---|---|
| `{x:.0f}` | 保留 0 位小数 |
| `{x:.1f}` | 保留 1 位小数 |
| `{x:.2f}` | 保留 2 位小数 |

# 第 4 节 · input() —— 从键盘读输入

## 4.1 基本用法

```python
name = input("请输入你的名字：")
print(f"你好，{name}！")
```

运行效果：

```
请输入你的名字：YN4
你好，YN4！
```

`input()` 括号里的文字会**先显示出来当提示**，然后等你打字、按回车。

## 4.2 ⚠️ 最关键：input() 读进来的永远是字符串

```python
age = input("请输入你的年龄：")
print(type(age))       # <class 'str'>   ← 永远是 str！
```

所以：

```python
age = input("请输入你的年龄：")   # 你输入 24
print(age + 1)                    # ❌ TypeError！
```

**正确写法：先转换**

```python
age = int(input("请输入你的年龄："))    # 用 int() 包起来
print(age + 1)                          # ✅ 25
```

> **看，这和你作业里 `age = "24"` 是同一个坑。**
> 区别只是：那次是你手写的引号，这次是 `input()` 自动带的。
> **只要来源是 `input()`，就一定要转换。**

小数用 `float()`：

```python
price = float(input("请输入价格："))
print(f"价格是 {price:.2f} 元")
```

**自己测这三个用例。** 这叫"测试用例"，是写程序的基本功。

<details>
<summary>卡住了点开看思路（先自己想）</summary>

```
小时 = 总秒数 // 3600
分钟 = (总秒数 % 3600) // 60
秒   = 总秒数 % 60
```

**为什么这样算？** 自己推一遍：

- 1 小时 = 3600 秒 → 小时数 = 一共有几个 3600 → `// 3600`
- 剩下的零头 = `% 3600`
- 零头里有几个 60 → 分钟 → `// 60`
- 最后剩的就是秒 → `% 60`

</details>

## A. 本课常见报错速查

| 报错 | 原因 | 怎么改 |
|---|---|---|
| `TypeError: can only concatenate str (not "int") to str` | 拿字符串去加数字 | 用 `int()` 或 `float()` 转换 |
| `ValueError: invalid literal for int() with base 10: '24.5'` | `int()` 吃了带小数点的字符串 | 先 `float()` 再 `int()` |
| `NameError: name 'xxx' is not defined` | 变量名拼错，或用了没定义的变量 | 检查拼写 |
| `ValueError: could not convert string to float: 'abc'` | `float()` 吃了不是数字的东西 | 检查输入 |
