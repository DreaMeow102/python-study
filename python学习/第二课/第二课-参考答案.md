## A 组 · 数字

### A1 · 先猜再跑

```python
print(7 / 2)
print(7 // 2)
print(6 / 2)
print(2 ** 8)
print(10 % 3)
print(24 + 1)
print("24" + "1")
print(int("24") + 1)
```

**实际输出**

```
3.5
3
3.0
256
1
25
241
25
```

> 最后三行是重点：`25` / `241` / `25`。

---

### A2 · 只改一个符号

```python
print(7 // 2)
```

**改动**：把 `/` 改成 `//`。

**实际输出**

```
3
```

> **补充（正文已修正）**：`//` 是**向下取整**，不是「砍掉小数」。
> 这题是正数，三种说法结果一样，看不出区别。但负数会分家：
>
> ```python
> print(-7 // 2)      # -4   向下取整
> print(int(-7 / 2))  # -3   截断
> ```
>
> C# 的 `-7 / 2` 是 `-3`，Python 的 `-7 // 2` 是 `-4`。

---

### A3 · 幂和余数

```python
a = 2 ** 16
b = 100 % 7

print(f"2 的 16 次方是 {a}")
print(f"100 除以 7 的余数是 {b}")
```

**实际输出**

```
2 的 16 次方是 65536
100 除以 7 的余数是 2
```

> 也可以直接把算式写进 `{}` 里，省掉变量：
> `print(f"2 的 16 次方是 {2 ** 16}")` —— 输出完全一样。

---

### A4 · 验证整数无上限

```python
print(2 ** 100)
```

**实际输出**

```
1267650600228229401496703205376
```

**思考题答案**：C# 的 `int` 上限是 `2,147,483,647`（约 21 亿），超过会**溢出**（通常变成负数，是个经典 bug）。Python 的 `int` **没有上限**，不会溢出。

## B 组 · 类型

### B1 · 看类型

```python
print(type(24))
print(type(24.0))
print(type("24"))
print(type("24.0"))
print(type(2 ** 100))
print(type(6 / 2))
```

**实际输出**

```
<class 'int'>
<class 'float'>
<class 'str'>
<class 'str'>
<class 'int'>
<class 'float'>
```

> 两个容易猜错的：`24.0` 是 `float`；`6 / 2` 也是 `float`。
> 另外注意 `2 ** 100` 虽然巨大，但**还是 `int`**——Python 的整数可以任意长。

---

### B2 · 判断对错

```python
print("1)", 24 + 1)
print("2)", "24" + "1")
print("3)", int("24.5"))
print("4)", int(3.9))
print("5)", round(3.9))
print("6)", type(6 / 2))
print("7)", "24" == 24)
```

**实际输出**

```
1) 25
2) 241
3) ValueError: invalid literal for int() with base 10: '24.5'
4) 3
5) 4
6) <class 'float'>
7) False
```

> **第 3 行是报错，这是正确答案。** `int()` 不能直接吃带小数点的字符串。
> **第 7 行 `False` 是最重要的一题**：Python 不会自动把字符串转成数字，
> `"24"` 和 `24` 是**两个完全不同的东西**。

---

### B3 · 修错（两种改法）

**先看它报什么错：**

```
TypeError: can only concatenate str (not "int") to str
```

**改法一：改赋值那一行（把字符串改成数字）**

```python
age = 24
print(age + 1)
```

**改法二：改 print 那一行（把字符串转成数字）**

```python
age = "24"
print(int(age) + 1)
```

**两种改法的实际输出都是**

```
25
```

> **哪种更好？**
> 一般是**改法二**更常见——因为数据往往来自 `input()`，你没法改它的来源，
> 只能在使用前转换。这正是第 4 节要讲的。

---

### B4 · 转换链

```python
print(int(float("3.5")))
```

**实际输出**

```
3
```

> **为什么不能一步到位？**
> `int("3.5")` 会报 `ValueError`（见 B2 第 3 题）。
> 必须**先转成小数，再转成整数**。
>
> 顺便注意：`int(3.9)` 也是 `3`，**是直接砍掉小数，不是四舍五入**。

---

### B5 · 这个坑最阴

```python
print("3" + "5")
print(3 + 5)
```

**实际输出**

```
35
8
```

> **`35` 是陷阱。** 它不报错，看起来还挺像一个答案。
> 如果你写程序时忘了转换，就会得到这种"静默的错误结果"——
> **比直接崩溃危险得多，因为它会被你放过去。**

## C 组 · f-string

### C1 · 改造旧代码

```python
name = "YN4"
age = 24

print(f"我叫{name}，我今年{age}岁。")
```

**实际输出**

```
我叫YN4，我今年24岁。
```

> **关键点**：中文逗号 `，` 直接写在 f-string 里面，**不要**用 `print` 的逗号分隔。
> 这样就不会有任何多余空格。

---

### C2 · 算式自动算出来

```python
a = 7
b = 2

print(f"{a} + {b} = {a + b}")
print(f"{a} - {b} = {a - b}")
print(f"{a} * {b} = {a * b}")
print(f"{a} / {b} = {a / b}")
```

**实际输出**

```
7 + 2 = 9
7 - 2 = 5
7 * 2 = 14
7 / 2 = 3.5
```

> 注意最后一行是 `3.5` 不是 `3`——因为 `/` 永远返回小数。

---

### C3 · 小数格式化

```python
pi = 3.14159

print(f"{pi:.0f}")
print(f"{pi:.1f}")
print(f"{pi:.2f}")
print(f"{pi:.3f}")
```

**实际输出**

```
3
3.1
3.14
3.142
```

> **第一行是 `3` 不是 `3.0`**：`.0f` 表示"不显示小数部分"。

---

### C4 · 重写你的自我介绍 ★

```python
name = "YN4"
age = 24
zhuanYe = "AI"

print(f"我叫{name}，我今年{age}岁，我的专业是{zhuanYe}。")
```

**实际输出**

```
我叫YN4，我今年24岁，我的专业是AI。
```

> **和第一课的输出对比：**
>
> | 版本 | 输出 |
> |---|---|
> | 旧（print 逗号版） | `我叫 YN4 ,我今年有 24 岁, 我的专业是 AI 。` |
> | 新（f-string） | `我叫YN4，我今年24岁，我的专业是AI。` |
>
> **这一题做完，你作业里那个空格问题就彻底解决了。**

---

### C5 · 小数 + 文字

```python
city = "北京"
temp = 23.456

print(f"{city}今天 {temp:.1f} 摄氏度")
```

**实际输出**

```
北京今天 23.5 摄氏度
```

> **注意两个空格的位置**：`{city}今天` 后面有一个空格，`{temp:.1f}` 后面也有一个。
> 这两个空格是**你手动敲进去的普通空格**，f-string 会原样输出。
> 在 f-string 里，**空格完全由你控制**——这就是它比 `print` 逗号版强的地方。

### D3 · 求和的陷阱

**第一步：不转换（错误示范）**

```python

```

```

请输入第二个数:5

```

> **第一步的 `35` 是这一课最值得记住的陷阱。**
> 它不报错、不崩溃，看起来还挺像一个答案。
> 但它是**错的**——因为 `input()` 给你的永远是字符串。

### D4 · 小数输入 + 打折

```python
price = float(input("请输入价格:"))
print(f"原价 {price:.2f} 元，打八折后 {price * 0.8:.2f} 元")
```

**运行（输入 `19.9`）**

```
请输入价格:19.9
原价 19.90 元，打八折后 15.92 元
```

> 注意 `{}` 里可以放**整个算式**：`{price * 0.8:.2f}` 表示
> "先把 `price * 0.8` 算出来，再保留 2 位小数"。

## 第 5 节 · 综合关卡

### 关卡 1 · 秒数转时分秒

```python
total = int(input("请输入秒数:"))

h = total // 3600
m = (total % 3600) // 60
s = total % 60

print(f"{total}秒 = {h}小时{m}分{s}秒")
```

**三个测试用例的实际输出**

| 输入 | 输出 |
|---|---|
| `3725` | `3725秒 = 1小时2分5秒` |
| `60` | `60秒 = 0小时1分0秒` |
| `3661` | `3661秒 = 1小时1分1秒` |

**完整运行示例**

```
请输入秒数:3725
3725秒 = 1小时2分5秒
```

> **推导过程**（自己再推一遍）：
>
> - `3725 // 3600` = `1` → 小时，因为 3725 里只有 1 个 3600
> - `3725 % 3600` = `125` → 剩下的零头
> - `125 // 60` = `2` → 分钟
> - `125 % 60` = `5` → 剩下的秒
>
> 合起来：`1小时2分5秒` ✅

### 关卡 2 · 找零计算器

```python
price = float(input("请输入商品价格:"))
paid = float(input("请输入付款金额:"))

change = paid - price

print(f"应收 {price:.2f} 元，实收 {paid:.2f} 元，找零 {change:.2f} 元")
```

**运行（输入 `37.5` 和 `50`）**

```
请输入商品价格:37.5
请输入付款金额:50
应收 37.50 元，实收 50.00 元，找零 12.50 元
```

> **思考题的答案**：为什么输入 `50` 也能输出 `50.00`？
>
> 因为 `float(input(...))` 把 `"50"` 转成了**小数** `50.0`，
> 再用 `.2f` 格式化，就补成了 `50.00`。
>
> **如果不用 `float()`**，`"50"` 就只是文本，`.2f` 会直接报错。
